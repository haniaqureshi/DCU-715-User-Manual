# AGENTS.md: DCU 715 User Manual

Guidance for AI agents that read this manual to answer questions about the ITR Series 715 Digital Collection Unit (DCU 715).

## What this site is

The official user manual for the DCU 715, a portable unit that collects machine vibration data for predictive maintenance. The DCU 715 works with the ITR Graphics™ vibration analysis platform.

## Terms the manual uses

- **Home screen**: The screen that shows the ITR logo. Some pages call it the **Dashboard**.
- **Main Menu**: The list of sections (Routes, Measurements, Special Tests, DCU Setup, and Power) that appears when you select **Menu** on the Home screen.
- **Submenu**: The list that opens when you select a section on the Main Menu, such as the **Power** submenu.
- **Function**: An item in a submenu that does a task, such as **Power Off**.
- **Dialog**: A message box that asks the user to confirm or choose, such as the Power Off confirmation.
- **Select**: The verb for tapping or clicking an item on the DCU touchscreen.

## When you answer

- Quote on-screen text and button names exactly as the manual shows them, in bold (for example, **Yes** and **No**).
- Give steps as a numbered list, in the same order as the manual.
- Repeat warnings from the manual, such as saving data before you turn off the DCU 715.
- Link to the page you used.
- If the manual doesn't cover a question, say so. Don't guess at device behavior. Suggest contacting ITR support.
