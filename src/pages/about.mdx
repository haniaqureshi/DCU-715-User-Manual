# About this manual

The DCU 715 User Manual explains how to use the ITR Series 715 Digital Collection Unit (DCU 715). The DCU 715 is a portable unit that measures machine vibration for predictive maintenance. It works with the ITR Graphics™ vibration analysis platform.

## Who this manual is for

This manual is for technicians who collect vibration data with the DCU 715, and for the people who set up and maintain the unit.

## What's in this manual

- [Getting started](/intro): What the DCU 715 is, its hardware, technical specifications, startup, and screen layout.
- [Routes](/Routes/): Select, update, create, and delete measurement routes.
- [Measurements](/Measurements/): Transmit, display, and manage measurement data.
- [Special Tests](/SpecialTests/): Bump tests, coast-down tests, orbit plots, balancing, and other special tests.
- [DCU Setup](/DCUSetup/): Maintenance, diagnostics, settings, and advanced settings.
- [Power](/Power/): Turn off the DCU 715, minimize the application, or close it.
- [Appendix](/Appendix/): URE measurements, troubleshooting, and a glossary.

## Accessibility

We want everyone to be able to use this manual. We're working to make every page meet the [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/) at Level AA, and we test each section as we update it. For example:

- Images have text descriptions, and you can enlarge an image with the keyboard by pressing Enter or Space.
- Text and controls have enough color contrast in light and dark mode.
- You can reach links and controls with the keyboard.

If something in this manual is hard to read or use, email [support@ITR.com](mailto:support@ITR.com). Tell us the page and what went wrong.
