# Transmit Measurements

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Transmit Measurements** option allows the user to send the recorded measurement data from the device to the server or computer for storage and further analysis.

To open the Transmit Measurements screen, proceed as follows:

1. From the Dashboard, select **Routes**.
2. Select **Transmit Measurements**.
3. The Transmit Measurements screen appears as shown in <FigureRef id="Transmit-Measurements-Screen" />.

####  Transmit Measurements screen 
The following  fields and controls available on the Transmit Measurements screen as shown in the <FigureRef id="Transmit-Measurements-Screen" />.

| Navigation Button               | Functionality                                                                    |
|-------------------------------- |--------------------------------------------------------------------------------- |
| Options                         | Displays the current transmission configuration.                                 |
| Connection                      | Displays the configured connection source. <br />**Example:** ITR.com            |
| Data not previously transmitted | Indicates whether the listed data has not yet been sent. <br />**Example:** True |
| Selected                        | Indicates whether a route is selected for transmission.                          |
| Id                              | Displays the route ID.                                                           |
| Route                           | Displays the route name.                                                         |
| Meas                            | Displays the number of measurements recorded on the route.                       |
| Select All                      | Selects all available routes in the list.                                        |
| Select                          | Selects the highlighted route.                                                   |
| Transmit                        | Starts sending the selected measurement data to the configured connection.       | 
| More / Less                     | Expands or collapses the left panel to show or hide the **Options** button.      |

#### Transmit measurement data

To transmit measurement data, proceed as follows:

1. On the Transmit Measurements screen, select the required route from the list, or select **Select All** to select every route.
2. Select **Transmit**.<br />
    a. If no route is selected when **Transmit** is selected, the following dialog appears: **You must select at &nbsp; &nbsp; &nbsp; 
        least one route**. Select **Close** to dismiss the dialog, then select a route before trying again as shown &nbsp; &nbsp; 
        in the <FigureRef id="Transmit-Measurements-Error-Dialog" />

        <FigureProvider>
            <Figure
                id="Transmit-Measurements-Error-Dialog"

                srcDark="/img/2-Measurements/1-TransmitMeasurements/Transmit-Measurements-Error-Dialog-Dark.jpg"
                caption="Transmit Measurements error dialog"

        You must select at least one route.

    b. If a route is selected, the DCU transmits the route data to the configured connection. <br />
    c. Once transmission completes, the system returns to the start of the ITR.

#### Options 
Use the **Options function** to configure the connection type and transmission settings before sending measurement data.
To open the Options screen, proceed as follows:

1. On the Transmit Measurements screen, select **More**, then select **Options**. 
2. The Options screen appears as shown in <FigureRef id="Transmit-Data-Options-Screen" />

#### Options screen Detail
The following fields and controls available on the Options screen.

| Fields/Control                  | Description                                                                                                               |
|-------------------------------- |-------------------------------------------------------------------------------------------------------------------------- |
| Connection 	    	          | Selects the connection type. Available options: USB Drive, USB Drive - Data from backup, ITR.com, ITR.com via CMAS, CMAS. |         
| Data not previously transmitted | Enable to limit transmission to data that has not been previously sent.                                                   |
| Measurements Only		          | Enable to transmit measurement data only, excluding other route information.                                              |
| High speed transmission         | Enable to use a high-speed transmission mode.                                                                             |
| Save                            | Saves the configured options and returns to the Transmit Measurements screen.                                             |
| Cancel                          | Closes the Options screen without saving changes.                                                                         |

#### Options screen Configuration
1. Select the required **Connection** type.
2. Enable or disable **Data not previously transmitted, Measurements Only**, and **High speed transmission** as required.
3. Select **Save**.
