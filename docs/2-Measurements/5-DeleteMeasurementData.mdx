# Delete Measurement Data

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Delete Measurement Data** option allows the user to remove recorded measurement data from the device when it is
no longer required or needs to be cleared.

**Procedure:**

1. Select Measurements from the Dashboard.
2. Select the Delete Measurement Data option from the measurement menu.
3. The Select Route screen will appear.
4. Select the required measurement as shown in <FigureRef id="" />
5. Click the Delete measurement option.

After selecting the route, a confirmation message will appear. (See <FigureRef id="" />)
6. Tap Yes to delete the measurement data, or tap No to cancel the operation.

## Screen Description (Delete Measurement Data)

| Navigation Button       | Functionality                                          |                                                                                                                                          
| :---------------------- | :----------------------------------------------------- |
| Route List              | Displays available routes containing measurement data. |
| Confirmation Dialog box | Asks for confirmation before deleting data.            |

:::note 

Deleted measurement data cannot be recovered. Ensure the data is transmitted or backed up before deleting.

:::
