# Delete Measurement Data

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Delete Measurements function** to permanently remove recorded measurement data for one or more routes from the device.

To open the Delete Measurements screen, proceed as follows:

1. From the Dashboard, select **Routes**.
2. Select **Delete Measurements**.
3. The Delete Measurements screen appears, listing all routes stored on the device  same as shown in <FigureRef id="Delete-Measurements-Screen" />.

#### Delete Measurements screen fields 
The following fields and controls are available in this screen. 

| Fields/Button       | Description                                                |                                                           
|-------------------- |----------------------------------------------------------- |
| Selected            | Checkbox to mark a route for deletion.                     |
| Id                  | Displays the account ID associated with the route.         |
| Route               | Displays the route name.                                   |
| # Meas              | Displays the number of measurements recorded on the route. |
| Select All          | Selects every route in the list.                           |
| Select              | Selects the highlighted route.                             |
| Delete Measurements | Deletes measurement data for the selected route(s).        |

#### Delete measurement data 
To delete measurement data, proceed as follows:

1. On the Delete Measurements screen, select the checkbox next to the required route(s), or select **Select All** to select every route.
2. Select **Delete Measurements**. <br />
    a. If no route is selected, the following dialog appears: **Select Routes to delete measurements**. <br />
    b. Select **Close** to dismiss the dialog, then select at least one route before trying again, same as shown
    &nbsp; &nbsp; in <FigureRef id="Select-Routes-to-Delete-Measurements-Dialog" />.

:::warning

    Select Routes to delete measurements.

:::

:::warning

    Deleted measurement data cannot be recovered. Ensure the data has been transmitted or backed up before deleting. 

:::
