# Display Trouble Code

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Display Trouble Code** option allows the user to view the trouble codes generated during the measurement process.
These codes help identify machine faults or abnormal conditions detected during data collection.

**Procedure:**

1. Select Measurements from the dashboard.
2. Click on **Display Trouble Code**.
3. The **Select Route screen** will appear showing the list of available routes as shown in <FigureRef id="" />
4. Select the required route.
5. Click **Select**.

## Screen Description (Display Trouble Code)

| Navigation Button | Functionality                                                              |                                                                                                                                          
| :---------------- | :------------------------------------------------------------------------- |
| ID                |  Displays the trouble code identification number.                          | 
| Type              | Shows the type or category of the detected issue.                          | 
| Date              | Displays the date when the trouble code was recorded.                      | 
| Tech Name         | Shows the technician name associated with the measurement.                 |
| Memo              | Allows viewing or entering additional remarks related to the trouble code. |
| Delete            | Removes the selected trouble code entry.                                   |

:::info

If no trouble cod R.es are available for the selected route, the system may display an empty screen.

:::
