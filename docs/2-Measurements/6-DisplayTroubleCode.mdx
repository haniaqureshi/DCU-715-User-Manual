# Display Trouble Code

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Display Trouble Code** function to view the trouble codes generated during the measurement process. Trouble codes help identify machine faults or abnormal operating conditions detected during data collection. 

To open the **Display Trouble Code** screen, proceed as follows:

1. From the **Dashboard**, select **Measurements**.
2. Select **Display Trouble Code**.
3. The **Select Route** screen appears, listing all available routes stored on the device, as shown in <FigureRef id="Display-Trouble-Code-Route-Selection-Screen" />.
4. Select the required route.
5. Select **Select**.

#### Display Trouble Code screen fields
The following fields and controls are available on this screen.

| Fields/Button | Description                                                                 |                                                           
|-------------- |---------------------------------------------------------------------------- |
| ID            | Displays the unique identification number of the trouble code.              |
| Code          | Displays the trouble code assigned to the detected fault.                   |
| Description   | Displays a brief description of the detected fault or abnormal condition.   |
| Type          | Displays the type or category of the trouble code.                          |
| Date          | Displays the date on which the trouble code was recorded.                   |
| Tech. Name    | Displays the name of the technician associated with the measurement.        |
| Memo          | Displays or allows entry of additional notes for the selected trouble code. | 
| Delete        | Deletes the selected trouble code.                                          |
| Up            | Scrolls up through the list of trouble codes.                               | 
| Down          | Scrolls down through the list of trouble code                               |
| Back          | Returns to the previous screen.                                             |

:::note

If no trouble codes are available for the selected route, the **Display Trouble Code** screen is displayed without 
any records. 

:::

#### Delete a Trouble Code
To delete a trouble code, proceed as follows:

1. On the **Display Trouble Code** screen, select the required trouble code from the list.
2. Select **Delete**.
3. The following confirmation dialog appears: **Do you want to delete the selected records?** as shown in <FigureRef id="" />. <br />
    a. Select **Yes** to permanently delete the selected trouble code. <br />
    b. Select **No** to cancel the operation.
