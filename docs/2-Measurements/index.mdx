# Measurements

The **Measurements** module allows the user to perform, review, manage, and transmit measurement data collected from 
the selected routes and machines. This screen provides multiple options for handling measurement activities and 
reports.

To open the Measurements submenu, proceed as follows:

1. From the Main Menu, select **Measurements**.
2. The Measurements submenu appears as shown in <FigureRef id="Measurements-Submenu" />.
