# Not-Measured Machines Report

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Not-Measured Machines** Report function to view the list of machines for which measurement data has not been 
recorded on the selected route. This helps ensure that all required machines are measured before the route is 
considered complete.
To open the Not-Measured Machines Report, proceed as follows:

1. From the Dashboard, select **Measurements**.
2. Select **Not-Measured Machines Report**.
3. The Select Route screen appears as shown in <FigureRef id="Machines-Not-Measured-Select-Route-Screen" />.

#### Select a route
To select a route, proceed as follows:

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. Select **Select**. The Machines Not Measured screen appears.

:::info

If all machines on the route have recorded measurements, the **Machines Not Measured** list appears empty.

:::

#### Machines Not Measured screen
After selecting a route, the Machines Not Measured screen appears, listing the machines on the route that do not
yet have recorded measurement data. The task status bar displays **Getting data** while the list loads.

#### Machines Not Measured Screen Details
The following controls and fields are available in this screen are shown in <FigureRef id="Machines-Not-Measured-Screen" />.

| Fields/Button               | Description                                                                    |                                                           
|---------------------------- |------------------------------------------------------------------------------- |
| Machine                     | Displays the details of the currently highlighted machine.                     |
| Name                        | Displays the area and machine name. <br />**Example**: MILL DRIVES, UNCOILER   |
| Reason                      | Displays the reason the machine has not been measured, if recorded.            |
| Last measured               | Displays the date the machine was last measured. <br />**Example**: 10/10/2023 |
| Id                          | Displays the machine ID.                                                       |
| No                          | Displays the row number in the list.                                           |
| Name (list column)          | Displays the area and machine name for each entry.                             |
| Last measured (list column) | Displays the date each machine was last measured.                              | 
| Reason (list column)        | Displays the reason each machine has not been measured, if recorded.           |
| Save Copy to USB            | Copies the not-measured machines report to a connected USB device.             |

#### Export the report to USB
To export the Not-Measured Machines report to USB, proceed as follows:

1. On the Machines Not Measured screen, select the required machine from the list, if needed.
2. Select **Save Copy to USB**.<br />
    a. If no USB device is connected, the following dialog appears: USB Stick not found. Select **Close** to dismiss
    the dialog, connect a USB device, then select **Save Copy to USB** again.<br />
    b. Once a USB device is connected, the system copies the report data to the USB device.
