# Display Measurements

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Display Measurements** option allows the user to view the recorded measurement data for a selected route, area, and machine. This option helps the user review previously captured measurement results.
When the user taps **Display Measurements** from the Measurements screen, the **Select Route** screen will appear, as shown in <FigureRef id="" />

**Procedure:**
1. From the Dashboard, tap Measurements.
2. Tap Display Measurements from the measurement menu.
3. The **Select Route screen** will appear showing the list of available routes.
4. Select the required route from the list.
5. Tap **Select**.

## Screen Description (Display Measurement):
- **Select Route Screen:**
- Select to:
    <ul><li> Displays the list of routes along with measurement count and date.</li>
    <li> Shows transmission status and recorded measurement information.</li></ul>
- **Area in Route Screen:** Displays all areas available within the selected route.
- **Machine in Area Screen:** Displays the list of machines available in the selected area.
- **Next:** Click the Next button, the graph for the next measurement point will be displayed.
- **Preview:** Click the Previous button, you can view the measurements of the previous page.

:::info

Only those routes, areas, and machines that contain recorded measurements will display measurement details.

:::
