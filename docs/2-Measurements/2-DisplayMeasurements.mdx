# Display Measurements
Use the **Display Measurements function** to review previously recorded measurement data for a selected route, area, and machine.

To open the Display Measurements screen, proceed as follows:

1. From the Dashboard, select **Measurements**.
2. Select **Display Measurements**.
3. The Select Route screen appears.

#### Select Route screen Details
The following fields and controls are available in the screen are shown in the <FigureRef id="Display-Measurements-Select-Route-Screen" />.

| Fields/Control   | Description                                                       |                                                           
|----------------- |------------------------------------------------------------------ |
| Meas             | Displays the number of measurements recorded on the route.        |
| Trans Date       | Displays the date the route data was last transmitted.            |
| Trans            | Displays the number of transmissions logged for the route.        |
| RDate            | Displays the route creation/assignment date.                      | 
| CVAAcct          | Displays the account number associated with the route.            |
| Job              | Displays the job reference number.                                |
| Route            | Displays the route name.                                          |
| Measurement Date | Displays the date of the last recorded measurement.               |
| # Meas           | Displays the number of measurements recorded.                     |
| WSN              | Indicates whether a wireless sensor is associated with the route. |
| Select           | Confirms the highlighted route.                                   | 

#### Select a route
To select a route, proceed as follow:

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. Select **Select**. The Areas in Route dialog appears.

#### Areas in Route
After selecting a route, the Areas in Route screen appears, listing the areas contained within the route.

The Following fields and controls are available in this screen as shown in the <FigureRef id="Areas-In-Route-Screen"/>.

| Fields/Buttons   | Description                                                          |                                                            
|----------------- |--------------------------------------------------------------------- |
| Area list        | Displays each area name and its associated ID.                       |

To select an area, proceed as follows:

1. On the Areas in Route dialog, select the desired area from the list.
2. Select **Select**. The Machines in Area dialog appears Showing the data of selected route and area.

1. On the Machines in Area dialog, select the desired machine from the list.
2. Select **Select**. The Display Measurements screen appears, showing data for the selected route, area, and machine.

#### Display Measurements screen 
After selecting a machine, the Display Measurements screen appears where at the top of the screen shows the selected
route, area, and machine (e.g., TEST #2 (1289) > MILL DRIVES > MAIN MILL DRIVE).

#### Display Measurements screen Detail
The following fields and controls are available in this screen are shown in <FigureRef id="Display-Measurements-Screen"/>.

| Fields/Control   | Description                                                                                            |                                                            
|----------------- |------------------------------------------------------------------------------------------------------- |
| Options          | Displays the details of the currently selected measurement.                                            |
| Measurement      | Displays the measurement ID and the date/time it was recorded.                                         |
| Trouble code     | Displays the trouble code associated with the measurement, if any. <br />**Example:** 100 Hz vibration |
| Areas / Machines | Returns to the Areas in Route dialog to select a different area or machine.                            |
| Previous         | Displays the previous measurement point.                                                               |
| Next             | Displays the next measurement point.                                                                   |
| More / Less      | Expands or collapses the right panel to show additional controls.                                      |

:::info

Only those routes, areas, and machines that contain recorded measurements will display measurement details. 

:::

### Additional Configuration Controls
#### More
Use the **More** button to expand the right panel and access additional controls: **Options, Reset**, and **Compare measurements**.

To access these controls, proceed as follows:

1. On the Display Measurements screen, select **More**. 
2. The panel expands to display Options, Reset, and Compare measurements as shown in <FigureRef id="Display-Measurements-Screen-More-Expanded"/>
    <FigureProvider>
        <Figure
            id="Display-Measurements-Screen-More-Expanded"
            src="/img/2-Measurements/2-DisplayMeasurements/Display-Measurements-Screen-More-Expanded-Light.jpg"
            caption="Display Measurements screen (More expanded)"
            width="70%"
        />
    </FigureProvider>
3. Select **Less** to collapse the panel and return to the standard Display Measurements screen view.

#### Options (Measure Point) 
Use the **Options function** to select a specific measurement point and axis to display.

To select a measurement point, proceed as follows:

1. On the Display Measurements screen, select **More**, then select **Options**. 
2. The Measure Point screen appears as shown in <FigureRef id="Measure-Point-Screen" />.
    <FigureProvider>
        <Figure
            id="Measure-Point-Screen"
            src="/img/2-Measurements/2-DisplayMeasurements/Measure-Point-Screen-Light.jpg"
            caption="Measure Point screen"
            width="70%"
        />
    </FigureProvider>

    #### Option screen Details
    The Following controls are available in the screen as shown in the <FigureRef id="Measure-Point-Screen"/>.

    | Fields/Control   | Description                                                                                      |                                                            
    |----------------- |------------------------------------------------------------------------------------------------- |
    | CVAAcct          | Displays the account number associated with each recorded measurement.                           |
    | Measurement Date | Displays the date and time each measurement was recorded.                                        |
    | RMS              | Displays the Root Mean Square vibration level recorded for each axis.                            |
    | X / Y / Z        | Selects the axis to display on the Display Measurements screen.                                  |
    | Save             | Applies the selected measurement point and axis, and returns to the Display Measurements screen. |
    | Cancel           | Closes the screen without applying changes.                                                      |

3. Select the required measurement row from the list.
4. Select the required axis: X, Y, or Z.
5. Select Save.

#### Compare measurements 
Use the **Compare measurements function** to view a side-by-side comparison of recorded measurement values for the selected machine.

To compare measurements, proceed as follows:
1. On the Display Measurements screen, select **More**, then select **Compare measurements**.
2. The Comparison of measurements dialog appears, showing the selected route, area, and machine path (e.g., NUCOR HICKMAN > MILL DRIVES > MAIN MILL DRIVE). See <FigureRef id="Comparison-of-Measurements-Dialog"/>
    <FigureProvider>
        <Figure
            id="Comparison-of-Measurements-Dialog"
            src="/img/2-Measurements/2-DisplayMeasurements/Comparison-of-Measurements-Dialog-Light.jpg"
            caption="Comparison of measurements dialog"
            width="70%"
        />
    </FigureProvider>  

    #### Comparison of Measurements Screen Detail
    | Fields/Control           | Description                                                                         |                                                            
    |------------------------- |------------------------------------------------------------------------------------ |
    | RMS X / RMS Y / RMS Z    | Displays the Root Mean Square vibration level for each axis.                        |
    | X % / Y % / Z %          | Displays the percentage change in RMS value for each axis compared to the baseline. |
    | Peak X / Peak Y / Peak Z | Displays the peak vibration level for each axis.                                    | 
    | Time                     | Displays the date and time of each recorded measurement.                            |
    | Cancel                   | Closes the dialog.                                                                  |

3. Review the listed measurements for the selected machine.
4. Select Cancel to close the dialog and return to the Display Measurements screen.
5. The task status bar displays **Processing...** while the Display Measurements screen reloads. See <FigureRef id="Display-Measurement-Screen-Comparison-Measurement"/>
    <FigureProvider>
        <Figure
            id="Display-Measurement-Screen-Comparison-Measurement"
            src="/img/2-Measurements/2-DisplayMeasurements/Display-Measurement-Screen-Comparison-Measurement-Light.jpg"
            caption="Display Measurement Screen (Comparison Measurement)"
            width="70%"
        />
    </FigureProvider> 

:::info

The status bar displays **Processing...** while the selected measurement is loading. 

:::

#### Reset 
Select **Reset** to restore the Display Measurements screen to its default view.
