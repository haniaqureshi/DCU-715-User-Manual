# Customer Signature

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Customer Signature** option allows the user to capture the customer’s signature after completing the measurement process. This feature is used for verification and documentation purposes.

**Procedure:**
1. Select Measurements from the Dashboard.
2. Click on **Customer Signature** from the measurement menu.
3. The Select Route screen will appear as shown in <FigureRef id="" />.
4. Select the required route.
5. Tap **Select**.

6. After selecting the route, the **Signature** screen will open.
7. Select the appropriate result option:<br />
    a. We were not able to measure every machine during this visit, or<br />
    b. We were able to measure all the machines.
8. After selecting the result, go to the **Signature** area and add the customer’s signature (see <FigureRef id="" />).
9. Capturing the signature, proceed as required.
10. Add the  required signature and click the **Select Recipients** option.

### Select Recipients
The Select Recipients option allows the user to add, edit, or select recipients who will receive the measurement report via email.

**Procedure**<br />
1. Select Recipients from the Customer Signature screen.
2. The Select Recipients window will appear (See <FigureRef id="" />).<br />

**To add a new recipient:**

1. Select New Recipient.
2. Enter the Recipient Name and Email Address.
3. Click Save Recipient to save new recipient data.<br />

**To select recipients from the list:**

1. Choose the required recipient(s).
2. Select to confirm.
3. To select all recipients, tap Select All.

### Clear Signature
Click the **Clear Signature** option on the Results screen. This option removes the existing signature or clears the previously captured signature.

### Memo Section
The Memo field allows the user to enter additional remarks or notes related to the visit or measurement process. See <FigureRef id="" />

**Procedure:**
1. Tap inside the **Memo** text box.
2. Enter the required notes using the on-screen keyboard.
3. To remove the entered text, click **Clear Memo**.

### Screen Description (Customer Signature)

<ul><li>**Signature Area:** The area where the customer can draw their signature.</li>
<li>**Memo Area:** The area where the user can enter additional remarks or notes related to the visit or measurement.</li>
<li>**Save Option:** Stores the captured signature.</li>
<li>**Clear Option:** Removes the signature if the user wants to sign again.</li></ul>
