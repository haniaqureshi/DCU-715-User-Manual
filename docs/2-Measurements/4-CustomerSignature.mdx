# Customer Signature

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the Customer Signature function to record the visit results, capture the customer's signature, and email the 
measurement report to selected recipients after completing the measurement process.

To open the Customer Signature screen, proceed as follows:

1. From the Dashboard, select **Measurements**.
2. Select **Customer Signature**.
3. The Select Route screen appears as shown in <FigureRef id="Customer-Signature-Select-Route-Screen" />

#### Record the visit and capture a signature
To complete the **Customer Signature** screen, proceed as follows:

1. Select the required **Results** option.
2. In the **Signature** area, have the customer draw their signature.
3. Enter the customer's name in the **Customer** field.
4. Enter any additional notes in the **Memo** field, if required.
5. Click on the **Select Recipients** option to choose who will receive the report by email.
6. Select **Submit**. <br />

    a. If no recipients have been selected, the following dialog appears: **Recipients must be selected**. <br /> 
    b. Select **Close** to dismiss the dialog, then select recipients before submitting again.

:::note

#### Select Recipients
Use the Select Recipients screen to add, edit, delete, or select the recipients who will receive the measurement 
report by email.

To open the Select Recipients screen, proceed as follows:
1. On the Customer Signature screen, select **Select Recipients**. The Select Recipients screen appears.

<FigureProvider>
    <Figure
        id="Select-Recipients-Screen"
        src="/img/2-Measurements/4-CustomerSignature/SelectRecipientsScreen-Light.jpg"
        caption="Select Recipients screen"
        width="70%"
    />
</FigureProvider>

**If the recipient has already been created, select the recipient from the list.**

#### Select Recipients screen fields
The following fields and controls are available. 

| Fields/Button    | Description                                                                       |                                                           
|----------------- |---------------------------------------------------------------------------------- |
| Recipient Name   | Enter or edit the recipient's name.                                               |
| Email            | Enter or edit the recipient's email address.                                      |  
| Recipients list  | Displays each saved recipient's selection status and name/email.                  |
| Save Recipient   | Saves the entered recipient name and email address.                               |
| Select All       | Selects all recipients in the list.                                               |
| New Recipient    | Clears the Recipient Name and Email fields to enter a new recipient.              |
| Clear            | Clears the Recipient Name and Email fields.                                       |
| Edit Recipient   | Enables editing of the selected recipient's details.                              | 
| Delete Recipient | Deletes the selected recipient.                                                   |
| Cancel           | Discards unsaved changes to the recipient fields.                                 |
| Close            | Closes the Select Recipients screen and returns to the Customer Signature screen. |

#### Select recipients

1. In the Recipients list, select the checkbox to select the required recipient(s), or select **Select All** to select every recipient.
2. Select **Close** to confirm and return to the Customer Signature screen.

#### Add a new recipient
1. Select **New Recipient**.
2. Enter the **Recipient Name** and **Email**.
3. Select **Save Recipient**. See <FigureRef id="Add-New-Recipients-Screen" />

#### Not Measured Machines  (Access form the Customer Signature Screen)
Use the **Not Measured Machines** screen, accessed from the Customer Signature screen, to review machines that were
not measured and prepare a report for the current route. 

To open this screen, proceed as follows:

1. On the Customer Signature screen, select **Not Measured Machines**.
2. A confirmation dialog box opens to inform you that: **The report file has been prepared** as shown in <FigureRef id="" />.

#### Browse Email
Use the Browse Emails screen to view details of previously sent customer signature reports, including the recipient's signature and email details, without selecting a route.

To open the Browse Emails screen, proceed as follows:

1. On the Customer Signature Select Route screen, select **Browse Emails**.
2. The Browse Emails screen appears as shown in <FigureRef id="" />.

#### Browse Emails screen fields 
The following fields and controls available in <FigureRef id="Browse-Emails-Screen" /> are mentioned below.

| Fields/Button  | Description                                                             |                                                           
|--------------- |------------------------------------------------------------------------ |
| Email details  | Displays the details of the currently selected sent report.             |
| Signature      | Displays the captured customer signature for the selected report.       |
| Id             | Displays the report ID.                                                 |  
| Route          | Displays the route name associated with the report.                     | 
| Tech. name     | Displays the name of the technician who submitted the report.           |
| Signer name    | Displays the name of the customer who signed the report.                |
| Date           | Displays the date the report was submitted.                             | 
| Report         | Opens the full report for the selected entry.                           |
| Cancel         | Closes the Browse Emails screen and returns to the Select Route screen. |

To review a sent report, proceed as follows:

1. On the Browse Emails screen, select the desired entry from the list.
2. Review the **Email details** and **Signature** shown for the entry.
3. Select **Report** to open the full report.
4. Select **Cancel** to return to the Select Route screen.
