## DCU Setup

While working in **DCU Setup**, the user might come across errors while performing certain actions. In this section,

### Error: The update file could not be downloaded from the CMAS server 
This error may appear while upgrading the DCU software using the ITR.com via CMAS option.

:::note

CMAS is another ITR system that can exchange data with the DCU. The CMAS system uses OPC for communication.

:::

        caption="CMAS update download error" 
        width="70%"

#### Root Cause
The DCU cannot download the update file from the CMAS server. This may happen if the DCU cannot reach the CMAS 
server, the network connection is unavailable or unstable, the CMAS server is not responding, or the update file
is not available from the selected source.

#### Possible Troubleshooting Steps

1. Check the network connection:<br />
    a. Confirm that the DCU has an active internet connection.<br />
    b. Run **Internet Test** from the **Maintenance** submenu to verify connectivity.<br />
2. Check CMAS availability:<br />
    a. Confirm that the CMAS server is online and reachable from the DCU network.<br />
    b. If the server is unavailable, wait until the connection is restored and try the upgrade again.<br />
3. Review the log file:<br />
    a. Check the DCU log for more information about the failed download.<br />
    b. **Action Required:** Resolve the issue shown in the log, and then run the software upgrade again.
4. Contact support:
    a. If the error continues after completing the checks above, contact the system administrator or ITR support.

### Error: The touch screen has not been tested properly
This error may appear when the user exits the **Touchscreen Test** screen without testing the touchscreen.

<FigureProvider>
    <Figure 
        id="Touchscreen-Test-Warning-Dialog-Box" 
        src="/img/4-DCUSetup/4-AdvanceSettings/12-TroubleShooting/                    -Light.png"
        srcDark="/img/4-DCUSetup/4-AdvanceSettings/12-TroubleShooting/                -Dark.png" 
        caption="Touchscreen test warning dialog box " 
        width="70%"
    />
</FigureProvider>

#### Root Cause 
The DCU did not detect touch input before the user exited the **Touchscreen Test** screen. This can happen if the 
user selects **Close** without touching, tapping, or swiping across the touchscreen.

#### Possible Troubleshooting Steps
1. **Run the touchscreen test again:**<br />
    a. Return to **DCU Setup > Maintenance**.<br />
    b. Select **Touchscreen Test.**<br />
2. **Test the touchscreen before exiting:**<br />
    a. Touch, tap, or swipe different areas of the touchscreen with your finger.<br />
    b. Test the center, corners, and edges of the display.<br />
3. **Exit the test correctly:**<br />
    a. Double-tap the **Double tap to exit** box.<br />
    b. Confirm that the message **The touch screen is working properly** appears.<br />
4. **Repeat the test if required:**<br />
    a. If the warning appears again, repeat the test and make sure the screen shows touch paths before exiting.

#### Action Required
If the touchscreen does not detect finger input after repeated attempts, contact the system administrator or ITR support.

### Error: No signal
This error may appear when the DCU cannot detect a valid tachometer signal during the Tachometer Test.

<FigureProvider>
    <Figure 
        id="Tachometer-Test-No-Signal-Condition" 
        src="/img/4-DCUSetup/4-AdvanceSettings/12-TroubleShooting/                    -Light.png"
        srcDark="/img/4-DCUSetup/4-AdvanceSettings/12-TroubleShooting/                -Dark.png" 
        caption="Tachometer Test No signal condition" 
        width="70%"
    />
</FigureProvider>

#### Root Cause
The DCU is not receiving a valid pulse signal from the tachometer sensor. This can occur when the sensor is 
disconnected, improperly positioned, connected to the wrong input, or when the monitored equipment is not 
generating a detectable speed signal.

#### Possible Troubleshooting Steps
1. **Verify the tachometer sensor connection:**<br />
    <ul><li>Confirm that the tachometer sensor is securely connected to the DCU.</li>
    <li>Check that the connector is fully seated.</li></ul>
2. **Inspect the sensor cable:**<br />
    <ul><li>Examine the cable for cuts, bends, loose connections, or other visible damage.</li>
    <li>Replace the cable if damage is suspected.</li></ul>
3. **Verify sensor positioning:**<br />
    <ul><li>Ensure that the tachometer sensor is correctly aligned with the target.</li>
    <li>Confirm that the sensor is within the recommended operating distance.</li></ul>
4. **Verify equipment operation:**<br />
    <ul><li>Confirm that the monitored equipment is running.</li>
    <li>Ensure that the rotating component is producing a measurable speed signal.</li></ul>
5. **Check the selected measurement unit:**<br />
    <ul><li>Switch between **Hertz** and **CPM (Cycles Per Minute)** if necessary.</li>
    <li>Verify that the signal is still not detected.</li></ul>
6. **Repeat the tachometer test:**<br />
    <ul><li>Close the Tachometer Test modal.</li>
    <li>Reopen **DCU Setup > Diagnostics > Tachometer Tests.**</li>
    <li>Allow the DCU 1 to 2 seconds to stabilize the measurement.</li></ul>

#### Action Required:
If the No signal condition remains after verifying the sensor connection, cable condition, sensor positioning, 
and equipment operation, contact the system administrator or ITR support for further assistance.
