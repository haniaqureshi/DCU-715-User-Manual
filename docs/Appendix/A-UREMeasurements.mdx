# URE Measurements

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Ultrasonic Resonance Excitation (URE) analysis utilizes the natural frequency of an accelerometer to detect 
impulsive behavior on an asset. Commonly used in slow speed applications, this technique extends fault detectability
by pairing specialized hardware with advanced data enveloping techniques. There are two types of URE measurements:

1. Enriched URE measurements
2. Routine URE measurements

Both measurement types are described in detail below.

:::note

Since these measurements are primarily designed to be used on slow speed equipment, this technique may require
extended acquisition times relative to standard vibration measurements.

:::

## Enriched URE Measurements
The Enriched URE Measurement retains the full, high-sample rate dataset, providing a detailed and comprehensive
view of the asset's status. This high-resolution measurement is ideal for in-depth analysis, allowing for the 
application of additional checks and algorithms to detect and diagnose specific faults with greater accuracy. 
Current implementation of this technique requires the use of the Extended Time Domain Measurement Routine, using 
the ultrasonic port. Please see that section for further information. 

## Routine URE Measurements
The URE Monitoring Measurement is a streamlined and compressed version of the Enriched URE Measurement. Designed
for efficient monitoring and trend analysis of slow speed equipment, it offers a lower resolution that is 
sufficient for general performance tracking. However, due to its compressed nature, it may not capture the finer 
details necessary for identifying specific faults. 

## Routine URE Workflow
During a Routine URE measurement, the DCU follows the standard route-based measurement sequence with modified
acquisition parameters.

1. **Sensor Setup**<br />
    <ul>
        <li>URE measurements must be taken using specialized accelerometers. DCU will prompt the user to ensure the
        correct accelerometer is connected.</li>
    </ul>
