# Special Tests Troubleshooting

While running diagnostic tests within the [**Special Tests**](../../3-SpecialTests/index.mdx) module, users may encounter validation warnings related to outdated route data or missing
machine information. This section details the error screens, their root causes, and specific steps to resolve them.

## Error: Route Configuration is More Than Two Weeks Old
This warning dialog appears on the **Bump Test – Select Route** screen when the user selects a route that has not been
updated for more than two weeks before starting a **Bump Test**.

<FigureProvider>
    <Figure 
        id="Bump-Test-(Route-Age-Warning-Dialog)" 
        src="../../img/Appendix/B-Troubleshooting/3-SpecialTests/Bump-Test-(Route-Age-Warning-Dialog)-Light.jpg"
        caption="Bump Test (Route Age Warning Dialog)" 
        width="50%"
    />
</FigureProvider>

### Root Cause
The selected route has not been synchronized with the DCMS server for more than 14 days. As a result, the route may
not contain the latest machine information, updated measurement points, or current test parameters required for the
Bump Test.

### Possible Troubleshooting Steps
- Select **Yes** to exit the current screen and download the latest route from the server (recommended).
- Ensure the DCU is connected to the network before updating the route.
- After updating the route, reopen the **Bump Test** module and select the updated route.
- If an updated route is not available and you are certain that no changes have been made to the route configuration,
    select **No** to continue using the existing route.

This version matches the style and level of detail used in your Chapter 3 troubleshooting section while referring
specifically to the **Bump Test** module.

## Error: Machine Description Required
This warning dialog appears on the **Balancing Program – Select Machine** screen when the user attempts to start a
balancing operation without creating or selecting a machine description.

<FigureProvider>
    <Figure 
        id="Balancing-Program-(Machine-Description-Warning-Dialog)" 
        src="../../img/Appendix/B-Troubleshooting/3-SpecialTests/Balancing-Program-(Machine-Description-Warning-Dialog)-Light.jpg"
        caption="Balancing Program (Machine Description Warning Dialog)" 
        width="70%"
    />
</FigureProvider>

### Root Cause
The balancing program requires a machine description before a balancing procedure can begin. No machine information
has been created or selected for the current balancing job.

### Possible Troubleshooting Steps
- Select **Close** to dismiss the warning dialog.
- Select **Add Machine** from the right-side menu.
- Enter the required machine information, such as machine name, rotor weight, rotor radius, operating speed, and other applicable parameters.
- Save the machine description.
- Select the newly created machine and start the balancing procedure again.
