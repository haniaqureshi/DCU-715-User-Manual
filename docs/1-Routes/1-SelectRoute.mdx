# Select Routes
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Select Route** option allows the user to choose a measurement route for data collection.
Once you select this option the system will display all routes that are currently available on the device. These 
routes are typically downloaded by technicians from the DCU and stored locally after synchronization with the server.

**Key-Points:**

<ul><li>The route list is fetched from the database (SQL Server).</li>
<li>Only downloaded and available routes are displayed.</li>
<li>Routes are used to perform measurements on industrial equipment through the ITR system.</li></ul>

**Procedure For Access the Select Route Module:**

1. From the **Routes** menu, click **Select Route**.
2. The list of available routes will appear.
3. Select the required route.
4. Click on **Select** to load the route.

## Measure Data 
If you want to measure the data, you can click on the **Measure Data** option from the right-side menu of the **Select 
Route** screen. 

**Procedure:**	

1. Select any route from the list and click on the **Measure Data** option.
2. The **Transmit Measurements** screen will open, displaying the available routes as shown in <FigureRef id="Measurement-Data-Screen" />.
3. Choose the desired routes by checking the box in the **Selected** column and click the **Transmit** option.
4. After clicking this option, the route data will be transmitted, and the system will redirect you to the main screen.

### Adjust Backlight 
The **Adjust Backlight Settings**s feature allows operators to adjust the hardware screen brightness and toggle the
system visual theme. This is used to optimize screen visibility and conserve battery life when working in different
plant lighting environments, such as low-light areas or bright outdoor conditions.

**Procedure:**

1. Access **Measure Data > More > Adjust Backlight**.
2. The **Display settings** window will open as shown in <FigureRef id="Adjust-Blacklight" />
3. **To adjust screen brightness:**
<ul><li>Tap and drag the vertical **Backlight slider** up or down to manually change the brightness levels.</li>
<li>Alternatively, click the **Plus (+)** button to increase screen brightness or the **Minus (-)** button to decrease it.</li></ul>

4. **To change the interface appearance:**<br />

### Clean Screen
The **Clean Screen** feature is used to temporarily lock the user interface layout so the physical touchscreen hardware

### Turn Off Screen
The **Turn Off** Screen feature allows operators to temporarily put the display into a power-saving mode without
shutting down the entire system or losing data within the active measurement route. This is used to save battery
life during breaks or while moving between distant machine test locations.

**Procedure:**
1. Access **Measure Data > More > Turn Off Screen**.
2. The screen will instantly dim, and a single **Turn On** button will appear at the bottom right corner of the interface as shown in <FigureRef id="Turn-Off-Screen" />.
3. Shortly after, the rest of the display surface will turn black to conserve the unit's battery power.
4. The device remains fully operational in the background, keeping your current data selection intact.
5. To reactivate the device display, tap the highlighted **Turn On** button on the bottom right of the panel.
6. The interface screen color will restore instantly, returning you directly to your active measurement layout.
