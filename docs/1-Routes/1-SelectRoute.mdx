# Select Routes
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Select Route** option allows the user to choose a measurement route for data collection.
Once you select this option the system will display all routes that are currently available on the device. These 
routes are typically downloaded by technicians from the DCU and stored locally after synchronization with the server.

**Key-Points:**

<ul><li>The route list is fetched from the database (SQL Server).</li>
<li>Only downloaded and available routes are displayed.</li>
<li>Routes are used to perform measurements on industrial equipment through the ITR system.</li></ul>

**Procedure For Access the Select Route Module:**

1. From the **Routes** menu, click **Select Route**.
2. The list of available routes will appear.
3. Select the required route.
4. Click on **Select** to load the route.

## Measure Data 
If you want to measure the data, you can click on the **Measure Data** option from the right-side menu of the **Select 
Route** screen. 

**Procedure:**

2. The **Transmit Measurements** screen will open, displaying the available routes as shown in Figure-2.2.3.

## More (Displayed When "Area/Machine" is Selected)

this screen, tap the More  button from the measurement screen. The More Screen is shown in <FigureRef id="More-Screen" />

The following options are available:
<ul><li>**Plot** – Displays the measurement data in graphical form for analysis.</li> 
<li>**Add Point** – Adds a new measurement point to the route.</li>
<li>**Enter ID Number** – Allows the user to enter an identification number for the selected measurement point.</li>

<li>**Trouble Codes** – Opens the list of available trouble codes for the selected measurement point.</li>
<li>**Adjust Backlight** – Adjusts the screen brightness level.</li>
<li>**Not Measured Codes** – Allows the user to select a reason code when a measurement cannot be taken.</li>
<li>**Enter Speed** – Allows the user to enter the machine operating speed.</li>
<li>**Enter Temp** – Allows the user to enter the temperature value for the selected point.</li>
<li>**Clean Screen** – Clears the screen display for improved visibility.</li>
<li>**Turn Off Screen** – Turns off the display to conserve battery power.</li></ul>

### Display Parameters
The **Display Parameters** feature allows operators to review the specific configuration settings, hardware setups,
and sensor details assigned to a selected measurement point. It is used to quickly verify test limits, sensor
channels, and machine location details before or after collecting vibration data.

**Procedure:**
1. Access **Measure Data > More > Display Parameters**.
2. The **Display Parameters** window will open as shown in <FigureRef id="Display-Measurement-Screen" />.
3. Review the **Measure Point** block to verify details such as the location ID, plant name, drive type, and specific test component.
4. Check the **Parameters** block to read sensor configurations, including the sensor type (Triaxial Accelerometer), frequency limits (250 000 CPM), and measurement type (Spectrum).
5. Verify additional diagnostic details like **Demodulation** frequencies and averaging configurations at the bottom of the pane.
6. Use the **Up** and **Down** arrow buttons on the right menu panel to scroll through the data fields if more parameters are available.
7. Click the **Cancel** button at the bottom right to close the window and return to the main measurement route list.

### Enter Temp
The **Enter Temperature** feature allows operators to manually record the current process or machinery temperature for
the selected measurement point. This parameter is tracked alongside vibration signatures to help diagnose thermal
expansion or overheating issues.

**Procedure:**<br />
<ul><li>Access **Measure Data > More > Enter Temp.**</li>
<li>The temperature entry window will open with a dynamic numeric keypad as shown in <FigureRef id="Enter-Temp-Screen" />.</li>
<li>Use the keypad interface (digits 0-9 and the decimal point button) to enter the observed temperature value.</li>
<li>The system will instantly validate your input and display a green **"Valid value"** confirmation status if the entry falls within acceptable limits.</li>
<li>If needed, use the unit conversion button (e.g., **-> °C**) to toggle or convert the measurement unit context.</li>
<li>Click the **Backspace icon** or **Clear All** button to modify or reset your numeric entry.</li>
<li>Click **Ok** to save the recorded temperature value. The pop-up window will close automatically, and you will return directly to the main measurement route list screen.</li>
<li>Click **Cancel** to dismiss the window and return to the main layout without saving the temperature parameter.</li></ul>

The **Adjust Backlight Settings**s feature allows operators to adjust the hardware screen brightness and toggle the
system visual theme. This is used to optimize screen visibility and conserve battery life when working in different
plant lighting environments, such as low-light areas or bright outdoor conditions.

**Procedure:**
