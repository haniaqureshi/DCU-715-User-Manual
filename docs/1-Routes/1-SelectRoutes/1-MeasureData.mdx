# Select Routes

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

    The **Select Route** option allows the user to choose a measurement route for data collection.
    Once you select this option the system will display all routes that are currently available     
    on the device. These routes are typically downloaded by technicians from the DCU and stored 
    locally after synchronization with the server.

    **Key-Points:**

    - The route list is fetched from the database (SQL Server).
    - Only downloaded and available routes are displayed.
    - Routes are used to perform measurements on industrial equipment through the ITR system.

    **Procedure For Access the Select Route Module:**

    1. From the Routes menu, click Select Route.
    2. The list of available routes will appear.
    3. Select the required route.
    4. Click on Select to load the route.
