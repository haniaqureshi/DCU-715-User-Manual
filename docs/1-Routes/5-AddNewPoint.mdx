# Add New Point

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

If no routes are available or additional measurements are required, users can add new points to a route. 

**Key Points:**
- Each new point has a unique 6-digit ID.
- Points define where and how measurements are taken.

**Procedure**
1. Click **Add New Point** from the Route main menu. 
2. The system will display the list of available routes as shown in <FigureRef id="Add-New Points-Route-list" />.
3. Select the required route from the list and press the Select button on the right panel.

    <FigureProvider>
        <Figure 
            id="Confirmation-Dialog-Box" 
            src="/img/1-Routes/5-AddNewPoint/AddNewPointsRouteList-Light.jpg"
            caption="Add New Points Route list" 
            width="70%"
        />
    </FigureProvider>

4. If the selected route is more than 2 weeks old, a warning dialog box will appear: **"Route is more than 2 weeks old. 
    Please download a new route before proceeding!"** as shown in <FigureRef id="Add-New-Points-Warning-Dialogbox" />.<br />
    a. **Press 'YES'**: Click Yes to exit and download a new route.<br />
    b. **Press 'NO'**: Click No to proceed with the old route and move forward to configuration.

:::warning

The route is more than 2 weeks old. Please download a new route before proceeding.

:::

<FigureProvider>
    <Figure 
        id="Add-New-Points-Warning-Dialogbox" 
        src="/img/1-Routes/5-AddNewPoint/AddNewPointsWarningDialogBox-Light.jpg"
        caption="Add New Points Warning Dialogbox" 
        width="70%"
    />
</FigureProvider>

**Configure New Measurement Point Details:** 

5. After pressing **'No'** on the warning dialog box, the Create New Point screen will open 
    as shown in <FigureRef id="Add-New-Points-Screen" />.
6. In this Screen you can enter the required Id for the measurement point and configure
    the remaining parameters (such as Measure Type, Frequency, Resolution, etc.).

<FigureProvider>
    <Figure 
        id="Add-New-Points-Screen" 
        src="/img/1-Routes/5-AddNewPoint/AddNewPointsScreen-Light.jpg"
        caption="Add New Points Screen" 
        width="70%"
    />
</FigureProvider>

**Configure Sensor Type (Optional):**

- If you want to add or modify the sensor type, click the Sensor button located on the right sidebar panel.
- A Sensor Type popup window will open as <FigureRef id="Add-New-Point-Add-Configure-Sensor-Type" />.
- Select your desired Sensor (e.g., Triaxial Accelerometer) and its Sensitivity (e.g., 100 mv/g) from the dropdown menus, then click Ok to apply the settings.

<FigureProvider>
    <Figure 
        id="Add-New-Point-Add-Configure-Sensor-Type" 
        src="/img/1-Routes/5-AddNewPoint/AddNewPointAddConfigureSensorType-Light.jpg"
        caption="Add New Point Add Configure Sensor Type" 
        width="40%"
    />
</FigureProvider>

**Save and Proceed to Measurement:**

- Once all details and parameters are properly configured, click the Save button on the right panel. 
    This will redirect you to the area and machine view, where the actual data measurement flow will proceed.

:::info

The **Add Point** option can also be accessed from the **Select Route** module. Open the More menu in the Select Route module and select the **Add Point**. 

:::
