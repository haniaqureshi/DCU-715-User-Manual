# Create New Route

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Create New Routes** option allows the user to manually add a new route to the device.

**Procedure:**
1. From the main interface, navigate to the **Route Module** and click the **Create Module** button located within it.
2. The system will open an **Enter Account Number** pin pad screen as shown in <FigureRef id="Create-New-Route-Pin-Pad" />.

<FigureProvider>
    <Figure 
        id="Create-New-Route-Pin-Pad" 
        src="/img/1-Routes/4-CreateNewRoutes/Create-New-Route-Pin-Pad-Light.png"
        srcDark="/img/1-Routes/4-CreateNewRoutes/Create-New-Route-Pin-Pad-Dark.png"
        caption="Create New Route Pin Pad" 
        width="70%"
    />
</FigureProvider>

3. Enter the required pin/account number using the on-screen numeric pad.
4. After entering a valid value, click **Ok** to submit.

:::note

You can use the backspace or **Clear All** button to correct any input errors before submitting.

:::

5. A confirmation dialog box reading **"Success => Account:[Number] Creating New Account With Success"** 
will be displayed and the system will automatically redirect you back to the main startup screen 
as shown in <FigureRef id="Confirmation-Dialog-Box" />.

:::tip[confirmation]

Success => Account:[Number] Creating New Account With Success.

:::
