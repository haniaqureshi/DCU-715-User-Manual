# Battery Test
Use the **Battery Test** function to verify battery health and review battery performance values, such as voltage, capacity, and test duration. 

To open the Battery Test function, follow these steps:
1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Maintenance**.
4. From the **Maintenance** submenu, select **Battery Test**. 

The **Battery Test** dialog appears. Opening the dialog doesn't start a test.

## Battery Test dialog
The following table describes the fields and controls available in the Battery Test dialog, as shown in <FigureRef id="Battery-Test-Modal"/>.

| Field/Button          | Description                                                                                                                                                                     | 
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | 
| Battery Serial Number | Displays the battery serial number for the battery test. Select the field to open the Battery Serial Number dialog and enter or change the value. The field is empty by default and shows the hint "(at least 5 digits)". <br /><br />**Example:** 12345 | 
| Minutes               | Displays the elapsed test time in minutes. The default value is 0. <br /><br />**Example:** 15                                                                                  | 
| Battery Voltage       | Displays the current battery voltage in volts. The default value is 0.00 Volts. The value updates while a test is running. <br /><br />**Example:** 12.45 Volts                 | 
| Battery Capacity      | Displays the current battery capacity as a percentage (%). The default value is 0.00 %. <br /><br />**Example:** 85.00 %                                                        | 
| Start                 | Starts the battery test cycle. **Start** is unavailable until you enter a valid battery serial number.                                                                          | 
| Stop                  | Stops the battery test cycle. **Stop** is unavailable when no test is running.                                                                                                  | 
| Cancel                | Closes the Battery Test dialog without running or continuing the test.                                                                                                           |
| Menu                  | Replaces the ITR logo in the header while the Battery Test dialog is open.                                                                                                       |

### Enter the battery serial number
To enter the battery serial number, follow these steps:

1. In the **Battery Test** dialog, select the **Battery Serial Number** field. The **Battery Serial Number** dialog appears.

2. Use the numeric keypad to enter the battery serial number.
3. To save the battery serial number and return to the Battery Test dialog, select **Ok**.

#### Battery Serial Number dialog
The following table describes the fields and controls available in the Battery Serial Number dialog, as shown in <FigureRef id="Battery-Serial-Number-Modal"/>.

| Field/Button          | Description                                                                                                                                                              | 
| :-------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | 
| Battery Serial Number | Specifies the battery serial number. Enter 5 to 8 numeric digits. The field accepts no more than 8 digits. Letters and special characters aren't accepted. <br /><br />If you enter 1 to 4 digits, the message "The entered value is too small (Minimum 5 digits)" appears. If you enter 5 to 8 digits, the message "Valid value" appears. <br /><br /> **Example:** 12345 | 
| Numeric keypad        | Enters numeric digits from 0 through 9.                                                                                                                                  | 
| Backspace             | Removes the last entered digit from the battery serial number field.                                                                                                     |  
| Clear All             | Removes all digits from the battery serial number field.                                                                                                                 |  
| Cancel                | Closes the Battery Serial Number dialog without saving changes to the battery serial number field.                                                                        |
| Ok                    | Closes the Battery Serial Number dialog and saves the entered battery serial number to the Battery Test dialog. **Ok** appears only after you enter a valid battery serial number of 5 to 8 digits. |   

## Run the battery test
To run the battery test, follow these steps:

1. In the **Battery Test** dialog, enter a battery serial number that contains 5 to 8 numeric digits in the **Battery Serial Number** field. **Start** becomes available after you enter a valid battery serial number.
2. Select **Start**. The DCU starts the battery test cycle.
3. Review the following values during the test:
    - **Minutes**
    - **Battery Voltage**
    - **Battery Capacity**
4. To end the battery test, select **Stop**.

Selecting **Stop** generates a battery test report and displays the report's file location in the [System Alert Bar](../../0-GettingStarted/5-ScreenLayout.mdx#dcu-application-screen-layout) as shown in <FigureRef id="Battery-Test-Report-Created-Message"/>.

### Battery test report
The battery test report is saved as a `.txt` file at `C:\CVASYS\ITR100\Batterytest.txt`. To view the report:

1. Open File Explorer.
2. Go to `C:\CVASYS\ITR100\`.
3. Double-click `Batterytest.txt` to open the report in the default text editor as shown in <FigureRef id="Battery-Test-Report-File"/>.

The first line of the report identifies the battery test record and the DCU used for the test:

```text title="C:\CVASYS\ITR100\Batterytest.txt"
12345;860;07150997;tech
```
| Field                 | Description                                                                                                                                                                                       | 
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | 
| Battery Serial Number | Identifies the battery tested during the battery test. This value matches the battery serial number entered in the Battery Test dialog before the test was started. <br /><br />**Example:** 12345 |
| Device ID             | Identifies the DCU device ID. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** 860                                              | 
| DCU number            | Identifies the DCU number. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** 07150997                                            |
| Technician name       | Identifies the technician assigned to the DCU. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** tech                            | 

The remaining lines contain the battery readings captured during the test. The DCU records one reading every minute.
```text title="C:\CVASYS\ITR100\Batterytest.txt"
0 5/14/2026 5:11:43 AM 100.00% 18.443
1 5/14/2026 5:12:43 AM 100.00% 18.418
```
| Field            | Description                                                                                                     | 
| :----------------| :-------------------------------------------------------------------------------------------------------------- | 
| Test ID          | Identifies each recorded test reading. The DCU records a new test ID every minute. <br /><br />**Example:** 0   |                                                
| Test day         | Records the date when the reading was captured. <br /><br />**Example:** 5/14/2026                              |
| Test time        | Records the time when the reading was captured. <br /><br />**Example:** 5:11:43 AM                             |
| Battery capacity | Records the battery capacity as a percentage at the time of the reading. <br /><br />**Example:** 100.00%       |
| Battery voltage  | Records the battery voltage in volts (V) at the time of the reading. <br /><br />**Example:** 18.443            |

To return to the **Maintenance** submenu, in the **Battery Test** dialog, select **Cancel**.
