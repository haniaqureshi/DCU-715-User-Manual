# Battery Test
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Battery Test** function to verify battery health and review battery performance values, such as voltage, capacity, and test duration. 

    To open the Battery Test function, proceed as follows:
    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Maintenance**.
    3. Select **Battery Test**.

    The **Battery Test** modal appears.

    ## Battery Test modal

    The following table describes the fields and controls available in the Battery Test modal as seen in <FigureRef id="Battery-Test-Modal"/>.

    | Field/Button          | Description                                                                                     | 
    | :-------------------- | :---------------------------------------------------------------------------------------------- | 
    | Battery Serial Number | Specifies the battery serial number. Enter at least five digits. <br /><br />**Example:** 12345 | 
    | Minutes               | Displays the elapsed test time in minutes. <br /><br />**Example:** 15                          | 
    | Battery Voltage       | Displays the current battery voltage in volts (V). <br /><br />**Example:** 12.45 V             | 
    | Battery Capacity      | Displays the current battery capacity as a percentage (%). <br /><br />**Example:** 85%         | 
    | Start                 | Starts the battery test cycle.                                                                  | 
    | Stop                  | Stops the battery test cycle.                                                                   | 
    | Cancel                | Closes the Battery Test modal without running or continuing the test.                           |

    ### Enter the Battery Serial Number
    To enter the battery serial number, proceed as follows:

    1. In the **Battery Test** modal, select the **Battery Serial Number** field. The **Battery Serial Number** modal appears.
        <Figure 
            id="Battery-SerialNumber-Modal" 
            src="/img/4-DCUSetup/1-Maintenance/1-BatteryTest/BatterySerialNumberModal.png" 
            srcDark="/img/4-DCUSetup/1-Maintenance/1-BatteryTest/BatterySerialNumberModal-Dark.png"
            caption="Battery Serial Number modal" 
            width="70%"
        />
    2. Use the numeric keypad to enter the battery serial number.

    #### Battery Serial Number modal
    The following table describes the fields and controls available in the Battery Serial Number modal as seen in <FigureRef id="Battery-SerialNumber-Modal"/>.

    | Field/Button          | Description                                                                                                   | 
    | :-------------------- | :------------------------------------------------------------------------------------------------------------ | 
    | Battery Serial Number | Displays the battery serial number entered by the user. <br /><br /> **Example:** 12345                       | 
    | Numeric Keypad        | Enters numeric digits from 0 through 9.                                                                       | 
    | Backspace             | Removes the last entered digit from the battery serial number field.                                          |  
    | Clear All             | Removes all digits from the battery serial number field.                                                      |  
    | Cancel                | Closes the Battery Serial Number modal without saving changes to the battery serial number field.             |
    | Ok                    | Closes the Battery Serial Number modal and saves the entered battery serial number to the Battery Test modal. |   

    ## Run the battery test

    To run the battery test, proceed as follows:

    1. Enter a valid value in the **Battery Serial Number** field.
    2. Select **Start**. The DCU starts the battery test cycle.
    4. Review the following values during the test:
       - Minutes
       - Battery Voltage
       - Battery Capacity
    5. Select **Stop** to end the battery test.
    
    The DCU creates a battery test report and displays a message in the system message bar.

    ### Battery test report
    When the user selects **Stop** in the Battery Test modal, the DCU creates a battery test report file and the system alert bar displays the report location as shown in <FigureRef id="Battery-Test-Report-Created-Message"/>.
    The file is saved to `C:\CVASYS\ITR100\` on the DCU as `Batterytest.txt`.

    The following table describes the fields in the report as seen in <FigureRef id="Battery-Test-Report-File"/>.

    | Field/Button          | Description                                                                                                                                                                     | 
    | :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | 
    | Battery serial number | Identifies the battery tested during the battery test. <br /><br />**Example:** 55444.                                                                                          |
    | Device ID             | Identifies the DCU device ID. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** 834                            | 
    | DCU number            | Identifies the DCU number. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** 07150002                          |
    | Technician name       | Identifies the technician assigned to the DCU. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** Indiana Jones | 

    The remaining lines contain the battery readings captured during the test. The DCU records one reading every 1 minute.

    ```jsx title="C:\CVASYS\ITR100\Batterytest.txt"
        0 5/14/2026 5:11:43 AM 100.00% 18.443
        1 5/14/2026 5:11:43 AM 100.00% 18.418
    ```
