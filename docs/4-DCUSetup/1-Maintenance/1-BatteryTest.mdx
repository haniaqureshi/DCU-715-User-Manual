# Battery Test
Use the **Battery Test** function to verify battery health and review battery performance values, such as voltage, capacity, and test duration. 

To open the Battery Test function, proceed as follows:
1. From the **Main Menu**, select **DCU Setup**.
2. From the **DCU Setup** submenu, select **Maintenance**.
3. From the **Maintenance** submenu, select **Battery Test**. 

The **Battery Test** modal appears.

## Battery Test modal
The following table describes the fields and controls available in the Battery Test modal as seen in <FigureRef id="Battery-Test-Modal"/>.

| Field/Button          | Description                                                                                                                                                                     | 
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | 
| Battery Serial Number | Displays the battery serial number for the battery test. Select the field to open the Battery Serial Number modal and enter or modify the value. <br /><br />**Example:** 12345 | 
| Minutes               | Displays the elapsed test time in minutes. <br /><br />**Example:** 15                                                                                                          | 
| Battery Voltage       | Displays the current battery voltage in volts (V). <br /><br />**Example:** 12.45 V                                                                                             | 
| Battery Capacity      | Displays the current battery capacity as a percentage (%). <br /><br />**Example:** 85%                                                                                         | 
| Start                 | Starts the battery test cycle.                                                                                                                                                  | 
| Stop                  | Stops the battery test cycle.                                                                                                                                                   | 
| Cancel                | Closes the Battery Test modal without running or continuing the test.                                                                                                           |

### Enter the Battery Serial Number
To enter the battery serial number, proceed as follows:

1. In the **Battery Test** modal, select the **Battery Serial Number** field. The **Battery Serial Number** modal appears.

2. Use the numeric keypad to enter the battery serial number.
3. Select **Ok** to save the battery serial number and return to the Battery Test modal.

#### Battery Serial Number modal
The following table describes the fields and controls available in the Battery Serial Number modal as seen in <FigureRef id="Battery-Serial-Number-Modal"/>.

| Field/Button          | Description                                                                                                                                                              | 
| :-------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | 
| Battery Serial Number | Specifies the battery serial number. Enter 5 to 8 numeric digits. Letters and special characters aren't accepted. <br /><br /> **Example:** 12345                        | 
| Numeric Keypad        | Enters numeric digits from 0 through 9.                                                                                                                                  | 
| Backspace             | Removes the last entered digit from the battery serial number field.                                                                                                     |  
| Clear All             | Removes all digits from the battery serial number field.                                                                                                                 |  
| Cancel                | Closes the Battery Serial Number modal without saving changes to the battery serial number field.                                                                        |
| Ok                    | Closes the Battery Serial Number modal and saves the entered battery serial number to the Battery Test modal.                                                            |   

## Run the Battery Test
To run the battery test, proceed as follows:

1. Enter a battery serial number that contains 5 to 8 numeric digits in the **Battery Serial Number** field in the **Battery Test** modal.
2. Select **Start**. The DCU starts the battery test cycle.
3. Review the following values during the test:
    - **Minutes**
    - **Battery Voltage**
    - **Battery Capacity**
4. Select **Stop** to end the battery test.

Selecting Stop generates a battery test report and displays the report's file location in the [System Alert Bar](../../intro.mdx#dcu-application-screen-layout) as shown in <FigureRef id="Battery-Test-Report-Created-Message"/>.

### Battery Test Report
The battery test report is saved as a `.txt` file at `C:\CVASYS\ITR100\Batterytest.txt`. To view the report:

1. Open File Explorer.
2. Navigate to `C:\CVASYS\ITR100\`.
3. Double-click `Batterytest.txt` to open the report in the default text editor as shown in <FigureRef id="Battery-Test-Report-File"/>.

The first line of the report identifies the battery test record and the DCU used for the test:

```jsx title="C:\CVASYS\ITR100\Batterytest.txt"
12345;860;07150997;tech
```
| Field                 | Description                                                                                                                                                                                       | 
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | 
| Battery Serial Number | Identifies the battery tested during the battery test. This value matches the battery serial number entered in the Battery Test modal before the test was started. <br /><br />**Example:** 12345 |
| Device ID             | Identifies the DCU device ID. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** 860                                              | 
| DCU number            | Identifies the DCU number. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** 07150997                                            |
| Technician name       | Identifies the technician assigned to the DCU. This value is available in [Show System Settings](../3-Settings/8-ShowSystemSettings.mdx).<br /><br />**Example:** Indiana Jones                   | 

The remaining lines contain the battery readings captured during the test. The DCU records one reading every 1 minute.
```jsx title="C:\CVASYS\ITR100\Batterytest.txt"
0 5/14/2026 5:11:43 AM 100.00% 18.443
1 5/14/2026 5:12:43 AM 100.00% 18.418
```
| Field            | Description                                                                                                     | 
| :----------------| :-------------------------------------------------------------------------------------------------------------- | 
| Test ID          | Identifies each recorded test reading. The DCU records a new test ID every 1 minute. <br /><br />**Example:** 0 |                                                
| Test day         | Records the date when the reading was captured. <br /><br />**Example:** 5/14/2026                              |
| Test time        | Records the time when the reading was captured. <br /><br />**Example:** 5:11:43 AM                             |
| Battery capacity | Records the battery capacity as a percentage at the time of the reading. <br /><br />**Example:** 100.00%       |
| Battery voltage  | Records the battery voltage in volts (V) at the time of the reading. <br /><br />**Example:** 18.288            |

To close the Battery Test modal select **Cancel**.
