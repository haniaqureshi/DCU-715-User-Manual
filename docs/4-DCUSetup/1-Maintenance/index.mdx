Use the **Maintenance** submodule to verify DCU operation before deployment. Its functions let you run system health checks, test hardware components, and confirm that the device is ready for field use.

To open the Maintenance submenu, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Maintenance**.

The **Maintenance** submenu appears, as shown in <FigureRef id="DCU-Setup-Maintenance-Submenu" />.

## Maintenance functions

The **Maintenance** submenu contains the following functions:

- [**Battery Test**](./1-BatteryTest.mdx): Checks battery health and records voltage and capacity.
- [**Internet Test**](./2-InternetTest.mdx): Checks the DCU network connection.
- [**Touchscreen Calibration**](./3-TouchscreenCalibration.mdx): Aligns the touchscreen with the display.
- [**Touchscreen Test**](./4-TouchscreenTest.mdx): Checks that the touchscreen responds across the display.
- [**Software Upgrade**](./5-SoftwareUpgrade.mdx): Updates the DCU software.

## Close the Maintenance submenu

- To return to the **DCU Setup** submenu, select **Back**.
- To return to the Home screen, select **Cancel**.
