# Maintenance

The **Maintenance** submenu provides tools that help technicians verify DCU operation before deployment. Use this submenu to run system health checks, test hardware components, and confirm that the device is ready for field use.

To open the Maintenance submenu, proceed as follows:

1. From the **Main Menu**, select **DCU Setup**.
2. From the **DCU Setup** submenu, select **Maintenance**.

The **Maintenance** submenu appears.
