# Touchscreen Calibration

Use the **Touchscreen Calibration** function to align the touchscreen sensors with the visual display. Run this calibration if the DCU doesn't respond accurately to touch input or if buttons are hard to select.

To open the Touchscreen Calibration function, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Maintenance**.
4. From the **Maintenance** submenu, select **Touchscreen Calibration**.

The Touchscreen Calibration screen appears.

## Touchscreen Calibration screen

When calibration starts, the screen turns white and displays a calibration point, such as a crosshair. The screen also displays instructions for completing or exiting the calibration process, as shown in <FigureRef id="Touchscreen-Calibration-Screen"/>.

| Screen element            | Description                                                                                                                                                                                                                                           | 
| :------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | 
| Calibration point         | Indicates the point to touch during calibration. Touch the center of the point as accurately as possible. <br /><br />**Example:** <img src="/img/4-DCUSetup/1-Maintenance/3-TouchscreenCalibration/Crosshair-Light.png" alt="Crosshair" width="7%" />|
| On-screen prompt          | Displays the instruction "Please touch the point on the screen."                                                                                                                                                                                    | 
| Shortcut key instructions | Displays the available keyboard or hardware shortcuts for testing, canceling, moving the calibration point, or advancing to the next screen.                                                                                                          |

## Calibrate the touchscreen

To calibrate the touchscreen, follow these steps:

1. On the Touchscreen Calibration screen, touch the center of the calibration point.
2. Repeat this action for each calibration point that appears.
3. Continue until the calibration sequence is complete.

## Navigation and shortcut keys

During touchscreen calibration, use the following keys to manage the calibration process.

| Key        | Function                                                                          | 
| :--------- | :-------------------------------------------------------------------------------- | 
| Home       | Restarts the calibration test.                                                    |
| Esc        | Cancels the calibration and exits the calibration screen without saving changes.  |
| Arrow keys | Moves the calibration point manually if it needs adjustment.                      |
| Enter      | Confirms the current calibration point and moves to the next screen.              |

To exit the calibration screen and return to the **Maintenance** submenu, press **Esc**.
