# Touchscreen Calibration
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Touchscreen Calibration** function to align the touchscreen sensors with the visual display. Run
    this calibration if the DCU does not respond accurately to touch input or if buttons are difficult to select.

    To open the Touchscreen Calibration function, proceed as follows:

    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Maintenance**.
    3. Select **Touchscreen Calibration**.

    The calibration screen appears.

    ## Touchscreen Calibration screen
    When calibration starts, the screen turns white and displays a calibration point, such as a crosshair. The screen also displays instructions for completing or exiting the calibration process.

    | Screen element            | Description                                                                                                                          | 
    | :------------------------ | :----------------------------------------------------------------------------------------------------------------------------------- | 
    | Calibration point         | Indicates the point to touch during calibration. Touch the center of the point as accurately as possible. <br /><br />**Example:** ![Crosshair](../../../static/img/4-DCUSetup/1-Maintenance/3-TouchScreenCallibration/Crosshair.png)  |
    | On-screen prompt          | Displays the instruction: Please touch the point on the screen.                                                                      | 
    | Shortcut key instructions | Displays the available keyboard or hardware shortcuts for testing, canceling, moving the point, or advancing to the next screen.     |

    ## Calibrate the touchscreen
    To calibrate the touchscreen, proceed as follows:

    1. Open the **Touchscreen Calibration** function. The calibration screen appears.
    2. Touch the center of the calibration point shown on the screen.
    3. Repeat the process for each calibration point that appears.
    4. Continue until the calibration sequence is complete.

    Use a stylus for more accurate calibration when available.

    ## Navigation and shortcut keys
    During touchscreen calibration, use the following keys to manage the calibration process.

    | Key        | Function                                                                         | 
    | :--------- | :------------------------------------------------------------------------------- | 
    | Home       | Restarts the calibration test.                                                   |
    | Esc        | Cancels the calibration and exits the calibration screen without saving changes. |
    | Arrow keys | Moves the calibration point manually, if adjustment is required.                 |
    | Enter      | Confirms the current calibration point and moves to the next screen.             |
