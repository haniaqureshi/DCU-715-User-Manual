# Touchscreen Test
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Touchscreen Test** function to verify that the touchscreen detects finger input across the 
    display area. This test helps identify unresponsive areas, inaccurate touch response, or possible 
    touchscreen dead zones.

    To open the Touchscreen Test function, proceed as follows:

    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Maintenance**.
    3. Select **Touchscreen Test**.

    The **Test Touch Screen** modal appears.

    ## Touchscreen Test screen
    The following table describes the information and controls available on the Touchscreen Test screen in <FigureRef id="Touchscreen Calibration Screen"/>

    | Screen element     | Description                                                          | 
    | :----------------- | :------------------------------------------------------------------- | 
    | Double tap to exit | Exits the touchscreen test when the user double-taps the box.        |
    | Close              | Closes the Touchscreen Test screen and returns to the previous menu. | 

    ## Test the touchscreen
    To test the touchscreen, proceed as follows:

    1. Open the **Touchscreen Test** function. The **Test Touch Screen** modal appears.
    2. Touch, tap, or swipe different areas of the touchscreen with your finger. Test the center, corners, and edges of the display to confirm that the screen responds accurately. As you swipe, the screen displays a drawn touch path.
    3. Double-tap the **Double tap to exit** box. If the touchscreen responds correctly, the confirmation dialog box appears.

        <Figure 
            id="Touchscreen-Working-Confirmation-DialogBox"
            src="/img/4-DCUSetup/1-Maintenance/4-TouchscreenTest/Touchscreen-Working-Confirmation-DialogBox-Light.png" 
            srcDark="/img/4-DCUSetup/1-Maintenance/4-TouchscreenTest/Touchscreen-Working-Confirmation-DialogBox-Dark.png"
            caption="Touchscreen working confirmation dialog box"
            width="70%"
        /> 

    4. Select **Close** to acknowledge the confirmation message and return to the Maintenance submenu.

    ## Exit without completing the test
    If the user exits the test screen without testing the touchscreen, the DCU displays a warning message. 

    <Figure 

        id="Touchscreen-TestWarning-DialogBox" 
        src="/img/4-DCUSetup/1-Maintenance/4-TouchscreenTest/Touchscreen-TestWarning-DialogBox-Light.png" 
        srcDark="/img/4-DCUSetup/1-Maintenance/4-TouchscreenTest/Touchscreen-TestWarning-DialogBox-Dark.png"
        caption="Touchscreen test warning dialog box"
        width="70%"
    /> 

    To exit without completing the test, proceed as follows:

    1. Select **Close** on the **Test Touch Screen** modal before testing the touchscreen.
    2. The warning dialog box appears.
    3. Select **Close** to acknowledge the warning and return to the Maintenance submenu.

    | Message                                       | When it appears                                                                              | Action                                                                         | 
    | :-------------------------------------------- | :------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
