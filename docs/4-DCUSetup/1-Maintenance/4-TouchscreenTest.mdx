# Touchscreen Test

Use the **Touchscreen Test** function to verify that the touchscreen detects finger input across the display area. This test helps identify unresponsive areas, inaccurate touch response, or possible touchscreen dead zones.

To open the Touchscreen Test function, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Maintenance**.
4. From the **Maintenance** submenu, select **Touchscreen Test**.

The **Test Touch Screen** dialog appears.

## Test Touch Screen dialog

The following table describes the fields and controls available in the Test Touch Screen dialog as shown in <FigureRef id="Touchscreen-TestScreen-Modal"/>.

| Button             | Description                                                                    | 
| :----------------- | :------------------------------------------------------------------------------| 
| Double tap to exit | Exits the touchscreen test when you double-tap it.                             |
| Close              | Closes the Test Touch Screen dialog and returns to the **Maintenance** submenu. | 

## Test the touchscreen

To test the touchscreen, follow these steps:

1. In the **Test Touch Screen** dialog, touch, tap, or swipe different areas of the touchscreen with your finger.
2. Test the center, corners, and edges of the display. As you swipe, the screen displays a touch path.
3. Double-tap **Double tap to exit**. If the touchscreen responds correctly, a confirmation dialog appears, as shown in <FigureRef id="Touchscreen-Working-Confirmation-DialogBox"/>.

4. To return to the **Maintenance** submenu, select **Close**.

## Exit without completing the test

To exit without completing the touchscreen test, follow these steps:

1. In the **Test Touch Screen** dialog, select **Close** before testing the touchscreen. A warning dialog appears, as shown in <FigureRef id="Touchscreen-TestWarning-DialogBox-1"/>.
