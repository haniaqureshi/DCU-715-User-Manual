# Touchscreen Test

Use the **Touchscreen Test** function to verify that the touchscreen detects finger input across the display area. This test helps identify unresponsive areas, inaccurate touch response, or possible touchscreen dead zones.

To open the Touchscreen Test function, proceed as follows:

1. From the **Main Menu**, select **DCU Setup**.
2. From the **DCU Setup** submenu, select **Maintenance**.
3. From the **Maintenance** submenu, select **Touchscreen Test**.

The **Test Touch Screen** modal appears.

## Test Touch Screen modal

The following table describes the fields and controls available in the Test Touch Screen modal as seen in <FigureRef id="Touchscreen-TestScreen-Modal"/>.

| Button             | Description                                                                    | 
| :----------------- | :------------------------------------------------------------------------------| 
| Double tap to exit | Exits the touchscreen test when you double-tap the button.                     |
| Close              | Closes the Test Touch Screen modal and returns to the **Maintenance** submenu. | 

## Test the touchscreen

To test the touchscreen, proceed as follows:

1. In the **Test Touch Screen** modal, touch, tap, or swipe different areas of the touchscreen with your finger.
2. Test the center, corners, and edges of the display. As you swipe, the screen displays a touch path.
3. Double-tap **Double tap to exit**. If the touchscreen responds correctly, a confirmation dialog box appears as seen in <FigureRef id="Touchscreen-Working-Confirmation-DialogBox"/>.

4. Select **Close** to return to the **Maintenance** submenu.

## Exit without completing the test

To exit without completing the touchscreen test, proceed as follows:

1. In the **Test Touch Screen** modal, select **Close** before testing the touchscreen. A warning dialog box appears as seen in <FigureRef id="Touchscreen-TestWarning-DialogBox-1"/>.
