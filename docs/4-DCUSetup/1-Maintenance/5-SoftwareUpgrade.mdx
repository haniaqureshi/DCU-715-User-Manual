# Software Upgrade

Use the **Software Upgrade** function to update the DCU software when a new approved version is available. Software updates help keep the DCU current with the latest features, fixes, and security updates.

To open the Software Upgrade function, proceed as follows:

1. From the **Main Menu**, select **DCU Setup**.
2. From the **DCU Setup** submenu, select **Maintenance**.
3. From the **Maintenance** submenu, select **Software Upgrade**.

The **Software Upgrade** screen appears.

## Select the upgrade source

Select one of the following upgrade sources:

- **USB Drive:** Select **USB Drive**, and then insert the USB flash drive that contains the approved software upgrade package into the USB port.
- **ITR.com:** The DCU checks for the available software version automatically.
- **ITR.com via CMAS:** Select **ITR.com via CMAS**, and then wait for the DCU to check the selected upgrade source.

### Upgrade the DCU software

To upgrade the DCU software, proceed as follows:

1. Select the required upgrade source.
2. Review the following version information:
    - **Current version**
    - **Version available**
3. Confirm that **Version available** is newer than **Current version**.
4. Select **Upgrade Now**. The software upgrade starts, and the task status bar displays the update status as shown in <FigureRef id="Software-Upgrade-Update-Process"/>.

#### Check software upgrade messages
If the DCU already has the latest approved software version, the System Alert Bar displays `Software is up to date`.

To review recent system messages, proceed as follows:

1. Double-tap the **System Alert Bar**. The **System Alerts** modal appears.

<FigureProvider>
    <Figure 
        id="System-Alerts-Modal"

        caption="System Alerts modal"

</FigureProvider>

2. Review the system messages.
3. Select **Clear** to remove the displayed messages, or select **Close** to return to the Software Upgrade screen.

To return to the **Maintenance** submenu, select **Exit** in the **Software Upgrade** screen.
