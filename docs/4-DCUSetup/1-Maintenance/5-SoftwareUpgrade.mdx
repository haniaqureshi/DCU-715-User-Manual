# Software Upgrade

Use the **Software Upgrade** function to update the DCU software when a new approved version is available. Software updates help keep the DCU current with the latest features, fixes, and security updates.

To open the Software Upgrade function, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Maintenance**.
4. From the **Maintenance** submenu, select **Software Upgrade**.

The **Software Upgrade** screen appears, as shown in <FigureRef id="Software-Upgrade-Screen"/>.

## Select the upgrade source

To select the upgrade source, do one of the following:

- **USB Drive:** Select **USB Drive**, and then insert the USB flash drive that contains the approved software upgrade package into the USB port.
- **ITR.com:** Select **ITR.com**. The DCU checks for the available software version automatically.
- **ITR.com via CMAS:** Select **ITR.com via CMAS**, and then wait while the DCU checks the selected upgrade source.

### Upgrade the DCU software

To upgrade the DCU software, follow these steps:

1. Select the upgrade source.
2. Review the following version information:
    - **Current version**
    - **Version available**
3. Confirm that **Version available** is newer than **Current version**. If both versions are the same, **Upgrade Now** is unavailable and the DCU software is already up to date.
4. Optional: To see what changed in the new version, select **Release Notes**. For details, see [View the release notes](#view-the-release-notes).
5. Select **Upgrade Now**. The software upgrade starts, and the task status bar displays the update status, as shown in <FigureRef id="Software-Upgrade-Update-Process"/>.

### View the release notes

Use **Release Notes** to see what changed in each software version before you upgrade.

To view the release notes, follow these steps:

1. On the **Software Upgrade** screen, select **Release Notes**. The **Release Notes** dialog appears, as shown in <FigureRef id="Release-Notes-Dialog" />.

    <FigureProvider>
        <Figure 
            id="Release-Notes-Dialog"
            src="/img/4-DCUSetup/1-Maintenance/5-SoftwareUpgrade/ReleaseNotesDialog-Light.png" 
            caption="Release Notes dialog"
            alt={"Release Notes dialog listing versions 0.3.2.46, 0.3.1.30 and 0.3.1.29, each with a date, a title and a short list of changes, and a Close button."}
            width="70%"
        /> 
    </FigureProvider>

2. Review the entry for each version. The following table describes each part of an entry.

    | Element             | Description |
    | :------------------ | :---------- |
    | ∧ (Collapse)        | Collapses or expands the list of changes for the version. |
    | Version number      | Displays the software version. <br /><br />**Example:** 0.3.2.46 |
    | Release date        | Displays the date that the version was released. <br /><br />**Example:** 2026-10-1 |
    | Release name        | Displays a short name for the main change in the version. <br /><br />**Example:** Time Machine |
    | List of changes     | Lists the features and fixes in the version. <br /><br />**Example:** Ability to revert to the previous version of the program |

3. To close the **Release Notes** dialog and return to the **Software Upgrade** screen, select **Close**.

### Check software upgrade messages
If the DCU already has the latest approved software version, the System Alert Bar displays "Software is up to date."

To review recent system messages, follow these steps:

1. Double-tap the **System Alert Bar**. The **System Alerts** dialog appears, as shown in <FigureRef id="System-Alerts-Modal" />.

<FigureProvider>
    <Figure 
        id="System-Alerts-Modal"

        alt={"System Alerts dialog showing the messages 'Software is up to date.' and ''Write Item' OPC error', with Clear and Close buttons."}
        width="70%"

2. Review the system messages.
3. To remove the displayed messages, select **Clear**. To return to the Software Upgrade screen, select **Close**.

To return to the **Maintenance** submenu, on the **Software Upgrade** screen, select **Exit**.
