# Software Upgrade
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Software Upgrade** function to update the DCU software when a new approved version is available.
    Software updates help keep the DCU current with the latest features, fixes, and security updates.

    To open the Software Upgrade function, proceed as follows:

    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Maintenance**.
    3. Select **Software Upgrade**.

    The **Software Upgrade** screen appears.

    ## Software Upgrade screen
    The following table describes the fields and controls available on the Software Upgrade screen.

    | Field/Button       | Description                                                                               | 
    | :----------------- | :-------------------------------------------------------------------------------------------- | 
    | USB drive          | Selects a USB drive as the source for the software upgrade package. After the user selects this option, the DCU waits for a USB flash drive to be inserted into the USB port.|
    | ITR.com            | Selects ITR.com as the source for the software upgrade package. When this option 
                           is selected, the DCU automatically checks for the available version when the 
                           Software Upgrade screen opens.                                                                |
    | ITR.com via CMAS   | Selects ITR.com through CMAS as the source for the software upgrade package.                  |
    | Current version    | Displays the software version currently installed on the DCU. <br /><br />
                           **Example:** 0.3.0.3                                                                          |
    | Version available  | Displays the software version available from the selected upgrade source. 
                           <br /><br />**Example:** 0.3.0.4                                                              |
    | Upgrade Now        | Starts the software upgrade process. This button becomes available only when a 
                           newer software version is available from the selected source.                                 | 
    | Update process     | Displays the software update progress after the upgrade starts.                               | 
    | Exit               | Closes the Software Upgrade screen and returns to the previous menu.                          | 
    | Menu               | Opens the main navigation menu.                                                               |
    | Task status bar    | Displays the status of the active upgrade task. <br /><br />**Example:** 
                           Update process <br /><br />**Example:** see [Task Status Bar](../../intro.mdx#task-status-bar)
                           for details.                                                                                  |                                                           | 
    | System message bar | Displays the most recent system message at the bottom of the screen. <br /><br />
                           **Example:** Software is up to date. <br /><br />**Note:** see System Message Bar for 
                           details. <br /><br />**Note:**  Double-tap the system message bar to open the 
                           System Alerts modal, which displays up to the last 50 system messages.                        | 

    ## Upgrade through ITR.com
    To upgrade the DCU software from **ITR.com**, proceed as follows:

    1. Open the **Software Upgrade** function. The **Software Upgrade** screen appears.
    2. Select **ITR.com**. The DCU checks for the available software version automatically.
    3. Review the following version information:
        - **Current version**
        - **Version available**
    4. Confirm that the **Version available** is newer than the **Current version**.
    5. Select **Upgrade Now**. The upgrade starts, and the task status bar displays the update status.

    ## Upgrade through a USB drive
    To upgrade the DCU software from a USB drive, proceed as follows:

    1. Open the **Software Upgrade** function. The **Software Upgrade** screen appears.
    2. Select **USB drive**.
    3. Insert the USB flash drive that contains the approved software upgrade package into the USB port.
    4. Review the following version information:
        1. **Current version**
        2. **Version available**
    5. Confirm that the **Version available** is newer than the **Current version**.
    6. Select **Upgrade Now**. The upgrade starts, and the task status bar displays the update status.
    7. Wait until the upgrade process is complete.
    8. Follow any on-screen prompts to finish the upgrade.

    ## Upgrade through CMAS
    To upgrade the DCU software through ITR.com via CMAS, proceed as follows:

    1. Open the **Software Upgrade** function. The **Software Upgrade** screen appears.
    2. Select **ITR.com via CMAS**. 
    3. Wait for the DCU to check the selected upgrade source.
    4. Review the following version information:
        1. **Current version**
        2. **Version available**
    5. Confirm that the **Version available** is newer than the **Current version**.
    6. Select **Upgrade Now**. The upgrade starts, and the task status bar displays the update status.
    7. Wait until the upgrade process is complete.
    8. Follow any on-screen prompts to finish the upgrade.

    ## Check software upgrade messages
    The Software Upgrade screen displays the most recent **system message** in the system message bar at the bottom of the screen.
    
    If the DCU already has the latest approved software version, the system message bar displays: Software is up to date.
    
    No further action is required.
    To review recent system messages, proceed as follows:
    1. Double-tap the **system message bar**. The **System Alerts** modal appears.
        <Figure 
            src="/img/4-DCUSetup/1-Maintenance/5-SoftwareUpgrade/SystemAlertsModal.png" 
            id="SystemAlertsModal" 
            caption="System Alerts modal"
            width="100%"
        /> 
    2. Review the system messages.
    3. Select **Clear** to clear the displayed messages, or select **Close** to return to the Software Upgrade screen.

    To return to the **Main Menu**, select the **Exit** button in the **Software Upgrade screen**. Alternatively, 
    select the **Menu** button in the header.
