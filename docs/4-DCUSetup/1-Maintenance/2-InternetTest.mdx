# Internet Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Internet Test** function to confirm that the DCU is connected to a network and ready for data transmission. The Internet Test screen shows the connection status, number of active connections, interface name, interface type, and connection speed.

    To open the Internet Test function, proceed as follows:

    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Maintenance**.
    3. Select **Internet Test**.

    The **Internet connection status** modal appears.
