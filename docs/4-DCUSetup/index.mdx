Use the **DCU Setup** module to maintain, test, and configure the DCU before field deployment.

## Open the DCU Setup submenu
To open the DCU Setup submenu, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.

The **DCU Setup** submenu appears, as shown in <FigureRef id="DCU-Setup-Submenu" />.

## DCU Setup submodules

The **DCU Setup** submenu contains the following submodules. Each submodule opens its own submenu of functions.

- [**Maintenance**](./1-Maintenance/index.mdx): Runs health checks and hardware tests on the DCU.
- [**Diagnostics**](./2-Diagnostics/index.mdx): Tests communication between the DCU and connected hardware.
- [**Settings**](./3-Settings/index.mdx): Configures device preferences and system settings.
- [**Advanced Settings**](./4-AdvanceSettings/index.mdx): Configures advanced device options. This submodule requires a password.

## Close the DCU Setup submenu
To return to the Home screen, select **Cancel**.
