# DCU Setup

The **DCU Setup** menu provides access to the main configuration, diagnostic, and maintenance functions for the DCU. Technicians and authorized users can use this menu to review system status, configure device settings, run hardware diagnostics, and perform maintenance tasks before field deployment.

To open the DCU Setup submenu, proceed as follows:

1. From the **Main Menu**, select **DCU Setup**.
