Use the **Diagnostics** submodule to verify communication between the DCU and connected hardware components. Its functions let you test communication interfaces, review measurement values, and verify software and hardware version information.

To open the Diagnostics submenu, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Diagnostics**.

## Diagnostics functions

The **Diagnostics** submenu contains the following functions:

- [**Accelerometer Tests**](./1-AccelerometerTests.mdx): Checks accelerometer operation, connectivity, and signal quality.
- [**Tachometer Tests**](./2-TachometerTests.mdx): Checks the tachometer speed signal.
- [**Voltage Tests**](./3-VoltageTests.mdx): Checks power rails, signal channels, and auxiliary inputs.
- [**Measurement Tests**](./4-MeasurementTests.mdx): Collects real-time vibration data from connected sensors.
- [**Screenshots**](./5-Screenshots.mdx): Views, sends, or deletes stored screenshots.
- [**Test Filters**](./6-FilterTest.mdx): Checks the performance of dynamic filters.

## Close the Diagnostics submenu

- To return to the **DCU Setup** submenu, select **Back**.
- To return to the Home screen, select **Cancel**.
