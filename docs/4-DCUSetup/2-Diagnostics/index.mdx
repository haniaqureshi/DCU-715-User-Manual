# Diagnostics

The **Diagnostics** submenu provides tools that help technicians verify communication between the DCU and 
connected hardware components. Use this submenu to test communication interfaces, review measurement 
values, and verify software and hardware version information.

To open the Diagnostics submenu, proceed as follows:

To open the Diagnostics submenu, proceed as follows:

    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Diagnostics**.
    3. The **Diagnostics** submenu appears.
