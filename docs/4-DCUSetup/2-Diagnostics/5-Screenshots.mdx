# Screenshots

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Screenshots** function to view, send, or delete screenshots that are stored on the DCU. If no screenshots are available, the screen displays a message that says so.

To open the Display Screenshots screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Diagnostics**.
4. From the **Diagnostics** submenu, select **Screenshots**.

The **Display Screenshots** screen appears, as shown in <FigureRef id="Display-Screenshots-Screen" />.

## Display Screenshots screen

The following table describes the fields and controls available on the Display Screenshots screen, as shown in <FigureRef id="Display-Screenshots-Screen" />.

| Option                       | Description |
| :--------------------------- | :---------- |
| Display screenshots (0 of 0) | Displays the total number of screenshots on the DCU and the position of the screenshot that's shown. <br />**Example:** 0 of 0 |
| Screenshot area              | Displays the selected screenshot. If no screenshots are available, the screen displays "No screenshots available." |
| ∧ (Up)                       | Scrolls to the previous screenshot in the list. |
| ∨ (Down)                     | Scrolls to the next screenshot in the list. |
| Send                         | Sends the selected screenshot. |
| Delete                       | Deletes the selected screenshot from the DCU. |
| Cancel                       | Closes the Display Screenshots screen and returns to the Diagnostics submenu. |

## View and manage screenshots

To view and manage screenshots, follow these steps:

1. Open the **Display Screenshots** screen. If the screen displays "No screenshots available," there are no screenshots to manage. To return to the **Diagnostics** submenu, select **Cancel**.
2. To check the total number of screenshots, review the screenshot counter at the top of the screen.
3. To scroll through the screenshots, select **∧** or **∨**.
4. To send a screenshot, select the screenshot, and then select **Send**. The DCU sends the selected screenshot.
5. To delete a screenshot, select the screenshot, and then select **Delete**. The DCU removes the selected screenshot from the device.

To return to the **Diagnostics** submenu, select **Cancel**.
