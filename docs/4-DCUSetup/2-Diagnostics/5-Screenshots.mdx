# Screenshots

    Use the **Screenshots option**  to view, send, or delete screenshots that are stored on the DCU. 
    If no screenshots are available, the screen displays a message indicating that no screenshots are stored on the device.

    To open the Display Screenshots screen, proceed as follows:

    1. From the Main Menu, select **Diagnostics**.
    2. From the Diagnostics submenu, select **Screenshots**.

    ## View and manage screenshots

    To view and manage screenshots, proceed as follows:
        1. Open the Display Screenshots screen.<br />
            a. If no screenshots are available, the screen displays **No screenshots available.**<br />
            b. Select **Cancel** to return to the Diagnostics submenu.<br />
            c. If screenshots are available, proceed with the steps below. <br />
                &nbsp; &nbsp; i.   Review the screenshot counter at the top of the screen to confirm the total number of available &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; screenshots.<br />
                &nbsp; &nbsp; ii.  Use the **up** and **down** arrow buttons to scroll through the available screenshots.<br />
                &nbsp; &nbsp; iii. To send a screenshot, select the desired screenshot and select **Send**. The DCU sends the selected &nbsp; &nbsp; &nbsp; &nbsp; screenshot.<br />
                &nbsp; &nbsp; iv.  To delete a screenshot, select the desired screenshot and select **Delete**. The DCU removes the &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; selected screenshot from the device.

    ## Display Screenshots screen

    The following fields and controls available on the Display Screenshots screen are shown in <FigureRef id="Display-Screenshots-Screen" />.

    | Options                      | Description                                                                                                                                  |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              
    | :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
    | Display screenshots (0 of 0) | Displays the total number of screenshots available on the DCU and the index of the currently displayed screenshot. <br />**Example:** 0 of 0 |  
    | Screenshot area              | Displays the currently selected screenshot. If no screenshots are available, the screen displays: **“No screenshots available”**             |
    | ∧ (Up)                       | Scrolls to the previous screenshot in the list.                                                                                              |
    | ∨ (Down)                     | Scrolls to the next screenshot in the list.                                                                                                  |
    | Send                         | Send the currently selected screenshot.                                                                                                      |
    | Delete                       | Deletes the currently selected screenshot from the DCU.                                                                                      |  
    | Cancel                       | Closes the Display Screenshots screen and returns to the Diagnostics submenu.                                                                |

    Select **Cancel** to return to the Diagnostics submenu.
