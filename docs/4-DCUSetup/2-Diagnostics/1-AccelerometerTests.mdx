# Accelerometer Tests
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Accelerometer Tests** function to verify accelerometer operation, sensor connectivity, and 
    signal quality. The function displays measurement data and provides diagnostic tools that help 
    identify sensor, cable, or connection issues before performing field measurements.

    To open the Accelerometer Tests function, proceed as follows:

    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Diagnostics**.
    3. Select **Accelerometer Tests**.

    The **Accelerometer Tests** screen appears.
