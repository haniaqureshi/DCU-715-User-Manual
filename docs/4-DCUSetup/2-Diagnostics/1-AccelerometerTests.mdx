# Accelerometer Tests

<FigureProvider>
    Use the **Accelerometer Tests** function to verify accelerometer operation, sensor connectivity, and 
    signal quality. The function displays measurement data and provides diagnostic tools that help 
    identify sensor, cable, or connection issues before performing field measurements.

    To open the Accelerometer Tests function, proceed as follows:

    1. From the **Main Menu**, select **DCU Setup**.
    2. From the **DCU Setup** submenu, select **Diagnostics**.
    3. Select **Accelerometer Tests**.

    The **Accelerometer Tests** screen appears.

    :::note

    When the **Accelerometer Tests** screen opens, the DCU automatically starts a measurement using the 
    most recently saved test configuration. The graph begins displaying data immediately, and the 
    [Task status bar displays](../../intro.mdx#task-status-bar) **Measurement** to indicate that a measurement is currently in progress.

    :::

    ## Run an Accelerometer Test
    To run an accelerometer test, proceed as follows:

    1. Connect the accelerometer sensor and cable to the DCU.
    2. Open the **Accelerometer Tests** screen. The DCU automatically starts a measurement using the previously saved configuration.
    3. If necessary, select the **Options** button and configure the following settings:
        - Plot Type
        - Source
        - Cable Test
        - Channel
    4. Select the Save button. The DCU applies the new settings and continues displaying measurement data.
    5. Review the following values during the test:
        - Plot Type
        - Source
        - Cable Test
        - Bias X, Bias Y, and Bias Z
        - Meas. nr
        - Graph data
    
    :::warning

    Do not disconnect the accelerometer cable during a measurement unless you are intentionally checking 
    cable connectivity. Disconnecting the cable may interrupt the signal shown on the graph.

    :::

    6. Select the **Stop** button to stop the measurement. The **Measurement** indicator is removed from the **Task Status Bar**.
    7. Select the **Reset** button to clear the displayed graph data and begin a new measurement session.

    :::warning

    The **Reset** button clears the currently displayed graph data. Record any required observations before 
    selecting **Reset.**

    :::

    To return to the Main Menu, select the **Menu** button in the header.
