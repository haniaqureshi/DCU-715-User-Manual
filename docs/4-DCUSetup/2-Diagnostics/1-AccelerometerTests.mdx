# Accelerometer Tests

import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Accelerometer Tests** function to verify accelerometer operation, sensor connectivity, and 
    signal quality. The function displays measurement data and provides diagnostic tools that help 
    identify sensor, cable, or connection issues before you take field measurements.

    To open the Accelerometer Tests function, follow these steps:

    1. On the Home screen, select **Menu**. The **Main Menu** appears.
    2. From the **Main Menu**, select **DCU Setup**.
    3. From the **DCU Setup** submenu, select **Diagnostics**.
    4. From the **Diagnostics** submenu, select **Accelerometer Tests**.

    The **Accelerometer Tests** screen appears.

    :::note

    When the **Accelerometer Tests** screen opens, the DCU automatically starts a measurement that uses the 
    most recently saved test configuration. The graph starts displaying data immediately, and the 
    [task status bar](../../intro.mdx#task-status-bar) displays **Measurement** to show that a measurement is in progress.

    :::

    ### Accelerometer Tests Options screen
    The following table describes the configuration options, as shown in <FigureRef id="AccelerometerTests-Options-Screen"/>.

    | Option     | Description                                                                                                                                                                                                                                 |
    | :--------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    | Plot Type  | **<u>RMS Trend</u>** <br />Displays measurement data as RMS trend values over time. <br /><hr /> **<u>Real Time</u>** <br />Displays live accelerometer signals in real time.                                                               |
    | Source     | **<u>Accel</u>** <br />Displays accelerometer measurement data. <br /><hr /> **<u>Bias</u>** <br />Displays sensor bias voltage values. <br /><br />**Note:** If the **Source** options are unavailable, clear the **Cable Test** checkbox.|
    | Cable Test | Turns cable integrity testing on or off. <br /><br /> **Note:** When you select the **Cable Test** checkbox, the **Source** options become unavailable.                                                                                               |
    | Channel    | **<u>X</u>** <br />Turns the X-axis channel on or off.<hr />**<u>Y</u>** <br />Turns the Y-axis channel on or off. <br /><hr /> **<u>Z</u>** <br />Turns the Z-axis channel on or off.                                          |
    | Cancel     | Closes the Options screen without saving changes.                                                                                                                                                                                           |
    | Save       | Saves the selected settings and returns to the Accelerometer Tests screen.                                                                                                                                                                  |

    ## Run an accelerometer test
    To run an accelerometer test, follow these steps:

    1. Connect the accelerometer sensor and cable to the DCU.
    2. Open the **Accelerometer Tests** screen. The DCU automatically starts a measurement that uses the previously saved configuration.
    3. If necessary, select **Options**, and then configure the following settings:
        - Plot Type
        - Source
        - Cable Test
        - Channel
    4. Select **Save**. The DCU applies the new settings and continues displaying measurement data.
    5. Review the following values during the test:
        - Plot Type
        - Source
        - Cable Test
        - Bias X, Bias Y, and Bias Z
        - Meas. nr
        - Graph data
    
    :::warning

    Don't disconnect the accelerometer cable during a measurement unless you're checking cable 
    connectivity. Disconnecting the cable might interrupt the signal shown on the graph.

    :::

    6. To stop the measurement, select **Stop**. The **Measurement** indicator no longer appears in the task status bar.
    7. To clear the displayed graph data and start a new measurement session, select **Reset**.

    :::warning

    **Reset** clears the displayed graph data. Record any observations that you need before you 
    select **Reset**.

    :::

    To return to the **Main Menu**, in the header, select **Menu**.
