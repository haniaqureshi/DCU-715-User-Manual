# Voltage Tests

    Use the Voltage Tests function to verify that the DCU power rails, signal channels, and auxiliary 
    inputs are operating within acceptable voltage ranges. This diagnostic function helps technicians
    identify power supply issues, abnormal sensor inputs, and hardware faults before performing 
    measurements.

    To open the Voltage Tests function, proceed as follows:

    1. From the Main Menu, select DCU Setup.
    2. From the DCU Setup submenu, select Diagnostics.
    3. Select Voltage Tests

    The **Start Voltage Tests** screen appears as shown in <FigureRef id="Start-Voltage-Tests-Screen"/>.

    ## Run Voltage Tests
    To run voltage tests, proceed as follows:

    To run voltage tests, proceed as follows:
    1. In the **Start Voltage Tests** screen, select **Start voltage tests.**
    2. Observe the displayed voltage values as the DCU evaluates each channel.
    3. Review the following sections:
        - Internal Voltages
        - Signal Channels
        - Auxiliary Channels: AC
        - Auxiliary Channels: DC
        - Other channels
    4. Verify that voltage readings remain stable and within expected operating ranges.
    5. Select **Pause** to stop updating the displayed values and review the current readings.

    When a test is running:

    1. Measured values update in real time.
    2. Values within the acceptable operating range are displayed in **light green**, see **Figure 5.17**.
    3. The value currently being tested is highlighted in **dark green**, see Figure 5.3.x (above).
    4. Values outside the acceptable operating range are displayed in **orange**, see Figure 5.3.x (above).
        1. When an out-of-range condition is detected, the associated warning message is displayed in the lower-right corner of the screen, Figure 5.3.x (above).
            1. **Example:** Battery voltage too high
    
    :::warning 

    If a voltage value is displayed in orange, the measured value is outside the expected operating
    range and may indicate a hardware, power supply, or sensor-related issue.

    :::

    ## Run Limit Tests

    Use the Limit Tests function to compare measured voltages against predefined operating limits.

    To run limit tests, proceed as follows:

    :::note

    The limit test starts automatically when **Limit Tests** are selected from the **Start Voltage Tests** screen.

    :::

    In the **Start Voltage Tests** screen, select **Limit Tests**.

    1. The **Limit Tests** screen appears with the test already running. 
    2. Review the displayed voltage values and limit violation counts.
    3. Observe any channels that exceed their configured limits.
    4. Select **Pause** to stop the running limit test.

    :::note

    When **Pause** is selected in the **Limit Tests** screen, the system message bar displays **Stop request**. 
    After the test has stopped, the system message bar displays **Ready**.
    
    :::
