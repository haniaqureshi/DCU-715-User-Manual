# Voltage Tests

import Figure from "@site/src/components/Figure";

<FigureProvider>
    Use the **Voltage Tests** function to verify that the DCU power rails, signal channels, and auxiliary 
    inputs are operating within acceptable voltage ranges. This diagnostic function helps you
    identify power supply issues, abnormal sensor inputs, and hardware faults before you take 
    measurements.

    To open the Voltage Tests function, follow these steps:

    1. On the Home screen, select **Menu**. The **Main Menu** appears.
    2. From the **Main Menu**, select **DCU Setup**.
    3. From the **DCU Setup** submenu, select **Diagnostics**.
    4. From the **Diagnostics** submenu, select **Voltage Tests**.

    The **Start Voltage Tests** screen appears, as shown in <FigureRef id="Start-Voltage-Tests-Screen"/>.

    ## Run Voltage Tests

    To run voltage tests, follow these steps:

    1. On the **Start Voltage Tests** screen, select **Start voltage tests**.
    2. Observe the displayed voltage values as the DCU evaluates each channel.
    3. Review the following sections:
        - Internal Voltages
        - Signal Channels
        - Auxiliary Channels: AC
        - Auxiliary Channels: DC
        - Other channels
    4. Verify that voltage readings remain stable and within expected operating ranges.
    5. To stop updating the displayed values and review the current readings, select **Pause**.

    While a test is running, as shown in <FigureRef id="Voltage-TestsIn-Progress" />:

    - Measured values update in real time.
    - Values within the acceptable operating range appear in light green.
    - The value that's being tested is highlighted in dark green.
    - Values outside the acceptable operating range appear in orange. When the DCU detects an out-of-range value, a warning message appears in the lower-right corner of the screen, such as "Battery voltage too high."
    
    :::warning 

    If a voltage value appears in orange, the measured value is outside the expected operating
    range and might indicate a hardware, power supply, or sensor-related issue.

    :::

    ## Run limit tests

    Use the **Limit Tests** function to compare measured voltages against predefined operating limits.

    To run limit tests, follow these steps:

    1. On the **Start Voltage Tests** screen, select **Limit Tests**. The **Limit Tests** screen appears, and the limit test starts automatically. 
    2. Review the displayed voltage values and limit violation counts.
    3. Check for any channels that exceed their configured limits.
    4. To stop the limit test, select **Pause**.

    :::note

    When you select **Pause** on the **Limit Tests** screen, the system message bar displays "Stop request." 
    After the test stops, the system message bar displays "Ready."
    
    :::
