# Measurement Tests

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

    Use the Measurement Tests function to collect real-time vibration data from connected sensors. 
    This screen displays current measurement options, output values, and live chart data. 
    Technicians can configure measurement settings, select a sensor, store collected data to a route, 
    and monitor sensor channel status during the measurement process.

    To open the Measurement Tests screen, proceed as follows:

    1. From the **Main Menu**, select **Measurement Tests**.
    2. The Measurement Tests screen appears as shown in the <FigureRef id="Measurement-Tests-Screen" /> below.

    ## Start Measuring 

    Use the Start Measuring function to begin real-time data collection from the connected sensor. 
    When measurement starts, the DCU collects output values and displays a live chart.  

    ## Run a measurement

    To start a measurement, proceed as follows:

    1. On the Measurement Tests screen, select **Start Measuring**. The task status bar displays **Waiting**.
    2. Wait for the DCU to initialize the measurement session. The task status bar updates to **Ready**, and the chart area displays a live data graph as shown in the <FigureRef id="Start-Measurement" />.
    3. Monitor the following values in the **Output** section during the measurement:
        - DC Off (X, Y, Z)
        - RMS (X, Y, Z)
    4. Review the live chart to observe amplitude data in real time.
    5. Select **Break** to pause the measurement session, or select **Store Data** to save the collected data.

    ## Store Data

    Use the **Store Data** function to save collected measurement data to a selected route. 
    When the technician selects Store Data, the Select Route modal appears and displays the available routes stored on the DCU.

    To store measurement data, proceed as follows:

    1. On the Measurement Tests screen, select **Store Data**. The Select Route screen will appear as shown in the <FigureRef id="Select-Route-List-Screen" />.

    <FigureProvider>
        <Figure 
            id="Select-Route-List-Screen" 
            src="/img/4-DCUSetup/2-Diagnostics/4-MeasurementTests/Select-Route-List-Screen-Light.jpg"
            srcDark="/img/4-DCUSetup/2-Diagnostics/4-MeasurementTests/Select-Route-List-Screen-Dark.png" 
            caption="Select Route list Screen"

    2. Select the desired route from the list. The selected route is highlighted.
    3. Select **Select**. The DCU saves the measurement data to the selected route and returns to the Measurement Tests screen and displays **Store Data** in the task status bar.

    ## Sensor Selection modal

    The following fields and controls available in the Sensor Selection modal as shown in the <FigureRef id="" />.
    
    | Field/Button           | Description                                                                                                                          |                                                                                                                                          
    | :--------------------- | :----------------------------------------------------------------------------------------------------------------------------------- |
    | Sensor                 | Selects the sensor type from the available options using the dropdown. <br />**Example:** Triaxial Accelerometer                     |
    | Sensitivity            | Selects the sensor sensitivity from the available options using the dropdown.<br />**Example:** 10 mv/g                              |
    | Checks Cable Integrity | Enables a cable integrity check when the sensor is confirmed. When selected, the DCU checks the cable connection before proceeding.  |
    | Cancel                 | Closes the Sensor Selection modal without saving changes and returns to the Measurement Tests screen.                                |
    | Ok                     | Saves the sensor configuration and returns to the Measurement Tests screen.                                                          |

    ## Configure the sensor

    1. To configure the sensor, proceed as follows:
    2. Select the desired sensor type from the **Sensor** dropdown.
    3. Select the desired sensitivity value from the **Sensitivity** dropdown.
    4. To enable a cable integrity check, select the **Checks Cable Integrity** checkbox.
    5. Select **Ok**. The DCU saves the sensor configuration and returns to the Measurement Tests screen. 
    The updated sensor details appear in the **Options** section of the Measurement Tests screen.
    6. To close the Sensor Selection modal without saving changes, select **Cancel**.

    ## Configure measurement options

    To configure the measurement options, proceed as follows:

    1. On the Option screen you can:<br />
        a.  Select the desired Frequency from the dropdown.<br />
        b.  Select the desired Resolution from the dropdown.<br />
        c.  Select the desired Averages from the dropdown.<br />
        d.  Select the desired Mode from the available options:<br />
            &nbsp; &nbsp; i.   Spectrum<br />
            &nbsp; &nbsp; ii.  Time<br />
            &nbsp; &nbsp; iii. Demod<br />
            &nbsp; &nbsp; iv.  URE<br />
            &nbsp; &nbsp; v.   Phase<br />
            &nbsp; &nbsp; vi.  Waterfall

        e.  Select the **Show Channel** axis (X, Y, or Z) to specify which axis to measure.<br />
        f.  Enable or disable the following options as required by selecting the corresponding checkbox or &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; radio button:<br />
            &nbsp; &nbsp; i.    Cable check<br />
            &nbsp; &nbsp; ii.   Integrate<br />
            &nbsp; &nbsp; iii.  Calibrate<br />
            &nbsp; &nbsp; iv.   Hipass<br />
            &nbsp; &nbsp; v.    Ac/Dc Couple<br />
            &nbsp; &nbsp; vi.   Use Anti-Alias Filter<br />
            &nbsp; &nbsp; vii.  1 Shot<br />
            &nbsp; &nbsp; viii. Max.Chart

    :::note
        - When **Calibrate** is selected, the **Cable Check** option becomes disabled.
        - When **Waterfall** mode is selected, the Waterfall section appears at the bottom of the screen. 
        Configure the **Plots** and **Interval** fields as required.
    :::

    2. Select **Save**. The DCU saves the configured options and returns to the Measurement Tests screen.
    3. On the Measurement Tests screen, select **Start Measuring**. The Sensor Channel Status modal appears and displays the progress of the sensor check for channels X, Y, and Z.

    <FigureProvider>
        <Figure 
            id="Sensor-Channel-Status-pop-up"

            caption="Sensor Channel Status pop-up"

    4. Wait for the sensor channel status check to complete. After the check is complete, the Sensor Channel Status modal closes and the task status bar displays **Ready**. 
    The chart area displays live measurement data according to the selected configuration.
