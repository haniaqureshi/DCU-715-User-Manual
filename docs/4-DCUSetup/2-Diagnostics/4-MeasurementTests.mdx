# Measurement Tests

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Measurement Tests** function to collect real-time vibration data from connected sensors. This screen displays the current measurement options, output values, and live chart data. You can configure measurement settings, select a sensor, store collected data to a route, and monitor sensor channel status during the measurement.

To open the Measurement Tests screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Diagnostics**.
4. From the **Diagnostics** submenu, select **Measurement Tests**.

The **Measurement Tests** screen appears, as shown in <FigureRef id="Measurement-Tests-Screen" />.

## Run a measurement

Use **Start Measuring** to start collecting real-time data from the connected sensor. When the measurement starts, the DCU collects output values and displays a live chart.

To run a measurement, follow these steps:

1. On the **Measurement Tests** screen, select **Start Measuring**. The task status bar displays **Waiting**.
2. Wait for the DCU to start the measurement session. The task status bar changes to **Ready**, and the chart area displays a live data graph, as shown in <FigureRef id="Start-Measurement" />.
3. During the measurement, monitor the following values in the **Output** section:
    - DC Off (X, Y, Z)
    - RMS (X, Y, Z)
4. Review the live chart to observe amplitude data in real time.
5. To pause the measurement session, select **Break**. To save the collected data, select **Store Data**.

## Store measurement data

Use **Store Data** to save collected measurement data to a route. When you select **Store Data**, the **Select Route** screen appears and lists the routes stored on the DCU.

To store measurement data, follow these steps:

1. On the **Measurement Tests** screen, select **Store Data**. The **Select Route** screen appears, as shown in <FigureRef id="Select-Route-List-Screen" />.

    <FigureProvider>
        <Figure

### Sensor Selection dialog

The following table describes the fields and controls available in the Sensor Selection dialog, as shown in <FigureRef id="Sensor-Selection-Screen" />.

| Field/Button           | Description |
| :--------------------- | :---------- |
| Sensor                 | Selects the sensor type from the list. <br />**Example:** Triaxial Accelerometer |
| Sensitivity            | Selects the sensor sensitivity from the list.<br />**Example:** 10 mV/g |
| Checks Cable Integrity | Turns on a cable integrity check when you confirm the sensor. When this checkbox is selected, the DCU checks the cable connection before it continues. |
| Cancel                 | Closes the Sensor Selection dialog without saving changes and returns to the Measurement Tests screen. |
| Ok                     | Saves the sensor configuration and returns to the Measurement Tests screen. |

### Select the sensor type and sensitivity

To configure the sensor, follow these steps:

1. From the **Sensor** list, select the sensor type.
2. From the **Sensitivity** list, select the sensitivity value.
3. To turn on a cable integrity check, select the **Checks Cable Integrity** checkbox.
4. Select **Ok**. The DCU saves the sensor configuration and returns to the **Measurement Tests** screen. The updated sensor details appear in the **Options** section of the Measurement Tests screen.

To close the **Sensor Selection** dialog without saving changes, select **Cancel**.

### Set the measurement options

To configure the measurement options, follow these steps:

1. On the **Options** screen, set the following options as needed:
    1. From the **Frequency** list, select the frequency.
    2. From the **Resolution** list, select the resolution.
    3. From the **Averages** list, select the number of averages.
    4. Under **Mode**, select **Spectrum**, **Time**, **Demod**, **URE**, **Phase**, or **Waterfall**.
    5. Under **Show Channel**, select the axis to measure: **X**, **Y**, or **Z**.
    6. Select or clear the checkboxes or options for the following settings:
        - **Cable check**
        - **Integrate**
        - **Calibrate**
        - **Hipass**
        - **Ac/Dc Couple**
        - **Use Anti-Alias Filter**
        - **1 Shot**
        - **Max.Chart**

    :::note

    - When **Calibrate** is selected, **Cable Check** is unavailable.
    - When **Waterfall** mode is selected, the **Waterfall** section appears at the bottom of the screen. Set the **Plots** and **Interval** fields as needed.

    :::

2. Select **Save**. The DCU saves the configured options and returns to the **Measurement Tests** screen.
3. On the **Measurement Tests** screen, select **Start Measuring**. The **Sensor Channel Status** dialog appears and shows the progress of the sensor check for channels X, Y, and Z, as shown in <FigureRef id="Sensor-Channel-Status-pop-up" />.

4. Wait for the sensor channel status check to finish. When the check is complete, the **Sensor Channel Status** dialog closes and the task status bar displays **Ready**. The chart area displays live measurement data based on the selected configuration.
