# Filter Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

    Use the **Test Filters option** to verify the performance of dynamic filters configured on the DCU. 
    Technicians can run a range test or a filter test and review the results on a live frequency chart.
    The Options screen allows the technician to configure the filter type and related parameters before running a test.

    To open the Test Filters screen, proceed as follows:

    1. From the Main Menu, select **Diagnostics**.
    2. From the Diagnostics submenu, select **Test Filters**.

    ## Run Range Test

    Use the **Run Range Test function** to test the pre-selected frequency range and display the result on the frequency chart.
    To run a range test, proceed as follows:

    1. On the Test Filters screen, select **Run Range Test**. 
    2. The DCU runs the range test and displays the frequency chart according to the selected range configuration. 
    3. Review the frequency chart to verify the filter performance across the selected range as shown in the <FigureRef id="Test-Filters-Screen-2" />.

    ## Configure filter options
    To configure the filter options, proceed as follows:

    1. Select the desired frequency range from the **Pre-Selected Ranges** dropdown.
    2. Under **Dynamic Filter (all in hertz)**, select the desired filter type:

        a. **LP** - Low Pass filter. When selected, the Fmax field becomes active and displays the upper corner &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; frequency value.<br />
        b. **HP** - High Pass filter. When selected, the upper corner frequency field becomes active. All other &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; corner fields are disabled.<br />
        c. **BP** - Band Pass filter. When selected, both the lower and upper corner frequency fields become &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; active.<br />
        d. **BS** - Band Stop filter. When selected, both the lower and upper corner frequency fields become &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; active.<br />

    3. To enter values for the following fields, select the field. The numeric keypad appears as shown in <FigureRef id="Test-Filters-Pin-Pad" />. 
    4. Enter the desired value using the numeric keypad.

        &nbsp; a.  **fsamp (fmax x 2.56)** - Enter the sampling frequency value.<br /> 
        &nbsp; b. **Sample Rate** - Enter the sample rate value.<br />
        &nbsp; c. **Fmax** - Enter the maximum frequency value.<br />
        &nbsp; d. **Taps** - Enter the number of filter taps.<br />

    5. To enable the maximum chart display, select the **Max. chart** checkbox.
    6. Select **Save**. The DCU saves the configured filter options and returns to the Test Filters screen, where the frequency chart displays the filter results according to the selected configuration. 
    7. To reset the filter configuration to default values, select **Reset**.
    8. To close the Options screen without saving changes, select **Cancel**.
