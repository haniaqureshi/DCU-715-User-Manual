# Filter Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Test Filters** function to verify the performance of dynamic filters configured on the DCU. You can run a range test or a filter test and review the results on a live frequency chart. On the **Options** screen, you can configure the filter type and related parameters before you run a test.

To open the Test Filters screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Diagnostics**.
4. From the **Diagnostics** submenu, select **Test Filters**.

The **Test Filters** screen appears, as shown in <FigureRef id="Test-Filters-Screen-1" />.

## Test Filters screen

The following table describes the fields, sections, and controls available on the Test Filters screen, as shown in <FigureRef id="Test-Filters-Screen-1" />.

| Option          | Description |
| :-------------- | :---------- |
| Options         | **<u>Pre-Selected Ranges</u>**<br />Displays the selected frequency range.<br />**Example:** 50,000 CPM (4 Code)<br /><br />**<u>Dynamic Filter (all in hertz)</u>**<br />Displays the dynamic filter parameters.<br /> <ul><li>**Filter**<br />Displays the selected filter type.<br />**Example:** LP </li></ul><hr /> <ul><li>**Sample Rate**<br />Displays the sample rate value in hertz.<br />**Example:** 12,800</li></ul><hr /> <ul><li>**fsamp (fmax x 2.56)**<br />Displays the calculated sampling frequency.<br />**Example:** 2133.333</li></ul><hr /> <ul><li>**Fmax**<br />Displays the maximum frequency value.<br />**Example:** 833.333</li></ul><hr /> <ul><li>**Taps**<br />Displays the number of filter taps.<br />**Example:** 1,500</li></ul> |

## Run a range test

Use **Run Range Test** to test the pre-selected frequency range and display the result on the frequency chart.

To run a range test, follow these steps:

1. On the **Test Filters** screen, select **Run Range Test**. The DCU runs the range test and displays the frequency chart based on the selected range configuration.
2. Review the frequency chart to verify the filter performance across the selected range, as shown in <FigureRef id="Test-Filters-Screen-2" />.

### Options screen

The following table describes the fields and controls available on the Options screen, as shown in <FigureRef id="Test-Filters-Options-Screen" />.

| Option                        | Description |
| :---------------------------- | :---------- |
| Pre-Selected Ranges           | Selects the frequency range from the list.<br /> **Example:** 50,000 CPM (4 Code) |
| Dynamic Filter (all in hertz) | Displays the dynamic filter configuration section. <br /><ul><li>**LP:**<br />Selects the low-pass filter type. When selected, the **Fmax** field becomes available and displays the upper corner frequency value.</li></ul><hr /> <ul><li>**HP:**<br />Selects the high-pass filter type. When selected, the upper corner frequency field becomes available. All other corner fields are unavailable.</li></ul><hr /> <ul><li>**BP:**<br />Selects the band-pass filter type. When selected, the upper and lower corner frequency fields become available.</li></ul><hr /> <ul><li>**BS:**<br />Selects the band-stop filter type. When selected, the upper and lower corner frequency fields become available.</li></ul> |
| fsamp (fmax x 2.56)           | Displays the calculated sampling frequency in hertz.<br /> **Example:** 2133.3333 |
| Sample Rate                   | Displays the sample rate in hertz. <br />**Example:** 12800 |
| Fmax                          | Displays the maximum frequency value in hertz. <br />**Example:** 833.333 |
| Taps                          | Displays the number of filter taps. <br />**Example:** 1500 |
| Max. chart                    | Turns the maximum chart display on or off. |
| Reset                         | Resets the filter configuration to the default values. |
| Cancel                        | Closes the Options screen without saving changes and returns to the Test Filters screen. |
| Save                          | Saves the filter configuration changes and returns to the Test Filters screen. |

### Set the filter options

To configure the filter options, follow these steps:

1. From the **Pre-Selected Ranges** list, select the frequency range.
2. Under **Dynamic Filter (all in hertz)**, select the filter type:
    - **LP** (low-pass filter): The **Fmax** field becomes available and displays the upper corner frequency value.
    - **HP** (high-pass filter): The upper corner frequency field becomes available. All other corner fields are unavailable.
    - **BP** (band-pass filter): The lower and upper corner frequency fields become available.
    - **BS** (band-stop filter): The lower and upper corner frequency fields become available.
3. To enter a value, select the field. The numeric keypad appears, as shown in <FigureRef id="Test-Filters-Pin-Pad" />.

4. Use the numeric keypad to enter values in the following fields:
    - **fsamp (fmax x 2.56)**: The sampling frequency value.
    - **Sample Rate**: The sample rate value.
    - **Fmax**: The maximum frequency value.
    - **Taps**: The number of filter taps.
5. To turn on the maximum chart display, select the **Max. chart** checkbox.
6. Select **Save**. The DCU saves the configured filter options and returns to the **Test Filters** screen. The frequency chart displays the filter results based on the selected configuration. 

To reset the filter configuration to the default values, select **Reset**. To close the **Options** screen without saving changes, select **Cancel**.

To return to the **Main Menu**, in the header, select **Menu**.
