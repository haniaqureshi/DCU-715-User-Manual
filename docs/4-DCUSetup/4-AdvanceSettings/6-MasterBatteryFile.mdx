# Master Battery File

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Master Battery File** function to generate a master battery curve for the DCU. This process maps the discharge characteristics of the internal battery. The DCU uses this curve to show accurate battery percentage readings during operation.

To open the Generate Master Battery Curve dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **Master Battery File**.

The **Generate Master Battery Curve** dialog appears, as shown in <FigureRef id="Generate-Master-Battery-Curve-Modal" />.

## Generate Master Battery Curve dialog

The following table describes the fields and controls available in the Generate Master Battery Curve dialog, as shown in <FigureRef id="Generate-Master-Battery-Curve-Modal" />.

| Field/Button    | Description |
| :-------------- | :---------- |
| Battery Voltage | Displays the current battery voltage reading while the curve is being generated. |
| Start           | Starts generating the master battery curve. |
| Stop            | Stops generating the master battery curve and saves the collected data. |
| Cancel          | Closes the Generate Master Battery Curve dialog and returns to the Advanced Settings submenu. |

:::info

When the process is complete, the DCU creates a battery curve file. The System Alert Bar at the bottom of the screen displays the file location, such as "File 'C:\CVASYS\ITR100\Master Battery Curve.txt' has been created."

:::

## Generate the master battery curve

To generate the master battery curve, follow these steps:

1. Make sure that the DCU is fully charged and disconnected from any external power source.
2. In the **Generate Master Battery Curve** dialog, select **Start**. The DCU starts generating the master battery curve, and the **Battery Voltage** field displays the current voltage reading in real time.
3. Let the process run until enough data is collected.
4. Select **Stop**. The DCU stops the process and saves the battery curve data. The System Alert Bar displays the location of the master battery curve file.

To close the **Generate Master Battery Curve** dialog, select **Cancel**.

:::note

After the process starts, **Cancel** is unavailable. **Cancel** becomes available again only after you select **Stop**.

:::
