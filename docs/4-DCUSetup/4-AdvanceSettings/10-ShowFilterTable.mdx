# Show Filter Table

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Show Filter Table** function to view the digital filter profiles stored in the DCU signal processing library. This dialog is read-only. It displays the filter configuration parameters for each stored filter profile.

To open the Show Filter Table dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **Show Filter Table**.

The **Show Filter Table** dialog appears, as shown in <FigureRef id="Show-Filter-Table-Modal" />.

## Show Filter Table dialog

The following table describes the columns and controls in the Show Filter Table dialog, as shown in <FigureRef id="Show-Filter-Table-Modal" />.

| Column/Button | Description |
| :------------ | :---------- |
| ID            | Displays the filter profile ID number. <br />**Example:** 0 |
| Description   | Displays the name and frequency range of the filter profile. <br />**Example:** Low Pass - 5000 CPM |
| SampFrq       | Displays the sampling frequency assigned to the filter profile. <br />**Example:** 12800 |
| Type          | Displays the filter type. <br />**Example:** 0 |
| Taps          | Displays the number of filter taps configured for the profile. <br />**Example:** 1600 |
| SBUpper       | Displays the upper stop band frequency value. <br />**Example:** 106 |
| SBLower       | Displays the lower stop band frequency value. <br />**Example:** 83 |
| PBUpper       | Displays the upper passband frequency value. <br />**Example:** 2500 |
| PBLower       | Displays the lower passband frequency value. <br />**Example:** 1666 |
| PBR           | Displays the passband ripple value. |
| ∧ (Up)        | Scrolls up through the filter table list. |
| ∨ (Down)      | Scrolls down through the filter table list. |
| Cancel        | Closes the Show Filter Table dialog and returns to the Advanced Settings submenu. |

:::note

The Show Filter Table dialog is read-only. You can't edit any values here.

:::

## View the filter table

To view the filter table, follow these steps:

1. In the **Show Filter Table** dialog, select **∧** or **∨** to scroll through the filter table and review the filter profiles.
2. Verify that the filter profile for the configured DFPID appears in the table.

To close the **Show Filter Table** dialog and return to the **Advanced Settings** submenu, select **Cancel**.
