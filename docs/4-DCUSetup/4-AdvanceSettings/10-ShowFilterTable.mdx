# Show Filter Table

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Show Filter Table** function to view the digital filter profiles currently stored in the DCU signal processing library. This screen is read-only and displays the filter configuration parameters for each stored filter profile.
To open the Show Filter Table modal, proceed as follows:

1. From the Advanced Settings submenu, select **Show Filter Table**.
2. The Show Filter Table modal appears as shown in <FigureRef id="Show-Filter-Table-Modal" />.

## Show Filter Table modal
The following columns displayed in the Show Filter Table modal are shown in <FigureRef id="" />.

| Column      | Description                                                                                         |                                                                                                                                          
| :---------- | :-------------------------------------------------------------------------------------------------- |
| ID          | Displays the filter profile ID number. <br />**Example:** 0                                         |
| Description | Displays the name and frequency range of the filter profile. <br />**Example:** Low Pass - 5000 CPM |
| SampFrq     | Displays the sampling frequency assigned to the filter profile. <br />**Example:** 12800            |
| Type        | Displays the number of successful test results. <br />**Example:** 0                                |
| Taps        | Displays the number of filter taps configured for the profile. <br />**Example:** 1600              | 
| SBUpper     | Displays the upper stop band frequency value. <br />**Example:** 106                                |
| SBLower     | Displays the lower stop band frequency value. <br />**Example:** 83                                 |
| PBUpper     | Displays the upper passband frequency value. <br />**Example:** 2500                                |
| PBLower     | Displays the lower passband frequency value. <br />**Example:** 1666                                |
| PBR         | Displays the passband ripple value.                                                                 | 
| ∧ (Up)      | Stop the currently running test.                                                                    |
| ∨ (Down)    | Scrolls down through the filter table list.                                                         |
| Cancel      | Closes the Show Filter Table modal and returns to the Advanced Settings submenu.                    |

:::note

The Show Filter Table modal is read-only. No values can be edited from this screen.

:::

## View the filter table
To view the filter table, proceed as follows:

1. From the Advanced Settings submenu, select **Show Filter Table**. The Show Filter Table modal appears.
2. Use the **∧** and **∨** buttons to scroll through the filter table and review the available filter profiles.
3. Verify that the filter profile corresponding to the configured DFPID is correctly listed in the table.
4. Select **Cancel** to close the Show Filter Table modal and return to the Advanced Settings submenu.
