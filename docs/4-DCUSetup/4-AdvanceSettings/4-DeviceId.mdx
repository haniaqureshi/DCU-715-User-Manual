# Device ID

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Device ID function** to assign or update the unique numerical identification code for the DCU. The device ID
is used to track field units and ensure that measurement data is correctly attributed to the specific device during
synchronization. To open the Enter Device ID modal, proceed as follows:

1. From the Advanced Settings submenu, select **Device ID**. 
2. The Enter Device ID modal appears as shown in <FigureRef id="Enter-Device-ID-Modal" />

## Enter Device ID modal
The following fields and controls available in the Enter Device ID modal are shown in <FigureRef id="" />

| Field/Button           | Description                                                          |                                                                                                                                          
| :--------------        | :--------------------------------------------------------------------|
| Enter Device ID (min 2 digits) | Displays the device ID entered by the user. A minimum of 2 digits is required. <br />**Example:** 860 |
| Numeric Keypad | Enter numeric digits from 0 through 9. |
| +/- | Toggles the entered value between positive and negative. |
| Backspace | Removes the last entered digit from the field. |
| Clear All | Removes all digits from the field. |
| ∧ (Up) | Scrolls up to the previous field. |
| ∨ (Down) | Scrolls down to the next field. |
| Ok | Saves the entered device ID and closes the modal. |
| Cancel | Closes the Enter Device ID modal without saving changes |

## Enter the device ID
To enter the device ID, proceed as follows:

1. From the Advanced Settings submenu, select **Device ID**. The Enter Device ID modal appears.
2. Use the numeric keypad to enter the device ID.

:::note

The device ID must contain a minimum of 2 digits. If fewer than 2 digits are entered, the **Ok** button remains 
disabled and the entry is not accepted.

:::

3. Select **Ok**. The DCU saves the device ID and returns to the Advanced Settings submenu.
4. To close the Enter Device ID modal without saving changes, select **Cancel**.
