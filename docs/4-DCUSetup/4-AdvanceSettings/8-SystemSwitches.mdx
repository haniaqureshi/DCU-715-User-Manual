# System Switches

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **System Switches** function to turn core hardware functions, software behaviors, and diagnostic modes on or off on the DCU. Each switch controls a specific system feature.

To open the System Switches screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **System Switches**.

## System Switches screen

The following table describes the switches available on the System Switches screen.

| Switch                                        | Description |
| :-------------------------------------------- | :---------- |
| Apply low frequency patch                     | Turns the low frequency patch on or off. |
| Allow CMAS OPC Transfers                      | Turns CMAS OPC data transfers on or off. |
| Reset Storage Id Numbers                      | Turns the reset of storage ID numbers on or off. |
| Disable Job Numbers                           | Turns the job number field on or off across the DCU software. |
| Disable Customer Signatures                   | Turns the customer signature requirement on or off. |
| Disable UserName Entry                        | Turns the username entry field on or off. When you select this checkbox, a confirmation dialog asks whether you want to change the current username. |
| Simulation Mode                               | Turns simulation mode on or off. When simulation mode is on, the **Manual entry for balancing** option becomes available. |
| Manual entry for balancing                    | Turns on manual entry for balancing. This option is available only when **Simulation Mode** is on. |
| Measure Cycle Mode (For Offline Testing Only) | Turns measure cycle mode on or off. Use this mode only for offline testing. |
| Z Channel to Ultrasonic Input patch installed | Turns the Z channel to ultrasonic input patch on or off. |
| Legacy View                                   | Turns the legacy view display mode on or off. |
| Use virtual keyboard                          | Turns the on-screen virtual keyboard on or off. |
| Enable Primetals Xtools                       | Turns the Primetals Xtools integration on or off. |
| Aging Route Notifications                     | Turns aging route notifications on or off. |
| Exit                                          | Saves the configured system switches and returns to the Advanced Settings submenu. |

## Configure system switches

To configure the system switches, follow these steps:

1. On the **System Switches** screen, select or clear the checkboxes as needed.
2. Select **Exit**. The DCU saves the configured system switches and returns to the **Main Menu**.

## Change the username

When you select the **Disable UserName Entry** checkbox, the DCU asks whether you want to change the current username.

To change the username, follow these steps:

1. On the **System Switches** screen, select the **Disable UserName Entry** checkbox. A confirmation dialog appears with a message such as "Do you want to change the user name? The last user was 'savcd'," as shown in <FigureRef id="Change-Username-Confirmation-Dialog-Box" />.

2. Select **Yes**. The **Enter Technician Name** dialog appears, as shown in <FigureRef id="Enter-Technician-Name-Modal" />.

3. Select the **Name** field. The on-screen keyboard appears.
4. Use the on-screen keyboard to enter the new technician name.
5. Select **Ok**. The DCU saves the new technician name and returns to the **System Switches** screen.

To keep the current username, in the confirmation dialog, select **No**.
