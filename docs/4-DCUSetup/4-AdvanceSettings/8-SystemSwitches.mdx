# System Switches

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the System Switches function to enable or disable core hardware functionalities, software behaviors, and 
diagnostic modes on the DCU. Each switch controls a specific system feature and can be toggled on or off as required. 
To open the System Switches screen, proceed as follows:

1. From the Advanced Settings submenu, select **System Switches**.
2. The System Switches screen appears as shown in <FigureRef id="System-Switches-Screen" />

## System Switches screen
The following switches available on the System Switches screen

| Switches                                      | Description                                                                                                                                           |                                                                                                                                          
| :-------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Apply low frequency patch                     | Enables or disables the low frequency patch on the DCU.                                                                                               |
| Allow CMAS OPC Transfers                      | Enables or disables CMAS OPC data transfers.                                                                                                          |
| Reset Storage Id Numbers                      | Enables or disables the reset of storage ID numbers.                                                                                                  |
| Disable Job Numbers                           | Enables or disables the job number field across the DCU software.                                                                                     | 
| Disable Customer Signatures                   | Enables or disables the customer signature requirement.                                                                                               | 
| Disable UserName Entry                        | Enables or disables the username entry field. When this switch is enabled and selected, a confirmation dialog appears to change the current username. |
| Simulation Mode                               | Enables or disables simulation mode. When enabled, the **Manual entry for balancing** option becomes available.                                       |
| Manual entry for balancing                    | Enables manual entry for balancing. This option is only available when Simulation Mode is enabled.                                                    |
| Measure Cycle Mode (For Offline Testing Only) | Enables or disables the measure cycle mode for offline testing purposes only.                                                                         |
| Z Channel to Ultrasonic Input patch installed | Enables or disables the Z channel to ultrasonic input patch.                                                                                          |
| Legacy View                                   | Enables or disables the legacy view display mode.                                                                                                     | 
| Use virtual keyboard                          | Enables or disables the on-screen virtual keyboard.                                                                                                   |
| Enable Primetals Xtools                       | Enables or disables the Primetals Xtools integration.                                                                                                 |
| Aging Route Notifications                     | Enables or disables aging route notifications.                                                                                                        |
| Exit                                          | Saves the configured system switches and returns to the Advanced Settings submenu.                                                                    |

## Configure system switches
To configure the system switches, proceed as follows:

1. From the Advanced Settings submenu, select **System Switches**. The System Switches screen appears.
2. Review the list of available switches and select or deselect the checkboxes as required.
3. Select **Exit**. The DCU saves the configured system switches and returns to the ITR main menu.

## Change the username
When the **Disable UserName Entry** switch is enabled and selected, the DCU prompts the technician to change the current
username. To change the username, proceed as follows:

1. On the System Switches screen, select the **Disable UserName Entry** checkbox.
2. A confirmation dialog appears as shown in <FigureRef id="Change-Username-Confirmation-Dialog-Box" />

8. To keep the current username without making changes, select **No** in the confirmation dialog.
