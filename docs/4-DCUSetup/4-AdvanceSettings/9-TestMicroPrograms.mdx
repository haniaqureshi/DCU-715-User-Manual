# Test Micro Programs

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Test Micro Programs** function to run diagnostic commands on the DCU microcontroller. You can select a command from the **Micro Controller** list and run the test once or in a loop.

To open the Test Micro Programs dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **Test Micro Programs**.

The **Test Micro Programs** dialog appears, as shown in <FigureRef id="Test-Micro-Programs-Modal" />.

## Test Micro Programs dialog

The following table describes the fields and controls available in the Test Micro Programs dialog, as shown in <FigureRef id="Test-Micro-Programs-Modal" />.

| Field/Control    | Description |
| :--------------- | :---------- |
| Battery          | Displays the battery test results section. |
| Type             | Displays the selected test type. <br />**Example:** Battery Capacity |
| Status           | Displays the current status of the test. |
| Good             | Displays the number of successful test results. <br />**Example:** 0 |
| Bad              | Displays the number of failed test results. <br />**Example:** 0 |
| Optional         | Displays the number of optional test results. <br />**Example:** 0 |
| Micro Controller | Lists the available microcontroller commands. Select one option. Available options include: Restart, Shutdown, WD On, WD Off, WD Trigger, Battery SN, Battery Capacity. |
| Loop Test        | Turns loop test mode on or off. When loop test mode is on, the **Number Of Tests** field appears so that you can specify how many times the test runs. |
| Number Of Tests  | Displays the number of times the test runs when **Loop Test** is on. <br />**Example:** 999 |
| Start            | Starts the selected microcontroller test. If no test type is selected, a warning dialog appears. |
| Stop             | Stops the running test. |
| Cancel           | Closes the Test Micro Programs dialog and returns to the Advanced Settings submenu. |

## Run a micro program test

To run a micro program test, follow these steps:

1. In the **Test Micro Programs** dialog, select a command from the **Micro Controller** list:
    - Restart
    - Shutdown
    - WD On
    - WD Off
    - WD Trigger
    - Battery SN
    - Battery Capacity

    :::note

    If you select **Start** without selecting a command, a warning dialog with the message "Select test type" appears, as shown in <FigureRef id="Test-Micro-Warning-Dialog-box" />. Select **Close**, and then select a command.

    :::

2. To run the test in a loop, select the **Loop Test** checkbox. The **Number Of Tests** field appears. In the **Number Of Tests** field, enter the number of test repetitions.
3. Select **Start**. The DCU runs the selected microcontroller command and displays the test results in the **Battery** section.
4. During the test, monitor the following values:
    - Type
    - Status
    - Good
    - Bad
    - Optional
5. To end the test, select **Stop**.

To close the **Test Micro Programs** dialog and return to the **Advanced Settings** submenu, select **Cancel**.
