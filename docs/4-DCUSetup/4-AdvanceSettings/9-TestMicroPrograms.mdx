# Test Micro Programs

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Test Micro Programs** function to run diagnostic commands on the DCU micro controller. Technicians can select 
a specific command from the Micro Controller list and run the test individually or in a loop. To open the Test 
Micro Programs modal, proceed as follows:

1. From the Advanced Settings submenu, select **Test Micro Programs**. 
2. The Test Micro Programs modal appears as shown in <FigureRef id="" />.

## Test Micro Programs modal 
The following fields and controls available in the Test Micro Programs modal are shown in <FigureRef id="Test-Micro-Programs-Modal" />. 

| Fields/Control   | Description                                                                                                                                                                                               |                                                                                                                                          
| :--------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Battery          | Displays the battery test results section.                                                                                                                                                                |
| Type             | Displays the type of test currently selected. <br />**Example:** Battery Capacity                                                                                                                         |
| Status           | Displays the current status of the test.                                                                                                                                                                  |
| Good             | Displays the number of successful test results. <br />**Example:** 0                                                                                                                                      | 
| Bad              | Displays the number of failed test results. <br />**Example:** 0                                                                                                                                          |
| Optional         | Displays the number of optional test results. <br />**Example:** 0                                                                                                                                        |
| Micro Controller | Displays the list of available micro controller commands. Select one option using the radio button. Available options include: Restart, Shutdown, WD On, WD Off, WD Trigger, Battery SN, Battery Capacity. |
| Loop Test        | Enables or disables loop test mode. When enabled, the **Number of Tests** field appears, allowing the technician to specify how many times the test should run.                                           |
| Number Of Tests  | Displays the number of times the test will run when Loop Test is enabled. <br />**Example:** 999                                                                                                          |
| Start            | Starts the selected micro controller test. If no test type is selected, a warning dialog appears.                                                                                                          |
| Stop             | Stop the currently running test.                                                                                                                                                                          |
| Cancel           | Closes the Test Micro Programs modal and returns to the Advanced Settings submenu.                                                                                                                        |

## Run a micro program test
To run a micro program test, proceed as follows:
1. From the Advanced Settings submenu, select **Test Micro Programs**. The Test Micro Programs modal appears.
2. Select the desired command from the **Micro Controller** list:
    <ul><li>Restart</li>
    <li>Shutdown</li>
    <li>WD On</li>
    <li>WD Off</li>
    <li>WD Trigger</li>
    <li>Battery SN</li>
    <li>Battery Capacity</li></ul>

:::note

If **Start** is selected without choosing a command from the Micro Controller list, a warning dialog appears displaying:
**Select test type**. Select **Close** to dismiss the dialog and select a command before proceeding shown in <FigureRef id="Test-Micro-Warning-Dialog-box" /> below.

:::

3. To run the test in loop mode, select the **Loop Test** checkbox. The **Number Of Tests** field appears. Enter 
    the desired number of test repetitions in the **Number Of Tests** field.
4. Select **Start.** The DCU runs the selected micro controller command and displays the test results in the **Battery** section.
5. Monitor the following values during the test:

    <ul><li>Type</li>
    <li>Status</li>
    <li>Good</li>
    <li>Bad</li>
    <li>Optional</li></ul>

6. Select **Stop** to end the test.
7. Select **Cancel** to close the Test Micro Programs modal and return to the Advanced Settings submenu.
