# DFPID

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **DFPID** function to assign a digital filter profile ID (DFPID) to the DCU signal processing engine. The DFPID makes sure that the hardware applies the correct filtering for vibration analysis.

To open the Enter DFPID dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **DFPID**.

The **Enter DFPID** dialog appears, as shown in <FigureRef id="Enter-DFPID-Modal" />.

## Enter DFPID dialog

The following table describes the fields and controls available in the Enter DFPID dialog, as shown in <FigureRef id="Enter-DFPID-Modal" />.

| Field/Button               | Description |
| :------------------------- | :---------- |
| Enter DFPID (min 2 digits) | Displays the DFPID value that you entered. The DFPID must have at least 2 digits. <br />**Example:** 16 |
| Numeric keypad             | Enters numeric digits from 0 through 9. |
| Backspace                  | Removes the last entered digit from the field. |
| Clear All                  | Removes all digits from the field. |
| Ok                         | Saves the DFPID value and closes the dialog. |
| Cancel                     | Closes the Enter DFPID dialog without saving changes. |

## Enter the DFPID

To enter the DFPID, follow these steps:

1. In the **Enter DFPID** dialog, use the numeric keypad to enter the DFPID value.

    :::note

    The DFPID value must have at least 2 digits. **Ok** stays unavailable until you enter at least 2 digits.

    :::

2. Check the value in the entry field to confirm that you entered the correct DFPID.
3. Select **Ok**. The DCU saves the DFPID value and returns to the **Advanced Settings** submenu.

To close the **Enter DFPID** dialog without saving changes, select **Cancel**.
