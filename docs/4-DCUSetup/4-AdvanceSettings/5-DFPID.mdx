# DFPID

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **DFPID function** to assign a Digital Filter Profile ID to the DCU signal processing engine. This ensures 
the hardware applies the correct filtering logic for vibration analysis. To open the Enter DFPID modal, proceed as follows:

1. From the Advanced Settings submenu, select **DFPID**. 
2. The Enter DFPID modal appears as shown in <FigureRef id="Enter-DFPID-Modal" />

## Enter DFPID modal 
The following fields and controls available in the Enter DFPID modal are shown in <FigureRef id="Enter-DFPID-Modal" />.

| Field/Button                | Description                                                          |                                                                                                                                          
| :--------------        | :--------------------------------------------------------------------|
| Enter DFPID (min 2 digits) | Displays the DFPID value entered by the user. A minimum of 2 digits is required. <br />**Example:** 16 |
| Numeric Keypad | Enter numeric digits from 0 through 9. | 
| Backspace | Removes the last entered digit from the field. |
| Backspace | Removes the last entered digit from the field. |
| Clear All | Removes all digits from the field. |
| Ok | Saves the entered DFPID value and closes the modal. |
| Cancel | Closes the Enter DFPID modal without saving changes |

## Enter the DFPID
To enter the DFPID, proceed as follows:

1. From the Advanced Settings submenu, select **DFPID**. The Enter DFPID modal appears.
2. Use the numeric keypad to enter the required DFPID value.

:::note

The DFPID value must contain a minimum of 2 digits. If fewer than 2 digits are entered, the **Ok** button remains
disabled and the entry is not accepted

:::

3. Review the value displayed in the entry field to confirm the correct DFPID is entered.
4. Select **Ok**. The DCU saves the DFPID value and returns to the Advanced Settings submenu.
5. To close the Enter DFPID modal without saving changes, select **Cancel**.
