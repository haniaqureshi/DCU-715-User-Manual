# Sequence Number Reset

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Sequence Number Reset** function to manually reset the internal counter that tracks the data packets sent to the CMAS server. Use this function when you troubleshoot data synchronization issues.

To open the Sequence Number Reset confirmation dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **Sequence Number Reset**.

A confirmation dialog appears, as shown in <FigureRef id="Sequence-Number-Reset-Confirmation-Dialog" />.

## Sequence Number Reset confirmation dialog

The following table describes the controls available in the Sequence Number Reset confirmation dialog.

| Control              | Description |
| :------------------- | :---------- |
| Confirmation message | Displays the message "Are you sure you want to reset the sequence Number?" |
| Yes                  | Confirms the reset and returns to the Advanced Settings submenu. |
| No                   | Cancels the reset and returns to the Advanced Settings submenu. |

## Reset the sequence number

To reset the sequence number, follow these steps:

1. In the confirmation dialog, review the message "Are you sure you want to reset the sequence Number?"
2. To confirm the reset, select **Yes**. The DCU resets the sequence number and returns to the **Advanced Settings** submenu.

To cancel the reset, select **No**. The DCU returns to the **Advanced Settings** submenu without making changes.
