# DCU Type

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **DCU Type** function to set the hardware model of the DCU. When you select the correct DCU type, the software applies the right processing parameters and calibration constants for the device.

To open the DCU Type screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **DCU Type**.

The **DCU Type** screen appears and lists the supported DCU types, as shown in <FigureRef id="DCU-Type-Screen" />.

## DCU Type screen

The following table describes the fields and controls available on the DCU Type screen, as shown in <FigureRef id="DCU-Type-Screen" />.

| Option              | Description |
| :------------------ | :---------- |
| Supported DCU types | Lists the supported DCU hardware models. Available options include: DCU 714, DCU 715. |
| Exit                | Saves the selected DCU type and returns to the Advanced Settings submenu. |

## Select the DCU type

To select the DCU type, follow these steps:

1. Find the hardware model label on the DCU.
2. On the **DCU Type** screen, select the hardware model that matches the label, such as **DCU 715**.
3. Select **Exit**. The DCU saves the selected type and returns to the **Advanced Settings** submenu.
