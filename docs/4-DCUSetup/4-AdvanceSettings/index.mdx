Use the **Advanced Settings** submodule to configure advanced device options on the DCU. This submodule is password protected. You need a valid 7-digit password to open its submenu.

## Open the Advanced Settings submenu

To open the Advanced Settings submenu, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**. The **Enter Password** dialog appears, as shown in <FigureRef id="Enter-Password-Modal" />.

4. Use the numeric keypad to enter the 7-digit password.

    :::info

    The password must be exactly 7 digits. **Ok** stays unavailable until you enter exactly 7 digits.

    :::

5. Select **Ok**.
    - If the password is correct, the **Advanced Settings** submenu appears, as shown in <FigureRef id="Advanced-Settings-Submenu" />.
    - If the password is incorrect, the message "Wrong password" appears, as shown in <FigureRef id="Wrong-Password-Dialog" />. Select **Close**, and then enter the correct password.

## Advanced Settings functions

The **Advanced Settings** submenu contains the following functions:

- [**Aux DC Offset Test**](./1-AuxDCOffsetTest.mdx): Calibrates the DC offset for the auxiliary inputs.
- [**Bias Stability Test**](./2-BiasStabilityTest.mdx): Sets the bias stability level for sensors.
- [**DCU Type**](./3-DCUType.mdx): Sets the DCU hardware model.
- [**Device ID**](./4-DeviceId.mdx): Sets the device ID.
- [**DFPID**](./5-DFPID.mdx): Sets the digital filter profile ID.
- [**Master Battery File**](./6-MasterBatteryFile.mdx): Generates the master battery curve.
- [**Sequence Number Reset**](./7-SequenceNumberReset.mdx): Resets the data transmission counter.
- [**System Switches**](./8-SystemSwitches.mdx): Turns system features on or off.
- [**Test Micro Programs**](./9-TestMicroPrograms.mdx): Runs microcontroller diagnostic commands.
- [**Show Filter Table**](./10-ShowFilterTable.mdx): Shows the stored filter profiles.
- [**Show Battery Table**](./11-ShowBatteryTable.mdx): Shows the stored battery discharge data.

## Close the Advanced Settings submenu

- To return to the **DCU Setup** submenu, select **Back**.
- To return to the Home screen, select **Cancel**.
