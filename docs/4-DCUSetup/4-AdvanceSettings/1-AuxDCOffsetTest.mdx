# Aux DC Offset Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the Aux DC Offset Test function to calibrate and verify the DC offset levels for the auxiliary input channels
(Aux1 and Aux2) on the DCU. This test ensures signal accuracy during data collection. To open the Aux DC Offset Test modal, proceed as follows:

1. From the Advanced Settings submenu, select **Aux DC Offset Test**. 
2. The Aux DC Offset Test modal appears as shown in Figure-5.5.3.

## Aux DC Offset Test modal 
The following  fields and controls available in the Aux DC Offset Test modal are shown in <FigureRef id="Aux-DC-Offset-Test-Modal" /> 

| Field/Button               | Description                                                          |                                                                                                                                          
| :--------------        | :--------------------------------------------------------------------|
| Instruction  | Displays the hardware preparation instruction: **Place shorting caps on Aux1 and Aux2.** | 
| Aux1 DC Offset | Displays the current DC offset value measured on the Aux1 channel. <br />**Example:** 0.000000 |
| Aux2 DC Offset | Displays the current DC offset value measured on the Aux2 channel. <br />**Example:** 0.000000  | 
| Measure | Measures the current DC offset values for Aux1 and Aux2 channels and displays the results. |
| Zero Values | Resets the DC offset values to zero for calibration |
| Store | Saves the calibrated offset values to the DCU. |
| Cancel | Closes the Aux DC Offset Test modal and returns to the Advanced Settings submenu. |

## Run the Aux DC Offset Test
To run the Aux DC Offset Test, proceed as follows:

1. From the **Advanced Settings** submenu, select **Aux DC Offset Test**. The **Aux DC Offset Test modal** appears.
2. Place shorting caps securely on the Aux1 and Aux2 ports of the DCU.
3. Select **Measure**. The DCU measures the current DC offset values and displays the results in the Aux1 DC Offset and Aux2 DC Offset fields.
4. Review the offset values.
<ul><li>If the values require calibration, select Zero Values to reset the offset values to zero.</li></ul>
5. Select Store. The DCU saves the calibrated offset values.
6. Select Cancel to close the Aux DC Offset Test modal and return to the Advanced Settings submenu.
