# Bias Stability Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Bias Stability Test** function to configure the bias stability level for connected vibration sensors. This 
setting determines the voltage threshold used to verify that sensors are electrically stable before a measurement 
begins. To open the Set Bias Stability Level modal, proceed as follows:

1. From the Advanced Settings submenu, select **Bias Stability Test**. 
2. The Set Bias Stability Level modal appears as shown in <FigureRef id="Set-Bias-Stability-Level-Modal" />

## Set Bias Stability Level modal
The following fields and controls available in the Set Bias Stability Level modal are shown in <FigureRef id="" />. 

| Field/Button                          | Description                                                                                                                                                    |                                                                                                                                          
| :------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Enable Bias level for Stability Check | Enables or disables the bias stability check. When selected, the DCU performs a bias stability check before each measurement.                                  |
| Set Bias Stability Level              | Displays the current bias stability threshold value in volts. Select the field to open the numeric keypad and enter a new value.<br /> **Example:** 0.01 Volts |
| Ok                                    | Saves the configured bias stability level and closes the modal.                                                                                                |
| Cancel                                | Closes the Set Bias Stability Level modal without saving changes.                                                                                              |

## Configure the bias stability level
To configure the bias stability level, proceed as follows:

1. From the Advanced Settings submenu, select **Bias Stability Test**. The Set Bias Stability Level modal appears.
2. Select the **Enable Bias level for Stability Check** checkbox to activate the bias stability check.
3. Select the **Set Bias Stability Level** field. The numeric keypad appears as shown in <FigureRef id="Set-Bias-Stability-Level-Numeric-Keypad" />.

4. Use the numeric keypad to enter the desired stability threshold value.
5. Select **Ok** on the numeric keypad to confirm the entered value.
6. Select **Ok** on the Set Bias Stability Level modal. The DCU saves the configured bias stability level and returns to the Advanced Settings submenu.
7. To close the modal without saving changes, select **Cancel**.

:::note

The value must contain exactly **2 digits** after the decimal point. If only **1 digit** is entered after the decimal point,
the DCU displays an error. A minimum of **2 decimal** places are required for a valid entry . 

:::
