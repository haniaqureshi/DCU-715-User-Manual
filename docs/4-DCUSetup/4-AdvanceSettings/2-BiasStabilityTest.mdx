# Bias Stability Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Bias Stability Test** function to configure the bias stability level for connected vibration sensors. This setting determines the voltage threshold that the DCU uses to verify that sensors are electrically stable before a measurement starts.

To open the Set Bias Stability Level dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Advanced Settings**, and then enter the password. For details, see [Open the Advanced Settings submenu](./index.mdx#open-the-advanced-settings-submenu).
4. From the **Advanced Settings** submenu, select **Bias Stability Test**.

The **Set Bias Stability Level** dialog appears, as shown in <FigureRef id="Set-Bias-Stability-Level-Modal" />.

## Set Bias Stability Level dialog

The following table describes the fields and controls available in the Set Bias Stability Level dialog, as shown in <FigureRef id="Set-Bias-Stability-Level-Modal" />.

| Field/Button                          | Description |
| :------------------------------------ | :---------- |
| Enable Bias level for Stability Check | Turns the bias stability check on or off. When this checkbox is selected, the DCU performs a bias stability check before each measurement. |
| Set Bias Stability Level              | Displays the current bias stability threshold value in volts. To enter a new value, select the field to open the numeric keypad.<br />**Example:** 0.01 Volts |
| Ok                                    | Saves the configured bias stability level and closes the dialog. |
| Cancel                                | Closes the Set Bias Stability Level dialog without saving changes. |

## Configure the bias stability level

To configure the bias stability level, follow these steps:

1. In the **Set Bias Stability Level** dialog, select the **Enable Bias level for Stability Check** checkbox to turn on the bias stability check.
2. Select the **Set Bias Stability Level** field. The numeric keypad appears, as shown in <FigureRef id="Set-Bias-Stability-Level-Numeric-Keypad" />.

    <FigureProvider>

3. Use the numeric keypad to enter the stability threshold value.

    :::note

    The value must have exactly 2 digits after the decimal point. If you enter only 1 digit after the decimal point, the DCU displays an error.

    :::

4. On the numeric keypad, select **Ok** to confirm the value.
5. In the **Set Bias Stability Level** dialog, select **Ok**. The DCU saves the configured bias stability level and returns to the **Advanced Settings** submenu.

To close the dialog without saving changes, select **Cancel**.
