# Disable Screen Blanking

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Disable Screen Blanking** function to turn screen blanking on or off on the DCU. When screen blanking is turned off, the display stays on and doesn't turn off automatically during periods of inactivity.

To open the Screen Blanking dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **Disable Screen Blanking**.

The **Screen Blanking** dialog appears, as shown in <FigureRef id="Disable-Screen-Blanking" />.

## Screen Blanking dialog

The following table describes the fields and controls available in the Screen Blanking dialog, as shown in <FigureRef id="Disable-Screen-Blanking" />.

| Field/Button            | Description |
| :---------------------- | :---------- |
| Disable Screen Blanking | Turns screen blanking on or off. When this checkbox is selected, screen blanking is off and the display stays on. |
| Ok                      | Saves the selection and closes the Screen Blanking dialog. |
| Cancel                  | Closes the Screen Blanking dialog without saving changes. |

## Configure screen blanking

To configure the screen blanking setting, follow these steps:

1. In the **Screen Blanking** dialog, select or clear the **Disable Screen Blanking** checkbox.
2. Select **Ok**. The DCU saves the setting and returns to the **Settings** submenu.

To close the **Screen Blanking** dialog without saving changes, select **Cancel**.
