# Disable Screen Blanking

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Disable Screen Blanking** function to enable or disable the screen blanking feature on the DCU. 
When screen blanking is disabled, the display remains active and does not turn off automatically during 
periods of inactivity. To open the Screen Blanking module, proceed as follows:

1. From the Settings submenu, select **Disable Screen Blanking**. 
2. The Screen Blanking popup will appear as shown in the <FigureRef id="Disable-Screen-Blanking" />.

## Screen Blanking module
The following fields and controls available in the Screen Blanking module are shown in the <FigureRef id="Disable-Screen-Blanking" />.

| Field/Button            | Function                                                                                                                                | 
| :---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- | 
| Disable Screen Blanking | Enables or disables the screen blanking feature. When selected, the screen blanking feature is disabled and the display remains active. |
| Ok                      | Saves the selection and closes the Screen Blanking popup.                                                                               |
| Cancel                  | Closes the Screen Blanking module without saving changes.                                                                               |

## Configure screen blanking
To configure the screen blanking setting, proceed as follows:

1. From the Settings submenu, select **Disable Screen Blanking**. The Screen Blanking popup will appear.
2. Select or deselect the **Disable Screen Blanking** checkbox as required.
3. Select **Ok**. The DCU saves the setting and returns to the Settings submenu.
4. To close the modal without saving changes, select **Cancel**.
