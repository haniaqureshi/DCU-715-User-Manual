# Language

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Language** function to change the display language of the DCU software. When you select a new language, the entire software interface changes to that language.

To open the Select Language dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **Language**.

The **Select Language** dialog appears, as shown in <FigureRef id="Select-Language-Screen" />.

## Select Language dialog

The following table describes the fields and controls available in the Select Language dialog, as shown in <FigureRef id="Select-Language-Screen" />.

| Field/Button | Description |
| :----------- | :---------- |
| Language     | Displays the list of available languages. Available options include: English, <span lang="es">Español</span>, <span lang="de">Deutsch</span>, <span lang="fr">Français</span>, <span lang="it">Italiano</span>, <span lang="zh">中文</span>, <span lang="ja">日本語</span>, <span lang="ko">한국어</span>, <span lang="pt">Português</span>. |
| Ok           | Saves the selected language and returns to the Home screen. |
| Cancel       | Closes the Select Language dialog without saving changes. |

## Select the display language

To select the display language, follow these steps:

1. In the **Select Language** dialog, select a language from the list.
2. Select **Ok**. The DCU changes the software language and returns to the Home screen. The entire software interface now appears in the selected language.

To close the **Select Language** dialog without saving changes, select **Cancel**.
