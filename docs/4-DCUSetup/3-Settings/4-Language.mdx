# Language

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Language function** to change the display language of the DCU software. When a new language is selected, 
the entire software interface updates to reflect the selected language. To open the Select Language modal, proceed
as follows:

1. From the Settings submenu, select **Language**.
2. The Select Language popup will appear.

## Select Language Screen
The following fields and controls available in the Select Language Screen as shown in the <FigureRef id="Select-Language-Screen"/>.

| Field/Button  | Description                                                                                                                                                                                            |                                                                                                                                          
| :------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Language      | Displays the list of available languages. Select the desired language using the radio button. Available options include: English, Español, Deutsch, Français, Italiano, 中文, 日本語, 한국어, Português. |
| Ok            | Saves the selected language and returns to the ITR home page.                                                                                                                                           | 
| Cancel        | Closes the Select Language modal without saving changes.                                                                                                                                                |  

## Select the display language
To select the display language, proceed as follows:

1. From the Settings submenu, select **Language**. The Select Language popup will appear.
2. Choose your desired language from the list.
3. Select **Ok**. The DCU updates the software language and returns to the **ITR** home page.
4. After updating the language the entire software interface displays in the selected language.
5. To close the Select Language modal without saving changes, select **Cancel**.
