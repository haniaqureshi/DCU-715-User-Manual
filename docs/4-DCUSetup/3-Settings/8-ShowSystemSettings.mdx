# Show System Settings

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the Show System Settings function to view the current system configuration values stored on the DCU. This screen
is read-only and displays device information such as the DCU type, board, device ID, technician name, and software 
version. To open the System Settings screen, proceed as follows:

1. From the Settings submenu, select **Show System Settings**. The System Settings modal appears as shown in the <FigureRef id="System-Settings-modal" />.

## System Settings modal
The following system variables displayed in the System Settings modal.

| System Variable           | Description                                                                                                           |                                                                                                                                          
| :------------------------ | :-------------------------------------------------------------------------------------------------------------------- |
| DCU Type                  | Displays the DCU device type. <br />**Example:** DCU 715                                                              |
| Board                     | Displays the board type installed in the DCU. <br />**Example:** Athena IV                                            |
| Apply low frequency patch | Displays whether the low frequency patch is applied. <br />**Example:** False                                         |
| DCU number                | Displays the DCU serial number. <br />**Example:** 07150997                                                           |
| Device ID                 | Displays the unique device ID assigned to the DCU. <br />**Example:** 860                                             |
| SID                       | Displays the security identifier assigned to the DCU. <br />**Example:** S-1-5-21-3254971474-1783749283-93584685-1001 |
|DFPID                      | Displays the DFPID value assigned to the DCU. <br />**Example:** 16                                                   |
| Device                    | Displays the device name. <br />**Example:** DCU-07150997                                                             |
| Tech. name                | Displays the technician name currently assigned to the DCU. <br />**Example:** savcd                                  |
| Version                   | Displays the current software version installed on the DCU. <br />**Example:** 0.3.1.28                               |
| Use virtual keyboard      | Displays whether the virtual keyboard is enabled. <br />**Example:** True                                             |
| ∧ (Up)                    | Scrolls up through the system settings list.                                                                          |
| ∨ (Down)                  | Scrolls down through the system settings list.                                                                        |
| Cancel                    | Closes the System Settings modal and returns to the Settings submenu                                                  | 

:::info

The System Settings modal is read-only. No values can be edited from this screen. 

:::
