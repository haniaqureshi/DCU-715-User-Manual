# Show System Settings

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the Show System Settings function to view the current system configuration values stored on the DCU. This screen
is read-only and displays device information such as the DCU type, board, device ID, technician name, and software 
version. To open the System Settings screen, proceed as follows:

1. From the Settings submenu, select **Show System Settings**. The System Settings modal appears.
