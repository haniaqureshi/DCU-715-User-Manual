# Theme (Dark/Light)

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Theme function** to configure the display appearance of the DCU software. Technicians can select a light or 
dark theme and adjust the backlight brightness. To open the Display settings screen, proceed as follows:

1. From the Settings submenu, select **Theme (Dark/Light)**.
2. The Display settings screen will appear as shown in the <FigureRef id="Display-Settings-Screen" />.

## Display Settings Screen 
The following fields and controls available in the Display settings modal.


| Field/Button    | Description                                                                                                                                                         |                                                                                                                                          
| :-------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Backlight       | Adjusts the backlight brightness level of the display. Use the slider or the **+** and **−** buttons to increase or decrease the brightness. <br /> **Example:** 33 |
| + (Increase)    | Increases the backlight brightness level.                                                                                                                           |
| − (Decrease)    | Decreases the backlight brightness level.                                                                                                                           |
| Light Theme     | Set the software display to light mode.                                                                                                                             |
| Dark Theme      | Set the software display to dark mode.                                                                                                                              |
| Ok              | Saves the display settings and returns to the ITR home page.                                                                                                        |
| Cancel          | Closes the Display settings modal without saving changes                                                                                                            |

## Configure the display settings
To configure the display settings, proceed as follows:

1. From the Settings submenu, select **Theme (Dark/Light)**. The Display settings screen will appear.
2.  Adjust the **Backlight** brightness using the slider, or select **+** or **−** to increase or decrease the brightness level.
3. Select the desired theme:
    <ul><li>**Light Theme**</li>
    <li>**Dark Theme**</li></ul>
4. Select **Ok**. The DCU applies the selected theme and backlight settings and returns to the ITR home page.
5. To close the Display settings modal without saving changes, select **Cancel**.
