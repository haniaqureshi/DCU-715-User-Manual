# Theme (Dark/Light)

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Theme (Dark/Light)** function to configure the display appearance of the DCU software. You can select a light or dark theme and adjust the backlight brightness.

To open the Display settings dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **Theme (Dark/Light)**.

The **Display settings** dialog appears, as shown in <FigureRef id="Display-Settings-Screen" />.

## Display settings dialog

The following table describes the fields and controls available in the Display settings dialog, as shown in <FigureRef id="Display-Settings-Screen" />.

| Field/Button | Description |
| :----------- | :---------- |
| Backlight    | Adjusts the backlight brightness level of the display. To increase or decrease the brightness, use the slider or the **+** and **−** buttons. <br />**Example:** 33 |
| + (Increase) | Increases the backlight brightness level. |
| − (Decrease) | Decreases the backlight brightness level. |
| Light Theme  | Sets the software display to light mode. |
| Dark Theme   | Sets the software display to dark mode. |
| Ok           | Saves the display settings and returns to the Home screen. |
| Cancel       | Closes the Display settings dialog without saving changes. |

## Configure the display settings

To configure the display settings, follow these steps:

1. In the **Display settings** dialog, adjust the **Backlight** brightness with the slider, or select **+** or **−**.
2. Select **Light Theme** or **Dark Theme**.
3. Select **Ok**. The DCU applies the selected theme and backlight settings and returns to the Home screen.

To close the **Display settings** dialog without saving changes, select **Cancel**.
