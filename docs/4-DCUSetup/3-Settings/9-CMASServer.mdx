# CMAS Server

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **CMAS Server** function to manage CMAS system connections on the DCU. You can add, edit, select, and delete CMAS server entries.

To open the Select CMAS system screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **CMAS Server**.

The **Select CMAS system** screen appears, as shown in <FigureRef id="Select-CMAS-System-Screen" />.

## Select CMAS system screen

The following table describes the fields and controls available on the Select CMAS system screen, as shown in <FigureRef id="Select-CMAS-System-Screen" />.

| Field/Button | Description |
| :----------- | :---------- |
| CMAS         | Displays the name of the CMAS server entry. <br />**Example:** abc |
| Alias        | Displays the alias assigned to the CMAS server entry. <br />**Example:** abc |
| Selected     | Displays a checkbox that shows whether the CMAS entry is selected. |
| Save         | Saves the CMAS server entry. **Save** is available only after you enter a valid CMAS name and alias. |
| Select       | Sets the highlighted CMAS server entry as the active connection. |
| New          | Clears the **CMAS** and **Alias** fields so that you can enter a new CMAS server entry. **New** is unavailable after you enter a CMAS name and alias and before you save the entry. |
| Edit         | Opens the selected CMAS server entry for editing. |
| ∧ (Up)       | Scrolls up through the CMAS server list. |
| ∨ (Down)     | Scrolls down through the CMAS server list. |
| Delete       | Deletes the selected CMAS server entry. A confirmation dialog appears before the entry is deleted. |
| Cancel       | Closes the Select CMAS system screen and returns to the Settings submenu. |

## Add a CMAS server entry

To add a CMAS server entry, follow these steps:

1. On the **Select CMAS system** screen, select **New**. The **CMAS** and **Alias** fields are cleared, and the on-screen keyboard appears, as shown in <FigureRef id="Enter-CMAS-(on-screen keyboard)" />.

    <FigureProvider>
        <Figure 
            id="Enter-CMAS-(on-screen keyboard)" 
            src="/img/4-DCUSetup/3-Settings/9-CMASServer/EnterCMASOnScreenKeyboard-Light.jpg"
            caption="Enter CMAS (on-screen keyboard)" 
            alt={"On-screen keyboard open over the Select CMAS system screen, with an empty preview box above the keys."}
            width="70%"
        />
    </FigureProvider>

2. Select the **CMAS** field, and then use the on-screen keyboard to enter the CMAS server name.
3. Select the **Alias** field, and then use the on-screen keyboard to enter the alias for the CMAS server.
4. Select **Save**. The DCU saves the new CMAS server entry. The entry appears in the CMAS server list under the input fields.

:::note

**Save** is available only after both the **CMAS** and **Alias** fields contain a valid entry. **New** is unavailable while a CMAS name and alias are entered but not saved.

:::

## Select a CMAS server entry

To set a CMAS server entry as the active connection, follow these steps:

1. On the **Select CMAS system** screen, select the CMAS entry from the list. The selected entry is highlighted.
2. Select **Select**. If CMAS OPC is turned off, the error message "CMAS OPC is disabled. Enable this option in "Advanced settings"" appears, as shown in <FigureRef id="CMAS-OPC-disabled-(Error-message-dialogbox)" />.

    <FigureProvider>

3. To acknowledge the message and return to the **Select CMAS system** screen, select **Close**. 

To turn on CMAS OPC, see [System Switches](../4-AdvanceSettings/8-SystemSwitches.mdx).

## Delete a CMAS server entry

To delete a CMAS server entry, follow these steps:

1. On the **Select CMAS system** screen, select the CMAS entry from the list. The selected entry is highlighted, and the checkbox in the **Selected** column is selected.
2. Select **Delete**. A confirmation dialog appears with the message "Delete CMAS server: [server name]," as shown in <FigureRef id="Delete-CMAS-Server-(confirmation dialog)" />.

    <FigureProvider>
        <Figure 
            id="Delete-CMAS-Server-(confirmation dialog)" 
            src="/img/4-DCUSetup/3-Settings/9-CMASServer/DeleteCMASServerConfirmationDialog-Light.jpg"
            srcDark="/img/4-DCUSetup/3-Settings/9-CMASServer/DeleteCMASServerConfirmationDialog-Dark.jpg"
            caption="Delete CMAS server (confirmation dialog)" 
            alt={"Confirmation dialog, outlined in red, with a yellow warning icon and the message 'Delete CMAS server: abc', and Cancel and Yes buttons."}
            width="70%"
        />
    </FigureProvider>

3. To confirm the deletion, select **Yes**. The DCU removes the selected CMAS server entry from the list.
