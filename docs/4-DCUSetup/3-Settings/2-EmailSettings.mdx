# Email Settings

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Email Settings** function to enter or update the email address associated with the DCU.

To open the Enter Email dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **Email Settings**.

The **Enter Email** dialog appears, as shown in <FigureRef id="Enter-Email-Module" />.

## Enter Email dialog

The following table describes the fields and controls available in the Enter Email dialog.

| Field/Button | Description |
| :----------- | :---------- |
| Email        | Displays the email address that you entered. <br />**Example:** clymerj@itr.com |
| Ok           | Saves the email address and returns to the Settings submenu. |
| Cancel       | Closes the Enter Email dialog without saving changes. |

## Enter the email address

To enter the email address, follow these steps:

1. In the **Enter Email** dialog, select the **Email** field. The on-screen keyboard appears, as shown in <FigureRef id="Enter-Email-(On-screen-keyboard)" />.

    <FigureProvider>
        <Figure 
            id="Enter-Email-(On-screen-keyboard)" 
            src="/img/4-DCUSetup/3-Settings/2-EmailSettings/EnterEmailOnScreenKeyboard-Light.jpg"
            caption="Enter Email (on-screen keyboard)" 
            alt={"On-screen keyboard open over the Enter Email dialog, with clymerj@itr.com in the preview box above the keys."}
            width="70%"
        />
    </FigureProvider>

2. Use the on-screen keyboard to enter the email address.

    :::info

    - To switch to numbers and special characters, use the **?123** key.
    - To insert the at sign (@), use the **@** key.
    - To remove the last character, use the **Backspace** key.

    :::

3. Select **Ok**. The DCU saves the email address and returns to the **Settings** submenu.

To close the **Enter Email** dialog without saving changes, select **Cancel**.
