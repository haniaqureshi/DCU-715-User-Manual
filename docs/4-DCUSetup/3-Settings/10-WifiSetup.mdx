# Wi-Fi Setup

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **WiFi Setup** function to configure and manage the wireless network connection on the DCU. You can turn Wi-Fi on or off, scan for available networks, and connect to a wireless network by entering the network name and password.

To open the WiFi Setup screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **WiFi Setup**.
    - If the Wi-Fi adapter is available, the **WiFi Setup** screen appears, as shown in <FigureRef id="WiFi-Setup-Screen" />.
    - If the Wi-Fi adapter is turned off, the error message "WiFi adapter is disabled" appears, as shown in <FigureRef id="WiFi-Adapter-Disabled-(Error-message)" />. To acknowledge the message and return to the **Settings** submenu, select **Close**.

## WiFi Setup screen

The following table describes the fields and controls available on the WiFi Setup screen, as shown in <FigureRef id="WiFi-Setup-Screen" />.

| Field/Button   | Description |
| :------------- | :---------- |
| Name           | Displays the name of the selected wireless network. |
| Status         | Displays the connection status of the wireless network. |
| Password       | Displays the password field for the selected wireless network. To connect, enter the network password. |
| Name (list)    | Displays the name of each detected wireless network. |
| Connected      | Displays whether the DCU is connected to the network. |
| Signal         | Displays the signal strength of the detected network. |
| Is Secure      | Displays whether the detected network is secured with a password. |
| Turn On Wi-Fi  | Turns on the Wi-Fi adapter and scans for available wireless networks. |
| Turn Off Wi-Fi | Turns off the Wi-Fi adapter and disconnects from the current network. |
| Rescan         | Scans for available wireless networks and refreshes the network list. |
| Abandon        | Disconnects from the connected wireless network. |
| Cancel         | Closes the WiFi Setup screen and returns to the Settings submenu. |

## Connect to a Wi-Fi network

To connect to a Wi-Fi network, follow these steps:

1. On the **WiFi Setup** screen, select **Turn On Wi-Fi**. The DCU turns on the Wi-Fi adapter and scans for available wireless networks. The detected networks appear in the network list.
2. From the list, select the network. The network name appears in the **Name** field.
3. Select the **Password** field, and then use the on-screen keyboard to enter the network password.
4. To connect, select **Turn On Wi-Fi**. The DCU connects to the selected wireless network, and the **Status** field shows the active connection.

To scan for networks again, select **Rescan**. To disconnect from the current network, select **Abandon**. To close the **WiFi Setup** screen without making changes, select **Cancel**.
