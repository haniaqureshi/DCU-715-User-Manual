# Settings

The Settings submenu provides options to configure device preferences and system settings on the DCU. 
Use this submenu to manage screen behavior, email configuration, display preferences, network connectivity and 
more.To open the Settings submenu, proceed as follows:

1. From the Main Menu, select **DCU Setup**.
2. From the DCU Setup submenu, select **Settings**.
