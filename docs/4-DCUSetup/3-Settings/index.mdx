Use the **Settings** submodule to configure device preferences and system settings on the DCU. Its functions let you manage screen behavior, email configuration, display preferences, network connectivity, and more.

To open the Settings submenu, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.

## Settings functions

The **Settings** submenu contains the following functions:

- [**Disable Screen Blanking**](./1-DisableScreenBlanking.mdx): Keeps the display on during periods of inactivity.
- [**Email Settings**](./2-EmailSettings.mdx): Sets the email address for the DCU.
- [**Technician Name**](./3-TechnicianName.mdx): Sets the technician name for the DCU.
- [**Language**](./4-Language.mdx): Changes the display language.
- [**Theme (Dark/Light)**](./5-Theme.mdx): Sets the theme and backlight brightness.
- [**Units (Imperial/Metric)**](./6-Units.mdx): Sets the units of measurement.
- [**Update Job Numbers**](./7-UpdateJobNumbers.mdx): Assigns job ID numbers to routes.
- [**Show System Settings**](./8-ShowSystemSettings.mdx): Shows the current system configuration.
- [**CMAS Server**](./9-CMASServer.mdx): Manages CMAS server connections.
- [**WiFi Setup**](./10-WifiSetup.mdx): Configures the wireless network connection.

## Close the Settings submenu

- To return to the **DCU Setup** submenu, select **Back**.
- To return to the Home screen, select **Cancel**.
