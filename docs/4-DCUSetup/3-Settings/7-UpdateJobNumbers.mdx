# Update Job Numbers

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Update Job Numbers** function to assign or update a job ID number for a selected route. The job ID number must be exactly 6 digits.

To open the Update Job Number screen, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **Update Job Numbers**.

The **Update Job Number** screen appears and lists the available routes, as shown in <FigureRef id="Update-Job-Number-Screen" />.

## Update Job Number screen

The following table describes the fields and controls available on the Update Job Number screen.

| Field/Button      | Description |
| :---------------- | :---------- |
| Id                | Displays the route ID number. <br />**Example:** 1289 |
| Route Name        | Displays the name of the route. <br />**Example:** TEST #2 |
| Job Id            | Displays the job ID number assigned to the route. <br />**Example:** 123458 |
| ∧ (Up)            | Scrolls up through the route list. |
| ∨ (Down)          | Scrolls down through the route list. |
| Update Job Number | Opens the Enter Job ID Number dialog for the selected route. |

## Update the job number

To update the job number for a route, follow these steps:

1. On the **Update Job Number** screen, select the route from the list. The selected route is highlighted.
2. Select **Update Job Number**. The **Enter Job ID Number** dialog appears, as shown in <FigureRef id="Enter-Job-ID-Number-(pin-pad)" />.

3. Use the numeric keypad to enter a 6-digit job ID number. When you enter exactly 6 digits, "Valid value" appears under the entry field.

    :::info

    The job ID number must be exactly 6 digits. **Ok** is available only when you enter exactly 6 digits.

    :::

4. Select **Ok**. The DCU saves the job ID number and returns to the **Update Job Number** screen.

To close the **Enter Job ID Number** dialog without saving changes, select **Cancel**.

To return to the **Main Menu**, select **Menu**.
