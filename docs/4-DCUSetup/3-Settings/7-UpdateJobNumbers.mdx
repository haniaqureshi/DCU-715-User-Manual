# Update Job Numbers

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Update Job Numbers** function to assign or update a job ID number for a selected route. The job ID number 
must be exactly 6 digits. To open the **Update Job Number** screen, proceed as follows:

1. From the Settings submenu, select **Update Job Numbers**.
2. The Update Job Number screen appears, displaying the list of available routes.

## Update Job Number screen
The following fields and controls available on the Update Job Number screen.

| Field/Button           | Description                                                          |                                                                                                                                          
| :--------------        | :--------------------------------------------------------------------|
| Id  | Displays the route ID number. <br />**Example:**1289 |
| Route Name | Displays the name of the route. <br />**Example:** TEST #2 |
| Job Id | Displays the current job ID number assigned to the route. <br />**Example:** 123458 |
| ∧ (Up) | Scrolls up through the route list. |
| ∨ (Down) | Scrolls down through the route list. |
| Update Job Number | Opens the Enter Job ID Number modal for the selected route. |

## Update the job number
To update the job number for a route, proceed as follows:
1. From the Settings submenu, select **Update Job Numbers**. The Update Job Number screen appears.
2. Select the desired route from the list. The selected route is highlighted.
3. If you want to update the job click on the Update **Job Number** option. 
4. The Enter Job ID Number modal appears.

Use the numeric keypad to enter a 6-digit job ID number. The modal displays **Valid value** below the entry field 
when exactly 6 digits are entered. 

:::info

The job ID number must be exactly 6 digits. If fewer or more than 6 digits are entered, the **Ok** button remains 
disabled and the entry is not accepted. The **Ok** button becomes available only when exactly 6 digits are entered.

:::

6. Select **Ok**. The DCU saves the job ID number and returns to the Update Job Number screen.
7. Select **Cancel**, to close the Enter Job ID Number modal without saving changes,.
8. **Select Menu**, to return to the Main Menu.
