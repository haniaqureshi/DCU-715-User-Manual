# Technician Name

import Figure from "@site/src/components/Figure";

Use the Technician Name function to enter or update the technician name associated with the DCU. To open the Enter 
Technician Name modal, proceed as follows:

1. From the Settings submenu, select **Technician Name**. 
2. The **Enter Technician Name** module will appear as shown in the <FigureRef id="Enter-Technician-Name-Screen" />

## Enter Technician Name module
The following table fields and controls available in the Enter Technician Name Screen.

| Field/Button    | Description                                                               |                                                                                                                                          
| :-------------- | :------------------------------------------------------------------------ |
| Name            | Displays the technician name entered by the user. <br />**Example:** tech |
| Ok              | Save the entered technician name and return to the Setting sub-menu.      |
| Cancel          | Closes the Enter Technician Name modal without saving changes.            |

## Enter the technician name
To enter the technician name, proceed as follows:

    1. From the Settings submenu, select **Technician Name**. The Enter Technician Name popup will appear.
    2. Select the **Name** field. The on-screen keyboard appears as shown in <FigureRef id="Enter-Technician-Name-(On-screen-keyboard)" />.
    3. Use the on-screen keyboard to enter the technician name.
    4. Select **Ok**. The DCU saves the technician name and returns to the Settings submenu.
    5. To close the Enter Technician Name modal without saving changes, select **Cancel**.
