# Technician Name

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Technician Name** function to enter or update the technician name associated with the DCU.

To open the Enter Technician Name dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **Technician Name**.

The **Enter Technician Name** dialog appears, as shown in <FigureRef id="Enter-Technician-Name-Screen" />.

## Enter Technician Name dialog

The following table describes the fields and controls available in the Enter Technician Name dialog.

| Field/Button | Description |
| :----------- | :---------- |
| Name         | Displays the technician name that you entered. <br />**Example:** tech |
| Ok           | Saves the technician name and returns to the Settings submenu. |
| Cancel       | Closes the Enter Technician Name dialog without saving changes. |

## Enter the technician name

To enter the technician name, follow these steps:

1. In the **Enter Technician Name** dialog, select the **Name** field. The on-screen keyboard appears, as shown in <FigureRef id="Enter-Technician-Name-(On-screen keyboard)" />.

    <FigureProvider>
        <Figure 
            id="Enter-Technician-Name-(On-screen keyboard)" 
            src="/img/4-DCUSetup/3-Settings/3-TechnicianName/EnterTechnicianNameOnScreenKeyboard-Light.jpg"
            caption="Enter Technician Name (on-screen keyboard)"

            width="70%"

    </FigureProvider>

2. Use the on-screen keyboard to enter the technician name.
3. Select **Ok**. The DCU saves the technician name and returns to the **Settings** submenu.

To close the **Enter Technician Name** dialog without saving changes, select **Cancel**.
