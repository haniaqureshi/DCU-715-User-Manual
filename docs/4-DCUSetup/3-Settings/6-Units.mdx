# Units (Imperial/Metric)

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Units (Imperial/Metric)** function to configure the units of measurement used across the DCU software. You can set individual units for temperature, velocity, acceleration, and frequency, and select the overall unit system.

To open the Select units dialog, follow these steps:

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **DCU Setup**.
3. From the **DCU Setup** submenu, select **Settings**.
4. From the **Settings** submenu, select **Units (Imperial/Metric)**.

The **Select units** dialog appears, as shown in <FigureRef id="Select-Unit-Screen" />.

## Select units dialog

The following table describes the fields and controls available in the Select units dialog, as shown in <FigureRef id="Select-Unit-Screen" />.

| Field/Button | Description |
| :----------- | :---------- |
| Temperature  | Selects the unit of measurement for temperature. <br />**Example:** °F |
| Velocity     | Selects the unit of measurement for velocity. <br />**Example:** in/s |
| Acceleration | Selects the unit of measurement for acceleration. <br />**Example:** g0 |
| Frequency    | Selects the unit of measurement for frequency. <br />**Example:** hz |
| Unit System  | Selects the overall unit system. Available options: Imperial, Metric. <br />**Example:** Imperial |
| Ok           | Saves the selected units and returns to the Settings submenu. |
| Cancel       | Closes the Select units dialog without saving changes. |

## Configure the units

To configure the units of measurement, follow these steps:

1. In the **Select units** dialog, select a unit from the list for each of the following fields:
    - **Temperature**
    - **Velocity**
    - **Acceleration**
    - **Frequency**
    - **Unit System**
2. Select **Ok**. The DCU saves the selected units and returns to the **Settings** submenu.

To close the **Select units** dialog without saving changes, select **Cancel**.
