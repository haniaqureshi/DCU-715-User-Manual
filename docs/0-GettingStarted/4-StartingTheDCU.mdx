# Starting the DCU

When you turn on the DCU, the ITR application initializes the device and then opens the Dashboard. This page describes the initialization screen and the Dashboard.

## DCU Initialization
When the ITR application starts, the **DCU Initialization** screen is displayed automatically. During startup, the
system initializes the DCU by loading the required components and verifying the device status. The screen also 
displays the internal voltage values, signal channel readings, auxiliary channel readings, and the overall system 
status.

## DCU Screen Description 
The following components are available in <FigureRef id="DCU-Initialization-Screen" />.

| Components         | Description                                                                                                                                            |                                                                                                                                          
| :----------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| DCU Initialization | Displays the status of the initialization process, such as loading language tables, initializing A/D, opening the database, and reading filter tables. |
| Internal Voltages  | Displays the DCU internal voltage values and battery voltage.                                                                                          |
| Signal Channels    | Displays the accelerometer and bias channel readings.                                                                                                  | 
| Auxiliary Channels | Displays the AC and DC readings for the auxiliary channels.                                                                                            |
| Status Bar         | Displays the current device status, total count, and saturation status.                                                                                |


## Dashboard Preview
After the DCU initialization process is completed successfully, the **Dashboard** screen opens automatically. The
Dashboard provides access to the main functional modules of the device. 

**Procedure:**
1. Power on the DCU device.
2. Wait for the **DCU Initialization** process to complete.
3. The Dashboard screen opens automatically.
4. Tap any module to access its corresponding menu and options.
