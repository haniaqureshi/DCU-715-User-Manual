# Screen Layout

Every screen in the DCU application uses the same layout. This page describes the areas of the screen and the status icons shown in the task status bar.

## DCU Application Screen Layout
The DCU screen is divided into 3 main areas: the **header bar**, the **main workspace**, and the **footer notification** area as shown in figure <FigureRef id="DCU-Application-Screen-Layout"/>.

| #   | Components                              | Description                                                                                                                                                                                                                         | 
| :-  | :-------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A   | Header bar                              | Displays the current screen title, instruction, or navigation path. It also shows the screenshot icon, battery charge, date and time, and the **Menu button**. The **Menu** button returns the user to the main menu from submenus. |                                                                                                                                                                                                       
| B   | Main workspace                          | Displays the main content of the selected screen. This is where the user performs tests, views data, configures settings, and completes operational tasks.                                                                          |   
| C   | Task status bar                         | Displays short status messages related to the current task or operation. These messages may be standard recurring messages or messages specific to the current screen.                                                              |
| D   | System alert bar                        | Displays the most recent system message. Double-clicking this area opens the **System Alerts Panel**, which shows the recent system message history.                                                                                |                                                                                                                                                                                                               

## Task Status Bar
The **Task status** bar is displayed at the bottom of the screen and provides real-time feedback on the current state of
the active operation. The status bar updates automatically as the DCU processes tasks. The following table describes the status indicators displayed in the task status bar.
