## ITR 715 DCU at a Glance
| Components            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |                                                                                                                                         
| :-------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Touchscreen           | All DCU operations are performed and viewed via the screen.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         
| Electronic Case       | Do not open this compartment.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Battery Cover         | Seals and protects the battery.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Sensor                | Main input port for collecting sensor data. Four circumstances to use this connector:<ul><li>**Triaxial IEPE (ICP®) accelerometers**</li> <li>**Single-axis IEPE (ICP®) accelerometers:** Requires an adapter to convert a two-conductor cable to a four-conductor cable.</li> <li>**Two-axis IEPE (ICP®) accelerometers:** Requires an adapter to convert a three-conductor cable to a four-conductor cable.</li> <li>**Voltage input – No ICP:** IEPE power is disabled; external power must be provided if the sensor needs it.</li></ul>**Requirements for Voltage Input – No ICP:**<ul><li>**DC voltage sensor:** ≤20V Peak, not powered by DCU</li> <li>**AC voltage sensor:** F ≤25 KHz, ≤ ±5V peak (no DC offset), not powered by DCU</li></ul> |
| TEST                  | Output port used to test the integrity of the DCU sensor cable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| PWR                   | <ul><li>2-pin Amphenol connection to provide constant power from an AC wall adapter (18 V).</li> <li>The battery can be disconnected without interrupting the power supply.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| AUX1                  | Used for: <ul><li>Additional channel for simultaneous sampling</li> <li>High voltage AC/DC input</li> <li>Ultrasonic data collection</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |  
| AUX2                  |  Used for: <ul><li>Additional channel for simultaneous sampling</li> <li>High voltage AC/DC input</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| TACH                  | Tachometer input.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Sensor Plate          | Stores magnet-mounted accelerometer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| On/Off Switch         | DCU smart on/off button.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |     
| USB Port              | Supports USB 2.0 devices.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Battery               | DCU Li-Ion battery.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Battery Release Latch | Slide and hold the latch to release the battery.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
