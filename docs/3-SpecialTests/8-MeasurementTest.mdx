# Measurement Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Measurement Tests function** for standard vibration data acquisition and analysis. This test allows real-time monitoring of machine health through spectral and time-waveform data.

To open the Measurement Tests screen, proceed as follows:

1. From the Dashboard, select **Measurement Tests**.
2. The Select Route screen appears as shown in <FigureRef id="Measurement-Tests-Select-Route-Screen" />

### Select Route Screen 

:::info

The **Select Route** screen and its available fields and controls are the same as described in [Section 3.1](1-BumpTest.mdx). Please review that section for a detailed description.
:::

### Select a route
To select a route, proceed as follows:

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. The system redirects you to the **Measurement Test** screen, where you can easily measure the selected route data.

:::info
If the selected route is more than 2 weeks old, a warning dialog appears. Select **Yes** to download a new route or **No** to proceed with the existing route. The warning and Update Routes flow is the same as described in above sections. 

:::

### Run a Measurement Test
To run a Measurement Test, proceed as follows:

1. On the Measurement Tests screen, select **Start Measuring.**
2. The **Sensor Channel Status** bar is displayed, as shown in <FigureRef id="Cable-Integration" />
3. Wait for the sensor channel status check to complete.
4. After the check is complete, the Sensor Channel Status dialog box closes automatically, and the task status bar displays Ready.

## Additional Configuration Controls

### Sensor

Use the Sensor function to configure the sensor type, sensitivity, and cable integrity check for the Measurement Test.
To configure the sensor, proceed as follows:
1. On the Measurement Tests screen, select **Sensor**.
2. The Sensor Selection modal appears as shown in <FigureRef id="Sensor-Selection-Modal" />.

<FigureProvider>
    <Figure
        id="Sensor-Selection-Modal"

### Sensor Selection Modal
1. Select the hardware type from the Sensor dropdown menu (e.g., Triaxial Accelerometer).
2. Select the required scale from the Sensitivity dropdown menu (e.g., 10 mv/g).
3. Toggle the Checks Cable Integrity checkbox if physical line bias health checks are required.
4. Select **Ok** to save variables, or **Cancel** to exit without making changes.

### Options 
Use the Options function to configure the analysis mode, frequency parameters, and signal conditioning settings for the Measurement Test. 

To open the Options screen, proceed as follows:

1. On the Measurement Tests screen, select Options.

### Options screen fields
The following fields and controls available on the Options screen are shown in <FigureRef id="Measurement-Tests-Options-Screen" />.

| Fields/Buttons         | Description             	                                                                   |
|----------------------- |-------------------------------------------------------------------------------------------- |
| Frequency              | Sets the frequency range for analysis. <br />**Example:** 5,000 CPM  			               |
| Resolution             | Sets the number of spectral lines for the measurement. <br />**Example:** 200 		           |
| Averages               | Sets the number of averages required for the test.  <br />**Example:** 1 			           |
| Demod                  | Sets the demodulation frequency range.  <br />**Example:** 5,000 CPM 			               |
| Show Channel           | Selects which axis to display. Available options: X, Y, Z. 				                   |
| Mode                   | Selects the analysis mode. Available options: Spectrum, Time, Demod, URE, Phase, Waterfall. |
| 1 Shot                 | Enables single-capture mode for the measurement. 					                       |
| Trigger                | Sets the trigger value for 1 Shot capture. 						                           |
| Max. chart             | Enables or disables the maximum chart display option. 				                       |
| Cable Check            | Enables the cable integrity check before measurement. 				                       |
| Integrate              | Enables signal integration. 							                                       |
| Calibrate              | Enables sensor calibration. 							                                       |
| HiPass                 | Enables the high-pass filter. 							                                   |
| AC Couple              | Sets the signal coupling to AC. 							                                   |
| DC Couple              | Sets the signal coupling to DC. 							                                   |
| Use Anti-Alias Filters | Enables anti-alias filtering on the captured signal. 			                           |
| Save                   | Saves the configured options and returns to the Measurement Tests screen. 		           |
| Cancel                 | Closes the Options screen without saving changes. 					                       |

### Options Configuration Screen
1. Adjust the following settings as required by your testing profile: <br />
	a. **Frequency / Resolution / Averages / Demod:** Adjust parameters from their respective dropdown &nbsp; &nbsp; &nbsp; lists (e.g., Frequency: 5,000 CPM, Resolution: 200, Averages: 1). <br />
	b. **Show Channel:** Select the primary channel target radio button **(X, Y,** or **Z)**. <br />
        c. **Mode Selection:** Select the calculation mode radio button **(Spectrum, Time, Demod, URE, Phase,** &nbsp; &nbsp; or **Waterfall)**. <br />
	d. **1 Shot & Trigger:** Check 1 Shot to isolate single blocks. Input the target limit value in the **Trigger** &nbsp; &nbsp; &nbsp; &nbsp; text field. <br />
	e. **Hardware Checkboxes & Coupling:**
		1. Toggle **Cable Check, Integrate, Calibrate,** or **HiPass** filters.
		2. Select either **AC Couple** or **DC Couple** radio buttons.
		3. Check **Use Anti-Alias Filters** to clear electrical line distortion. <br />
        
    f. **Max. chart:** Toggle to enable full-screen layout plotting.
2. Select **Save** to update the DCU internal processing parameters, or **Cancel** to exit.
