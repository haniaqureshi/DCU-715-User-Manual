# Bump Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Bump Test function** to determine the natural frequencies and resonance characteristics of a machine or structure. This test is performed by striking a stationary machine component with an impact hammer and measuring the vibration response.

To open the Bump Test screen, proceed as follows:
1. From the **Special Tests** submenu, select **Bump Test**. 
2. The Select Route screen appears as shown in <FigureRef id="" />
