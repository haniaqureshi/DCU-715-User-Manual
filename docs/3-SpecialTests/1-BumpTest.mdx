# Bump Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Bump Test function** to determine the natural frequencies and resonance characteristics of a machine or
structure. This test is performed by striking a stationary machine component with an impact hammer and measuring 
the vibration response.

To open the Bump Test screen, proceed as follows:
1. From the **Special Tests** submenu, select **Bump Test**. 
2. The Select Route screen appears as shown in <FigureRef id="Bump-Test-Select-Route-Screen" />

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. Select **Select**.<br />

## Run a Bump Test

To run a Bump Test, proceed as follows:

1. On the Bump Test Measurement screen, select **Trigger**. The DCU begins the data acquisition process. The task status bar displays **Waiting**.
2. Strike the machine or structure with the impact hammer. The DCU captures the vibration response and displays the Bump Test chart on the screen.
3. Repeat the impact if averaging is enabled.
4. Select **Break** to stop the measurement without saving.
5. Select **Store Data** to save the captured measurement data.

## Sensor
Use the **Sensor function** to configure the sensor type and sensitivity for the Bump Test.

To configure the sensor, proceed as follows:
1. On the Bump Test Measurement screen, select **More**, then select **Sensor**. 
2. The Sensor Selection modal appears as shown in <FigureRef id="Sensor-Selection-modal" />.

<FigureProvider>
    <Figure 
        id="Sensor-Selection-modal" 
        src="/img/3-SpecialTests/1-BumpTest/SensorSelectionModal-Light.jpg"
        srcDark="/img/3-SpecialTests/1-BumpTest/SensorSelectionModal-Dark.jpg"
        caption="Sensor Selection modal" 
        width="40%"
    />
</FigureProvider>

3. Select the desired sensor type from the **Sensor** dropdown. Example: Triaxial Accelerometer
4. Select the desired sensitivity value from the **Sensitivity** dropdown. Example: 100 mv/g
5. To enable a cable integrity check, select the **Checks Cable Integrity** checkbox.
6. Select **Ok**. The DCU saves the sensor configuration and returns to the Bump Test Measurement screen.
7. To close the Sensor Selection modal without saving changes, select **Cancel**.

## Options (In case of No)
Use the **Options function** to configure the measurement parameters for the Bump Test.

To configure the measurement options, proceed as follows:
1. On the Bump Test Measurement screen, select **More**, then select **Options**. 
2. The Options screen appears as shown in <FigureRef id="Bump-Test-Options-screen" />.

<FigureProvider>
    <Figure 
        id="Bump-Test-Options-screen" 
        src="/img/3-SpecialTests/1-BumpTest/BumpTestOptionsScreen-Light.jpg"
        srcDark="/img/3-SpecialTests/1-BumpTest/BumpTestOptionsScreen-Dark.jpg"
        caption="Bump Test Options screen" 
        width="70%"
    />

3. Select the desired **Frequency** from the dropdown. 
4. Select the desired **Resolution** from the dropdown. 
5. Select the desired **Averages** from the dropdown. 
6. Enter the **Trigger** value.
7. Enter the **Pre-Trigger** value. 
8. Enable or disable the following options as required:
    <ul>
        <li>Perform Negative Averaging</li>
        <li>Instrumented Hammer</li>
        <li>Expanded X Axis</li>
        <li>Unwrap Phase</li>
        <li>Max. chart</li>
    </ul>
9. Select the desired **Display** option:
    <ul>
        <li>Output</li>
        <li>Input</li>
    </ul>
10. Select the desired **Mode**:
    <ul>
        <li>Spectrum</li>
        <li>Time</li>
    </ul>
11. Select the desired **Scale**:
    <ul>
        <li>Log</li>
        <li>Linear</li>
    </ul>
12. Select the desired **Show** option:
    <ul>
        <li>Coherence</li>
        <li>Phase</li>
    </ul>
13. Select **Save**. The DCU saves the configured options and returns to the Bump Test Measurement screen.
14. To reset all settings to default values, select **Reset**.
15. To close the Options screen without saving changes, select **Cancel**.
