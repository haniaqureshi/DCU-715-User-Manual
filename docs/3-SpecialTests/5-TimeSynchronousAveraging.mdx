# Time Synchronous Averaging

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Time Synchronous Averaging** (TSA) function to extract periodic waveforms from noisy vibration data by synchronizing data acquisition with the shaft's rotation via a tachometer signal. This technique is useful for isolating gear mesh frequencies and other rotation-synchronous events from background noise.
To open the Time Synchronous Averaging screen, proceed as follows:
1. From the **Special Tests** submenu, select **Time Synchronous Averaging**.
2. The Select Route screen appears as shown in <FigureRef id="Time-Synchronous-Averaging-Select-Route-Screen" />.

### Run a Time Synchronous Averaging measurement
To run a Time Synchronous Averaging measurement, proceed as follows:

1. On the Time Synchronous Averaging Measurement screen, select **Start Measuring**.
2. The DCU begins capturing the vibration signal synchronized with the tachometer pulses.
3. Allow the DCU to complete the configured number of averages.
4. Select **Store Data** to save the captured data.
5. Select **Reset** to clear the current measurement, if needed.
