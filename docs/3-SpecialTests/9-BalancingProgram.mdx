# Balancing Program
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Balancing Program** to correct rotor unbalance by calculating the correction weight and angle needed on one or two correction planes. The program supports Single Plane, Single Plane One Shot, and 2 Plane Balance workflows depending on the rotor configuration.

To open the Balancing Program, proceed as follows:

1. From the Dashboard, select **Balancing Program.**
2. The Select Route screen appears as shown in <FigureRef id="Balancing-Program-Select-Route-Screen" />

### Select a route
To select a route, proceed as follows:

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. Select **Select** the system redirect you to the Select Machine screen.

:::info 
If the selected route is more than 2 weeks old, a warning dialog appears. Select **Yes** to download a new route or **No** to proceed with the existing route. The warning and Update Routes flow is the same as described in above sections.

## Right Side Navigation Menu
### Single Plane 
Use **Single Plane balancing** for narrow or cantilevered rotors, where correction on a single plane is sufficient and cross-effect balancing between two planes is not required.

To run a Single Plane balancing measurement, proceed as follows:

1. On the Select Machine screen, select the required machine profile from the list.
2. Select **Single Plane**. The Single Plane measurement screen appears as shown in <FigureRef id="Single-Plane" />.

### 2 Plane Balance  
Use **2 Plane Balance** for long, dual-bearing rotors where unbalance forces affect both correction planes simultaneously.

To run a 2 Plane Balance measurement, proceed as follows:

1. On the Select Machine screen, select the required machine profile from the list.
2. Select **2 Plane Balance**. The 2 Plane Balance screen appears as shown in <FigureRef id="2-Plane-Balance" />.
3. This screen displays the measurement instructions, tachometer and phase readings, and the run values for both the Near and Far correction planes.

### Run a 2 Plane Balance measurement
To run a 2 Plane Balance measurement, proceed as follows:

1. On the 2 Plane Balance screen, review the instruction shown in the Instructions box (e.g., Measure on NEAR END).
2. Select **Near end Initial** (or **Far end Initial**, depending on the instruction). The polar diagram screen appears, 
and the status bar shows the current measurement count (e.g., Measurement: 1).

<FigureProvider>
    <Figure

        caption="2 Plane Balance polar diagram screen"

3. Follow the on-screen instructions to complete the near and far initial runs, trial weight run, and second runs as prompted.
4. Select **Capture** to record each measurement reading.
5. Once all required runs are complete, select **Display Results** to view the calculated correction weight and angle.

### Polar diagram zoom controls
To enlarge a polar plot for closer inspection of phase and amplitude, proceed as follows:

1. Select **Maximize Near Plot** or **Maximize Far Plot** to enlarge the corresponding polar diagram to full screen.
2. Select the same button again to return the diagram to its standard size and restore the control panel view.

The **Sensor** and **Options** screens in the **2-Plane Balance Measurement** module are the same as those described in
[Section 3.8](../3-SpecialTests/8-MeasurementTest.mdx). Check **Section 3.8** for a detailed description of these screens. 

:::

#### Procedure Add New Machine
To successfully register a new machinery profile into the device memory, proceed as follows:

1. Navigate to the **Add Machine** layout grid by selecting **More** and then click **Add machine**.
2. Tap inside the individual text data entry blocks to populate asset values **(Machine Name, Rotor Weight, Rotor Radius,** etc.) using the device keypad.
3. Configure physical shaft properties using the **Direction, Unit System,** and **Weight Unit** radio button selection targets.
4. Review the configured entries to ensure operational parameters match the physical machine nameplate details.
5. Select **Save**. The DCU registers the profile parameters, appends the entry to the machine database index list, 
and redirects the interface back to the updated **Area and Machine View** dashboard panel.
6. To exit the input screen immediately without preserving data entry modifications, select **Cancel**.

### Edit Machine

1. Highlight the target machine profile row from the database list, select **More** and click **Edit machine**.
2. Modify the dimensional or operational tracking properties inside the entry form, then select **Save** to lock in updates.

### Delete Machine 
1. Highlight the target machine entry row from the index list, select **More**, and click **Delete machine**.
2. A deletion confirmation dialog appears; confirm the prompt to permanently purge the selected asset configuration profile from the DCU local storage database memory.
