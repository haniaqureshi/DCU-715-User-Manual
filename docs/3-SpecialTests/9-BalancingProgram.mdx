# Balancing Program
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Balancing Program** to correct rotor unbalance by calculating the correction weight and angle needed on one or two correction planes. The program supports Single Plane, Single Plane One Shot, and 2 Plane Balance workflows depending on the rotor configuration.
To open the Balancing Program, proceed as follows:

1. From the Dashboard, select **Balancing Program.**
2. The Select Route screen appears as shown in <FigureRef id="Balancing-Program-Select-Route-Screen" />

### Select Route Screen

:::note

The Select Route screen and its available fields and controls are the same as described in [Section 3.1](1-BumpTest.mdx). 
Please review that section for a detailed description. 

:::

### Select a route
To select a route, proceed as follows:

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. Select **Select** the system redirect you to the Select Machine screen.

:::info 
If the selected route is more than 2 weeks old, a warning dialog appears. Select **Yes** to download a new route or **No** to proceed with the existing route. The warning and Update Routes flow is the same as described in above sections. 
:::

### Select Machine screen
After selecting a route, the Select Machine screen appears. This screen displays the profile of the currently 
selected machine and provides access to the balancing workflows.

## Right Side Navigation Menu
### Single Plane 
Use **Single Plane balancing** for narrow or cantilevered rotors, where correction on a single plane is sufficient and cross-effect balancing between two planes is not required.
To run a Single Plane balancing measurement, proceed as follows:

1. On the Select Machine screen, select the required machine profile from the list.
2. Select **Single Plane**. The Single Plane measurement screen appears as shown in <FigureRef id="Single-Plane" />.

:::

### Single Plane One Shot
Use **Single Plane One Shot** to compute a rapid correction using existing configuration coefficients, bypassing the trial weight run required in a standard 
Single Plane balance. To run a Single Plane One Shot balancing measurement, proceed as follows:

1. On the Select Machine screen, select the required machine profile from the list.
2. Select **Single Plane One Shot**. The Single Plane One Shot measurement screen appears as shown in <FigureRef id="Single-Plane-One-Shot" />.

### 2 Plane Balance  
Use **2 Plane Balance** for long, dual-bearing rotors where unbalance forces affect both correction planes simultaneously.
To run a 2 Plane Balance measurement, proceed as follows:

1. On the Select Machine screen, select the required machine profile from the list.
2. Select **2 Plane Balance**. The 2 Plane Balance screen appears as shown in <FigureRef id="2-Plane-Balance" />.
3. This screen displays the measurement instructions, tachometer and phase readings, and the run values for both the Near and Far correction planes.
