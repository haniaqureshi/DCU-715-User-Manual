# Coast Down Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Coast Down Test function** to analyze how a machine's vibration levels change as it decelerates from 
operating speed to a complete stop. This test helps identify resonance zones and critical speeds that the 
machine passes through during shutdown.

To open the Coast Down Test screen, proceed as follows:

1. From the **Special Tests** submenu, select **Coast Down Test**.
2. The Select Route screen appears as shown in <FigureRef id="Coast-Down-Test-Select-Route-Screen" />

## Select Route

To select a route, proceed as follows:

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. Select **Select**.<br />
    a. If the selected route is more than 2 weeks old, a warning dialog appears the same as shown in <FigureRef id="Route-Age-Warning-Dialog" /> 

<FigureProvider>
    <Figure 
        id="Route-Age-Warning-Dialog" 
        src="/img/3-SpecialTests/2-CoastDownTest/Route-Age-Warning-Dialog-Light.jpg"
        caption="Route Age Warning Dialog" 
        width="70%"
    />

:::warning

If the route is more than 2 weeks old, the following message appears: 
**Route is more than 2 weeks old**. Please download a new route before proceeding! 
Press **'YES' to exit** and download a new **ROUTE or 'NO' to** proceed with the old **ROUTE**.

3. Select **Yes** to exit and download a new route. The Update Routes screen appears.
4. Select **No** to proceed with the existing route. The Coast Down Test Measurement screen appears.

1. On the Update Routes screen, select **More**. The Options screen appears, displaying the available connection types as shown in <FigureRef id="Connection-Options-Screen" />

    <ul>

## Run a Coast Down Test

To **run a Coast Down Test**, proceed as follows:

1. On the Coast Down Test Measurement screen, select **Start Measuring**. 
2. The DCU begins capturing vibration data. The task status bar displays **Measurement**.
3. Allow the machine to decelerate from operating speed to a complete stop. 
4. The DCU captures vibration data across the decreasing RPM range and displays the results on the chart as shown in <FigureRef id="Coast-Down-Test-Measurement-Chart" /> 

<FigureProvider>
    <Figure 
        id="Coast-Down-Test-Measurement-Chart" 
        src="/img/3-SpecialTests/2-CoastDownTest/Coast-Down-Test-Measurement-Chart-Light.jpg"
        caption="Coast Down Test Measurement Chart" 
        width="70%"
    />
</FigureProvider>

5. Select **Stop** to end the measurement.
6. Select **Store Data** to save the captured measurement data to the selected route.

To run the Tachometer Test, proceed as follows:

1. On the Coast Down Test Measurement screen, select **More**, then select **Test Tachometer**. 
2. The Tachometer Test modal appears as shown in <FigureRef id="Tachometer-Test-Modal" />

To configure the sensor, proceed as follows:
1. On the Coast Down Test Measurement screen, select **More**, then select **Sensor**.
