# Extended Time Domain Test

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Extended Time Domain function** to capture long-duration, high-resolution raw time waveform data. 
This test is particularly useful for analyzing transient events or performing Operating Deflection Shape (ODS) studies.

To open the Extended Time Domain screen, proceed as follows:

1. From the **Special Tests** submenu, select **Extended Time Domain**. 
2. The Select Route screen appears as shown in <FigureRef id="Extended-Time-Domain-Select-Route-Screen" />

## Select a route

To select a route, proceed as follows:

1. On the Select Route screen, select the desired route from the list. The selected route is highlighted.
2. Select Select.<br />
    a. If the selected route is more than 2 weeks old, a warning dialog appears.

<FigureProvider>
    <Figure 
        id="Route-Age-Warning-Dialog" 
        src="/img/3-SpecialTests/3-ExtendedTimeDomain/Route-Age-Warning-Dialog-Light.jpg"
        srcDark="/img/3-SpecialTests/3-ExtendedTimeDomain/Route-Age-Warning-Dialog-Dark.jpg" 
        caption="Route Age Warning Dialog" 
        width="70%"
    />
</FigureProvider>

:::warning

If the route is more than 2 weeks old, the following message appears: Route is more than 2 weeks old. 
Please download a new route before proceeding! Press **'YES'** to exit and download a new **ROUTE** or **'NO'** 
to proceed with the old **ROUTE**.

:::

3. Select **Yes** to exit and download a new route. The Update Routes screen appears.
4. Select **No** to proceed with the existing route. The Extended Time Domain Measurement screen appears.

## Extended Time Domain Measurement screen
The following fields and controls available on the Extended Time Domain Measurement screen.

| Field/Button    | Description                                                                                |                                                                                                                                                                                                                           
| :-----------    | :----------------------------------------------------------------------------------------- |
| Options         | Displays the current measurement configuration.                                            |
| Sequence Nr     | Displays the current capture sequence number.  <br />**Example**: 1                        | 
| Sensor          | Displays the connected sensor type and sensitivity. <br />**Example**: 100 mv/g triax      |
| Active Channels | Displays the axes currently enabled for measurement. <br />**Example**: X, Y, Z            | 
| ICP             | Displays whether ICP sensor power is enabled.  <br />**Example**: True                     | 
| Cable Check     | Displays whether the cable integrity check is enabled. <br />**Example**: True             |  
| Time            | Displays the time waveform capture parameters.                                             |  
| ODS             | Displays whether Operating Deflection Shape mode is enabled. <br />**Example**: False      |  
| Time            | Displays the configured recording duration in seconds. <br />**Example**: 2.00             | 
| Samples         | Displays the number of samples collected during the recording. <br />**Example**: 384,615  |
| Measure         | Starts the extended time waveform data capture.                                            |
| Stop            | Stops the active recording session.                                                        |
| Store Data      | Saves the captured waveform data to the device                                             |
| Sensor          | Opens the Sensor Selection modal to configure the sensor type and sensitivity.             |
| Options         | Opens the Options screen to configure channel and time settings.                           |
| More            | Expands the button panel to display the Reset Sequence Number button.                      |

## Run an Extended Time Domain measurement
To run an **Extended Time Domain measurement**, proceed as follows:

1. On the Extended Time Domain Measurement screen, select **Measure**. 
2. The DCU begins capturing the extended time waveform data. The task status bar displays the active measurement number.
3. Monitor the following values during the recording:
    <ul>
        <li>Sequence Nr</li>
        <li>Time (s)</li>
        <li>Samples</li>
    </ul>
4. Select **Stop** to end the recording manually before the set time expires.
5. Select **Store Data** to save the captured waveform data. The task status bar displays **Store completed** and shows the
measurement finish time as shown in <FigureRef id="Store-Measurement-Data" />

## Additional Configuration Controls 
#### Options Screen
The following fields and controls available on the Options screen.

| Field/Button | Description                                                                                                                            |                                                                                                                                                                                                                           
| :----------- | :------------------------------------------------------------------------------------------------------------------------------------- |
| Channel      | Selects the measurement axes to record. Available options: X, Y, Z, R. Select the checkbox for each required channel.                  |
| ODS          | Enables or disables Operating Deflection Shape mode. When enabled, ODS data is captured during the recording.                          |
| Time         | Sets the recording duration in seconds. Select the field to open the numeric keypad and enter the desired value. <br /> **Example:** 0 |
| Save         | Saves the configured channel and time settings and returns to the Extended Time Domain Measurement screen.                             |
| Cancel       | Closes the Options screen without saving changes.                                                                                      |

## Configure the options
To configure the measurement options, proceed as follows:

1. On the Extended Time Domain Measurement screen, select **Options**. The Options screen appears.
2. Select the checkboxes for the required measurement channels:
    <ul>
        <li>X</li>
        <li>Y</li>
        <li>Z</li>
        <li>R</li>
    </ul>
3. To enable Operating Deflection Shape analysis, select the **ODS** checkbox.
4. Select the **Time** field. 
5. The Time (Seconds) numeric keypad appears as shown in <FigureRef id="Time-Seconds-Numeric-Keypad" />.

<FigureProvider>
    <Figure 
        id="Time-Seconds-Numeric-Keypad" 
        src="/img/3-SpecialTests/3-ExtendedTimeDomain/Time-Seconds-Numeric-Keypad-Light.jpg"
        srcDark="/img/3-SpecialTests/3-ExtendedTimeDomain/Time-Seconds-Numeric-Keypad-Dark.jpg" 
        caption="Time Seconds Numeric Keypad" 
        width="40%"
    />
</FigureProvider>

6. Use the numeric keypad to enter the desired recording duration in seconds.
7. Select **Save**. The DCU saves the configured options and returns to the Extended Time Domain Measurement screen.
8. To close the Options screen without saving changes, select **Cancel**.

## Sensor
Use the **Sensor function** to configure the sensor type and sensitivity for the Extended Time Domain measurement.

To configure the sensor, proceed as follows:
1. On the Extended Time Domain Measurement screen, select **Sensor**.
2. The Sensor Selection modal appears as shown in  <FigureRef id="Sensor-Selection-Modal" />. 

<FigureProvider>
    <Figure 
        id="Sensor-Selection-Modal" 
        src="/img/3-SpecialTests/3-ExtendedTimeDomain/Sensor-Selection-Modal-Light.jpg"
        srcDark="/img/3-SpecialTests/3-ExtendedTimeDomain/Sensor-Selection-Modal-Dark.jpg" 
        caption="Sensor Selection Modal" 
        width="40%"
    />
</FigureProvider>

3. Select the desired sensor type from the **Sensor** dropdown. Example: Triaxial Accelerometer
4. Select the desired sensitivity value from the **Sensitivity** dropdown. Example: 100 mv/g
5. To enable a cable integrity check, select the **Checks Cable Integrity** checkbox.
6. Select **Ok**. The DCU saves the sensor configuration and returns to the Extended Time Domain Measurement screen.
7. To close the Sensor Selection modal without saving changes, select **Cancel**.

To reset the sequence number, proceed as follows:

1. On the Extended Time Domain Measurement screen, select **More**.
