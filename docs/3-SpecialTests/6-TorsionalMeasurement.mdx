# Torsional Measurement
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Torsional Measurement** function to analyze fluctuations in the angular velocity of a rotating shaft. This test helps identify torque-related issues or mechanical defects in rotating equipment.

To open the Torsional Measurement screen, proceed as follows:

1. From the Special Tests submenu, select **Torsional Measurement**. 
2. The Select Route screen appears as shown in <FigureRef id="Torsional-Measurement-Select-Route-Screen" />.

### Select a route
To select a route, proceed as follows:

1. On the **Select Route** screen, select the desired route from the list. 
2. The system redirects you to the **Measurement** screen, where you can measure the route data. 

:::info

If the selected route is more than 2 weeks old, a warning dialog appears. Select **Yes** to download a new route or **No** to proceed with the existing route. The warning and Update Routes flow is the same as described in above sections.

:::

### Run a Torsional Measurement
To run a Torsional Measurement, proceed as follows:
1. On the Torsional Measurement screen, select **Start Measuring**. The DCU begins capturing torsional vibration
 data. The task status bar displays **Measurement** and the live chart updates in real time.
2. To run an Extended Time Domain measurement simultaneously, select **Start Meas. Ext. TD**.
3. Select **Stop** to end the active measurement session.
4. Select **Store Data** to save the captured torsional measurement data.
5. To save the Extended Time Domain data, select **Store Ext. TD.**

:::info

When **Start Measuring** is selected, the **Stop** button becomes active and all other controls on the right panel are disabled. When **Stop** is selected to end the measurement, the **Stop** button becomes disabled and all other controls become available again. 

:::

### Options screen

| Fields/Buttons     | Description                                         	       	                                                                    |
|------------------- |---------------------------------------------------------------------------------------------------------------------------------- |
| Display            | Selects the measurement display mode. Available options: Spectrum, Time.                                                          | 
| Show               | Selects the active measurement axis. Available options: X, Y, Z.                                                                  |
| Frequency          | Sets the frequency range for analysis. Select from the dropdown.<br />**Example:** 250,000 CPM                                    |
| Resolution         | Sets the number of spectral lines. Select from the dropdown.<br />**Example:** 6400                                               |
| Number of Teeth    | Sets the number of gear or encoder teeth. Select the field to open the numeric keypad and enter the value. <br />**Example:** 100 |
| Shaft Speed (CPM)  | Sets the shaft rotational speed in CPM. <br />**Example:** 1800                                                                   |
| Filter Width (CPM) | Sets the filter width in CPM. <br />**Example:** 10000                                                                            |
| Apply Filter       | Enables or disables the frequency filter.                                                                                         |
| FM Demod           | Enables or disables FM demodulation.                                                                                              |
| Zoom               | Enables or disables zoom mode.                                                                                                    |
| Max. chart         | Enables or disables the maximum chart display.                                                                                    |  
| Reset              | Resets all options to their default values.                                                                                       | 
| Save               | Saves the configured options and returns to the Torsional Measurement screen.                                                     | 
| Cancel             | Closes the Options screen without saving changes.                                                                                 |

### Configure the options

To configure the measurement options, proceed as follows:
1. On the Torsional Measurement screen, select **More**, then select **Options**. The Options screen appears.
2. Select the desired **Display** mode:
    <ul>
        <li>Spectrum</li>
        <li>Time</li>
    </ul>
3. Select the desired **Show** axis:
    <ul>
        <li>X</li>
        <li>Y</li>
        <li>Z</li>
    </ul>
4. Select the desired **Frequency** from the dropdown.
5. Select the desired **Resolution** from the dropdown.
6. Select the **Number of Teeth** field. The Number of Teeth numeric keypad appears as shown in <FigureRef id="Number-of-Teeth-Numeric-Keypad" />


<FigureProvider>
    <Figure
        id="Number-of-Teeth-Numeric-Keypad"
        src="/img/3-SpecialTests/6-TorsionalMeasurement/NumberOfTeethNumericKeypad-Light.jpg"
        caption="Number of Teeth numeric keypad"
        width="40%"
    />
</FigureProvider>

7. Use the numeric keypad to enter the number of gear or encoder teeth. 
8. Select the **Shaft Speed (CPM)** and **Filter Width (CPM)** field to enter the value using the numeric keypad, same as used in the **Number of Teeth** field. 
9. Enable or disable the following options as required:
    <ul>
        <li>Apply Filter</li>
        <li>FM Demod</li>
        <li>Zoom</li>
        <li>Max. chart</li>
    </ul>
10. Select **Save**. The DCU saves the configured options and returns to the Torsional Measurement screen.
11. To reset all options to default values, select **Reset**.
12. To close the Options screen without saving changes, select **Cancel**.
