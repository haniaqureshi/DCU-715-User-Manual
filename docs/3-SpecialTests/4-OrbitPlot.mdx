# Orbit Plot

import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the Orbit Plot function to visualize the path of a shaft's centerline as it rotates within a bearing. 
This test combines vibration data from two orthogonal sensors to help identify unbalance, misalignment, or 
shaft rubs.

To open the Orbit Plot screen, proceed as follows:

1. From the **Special Tests** submenu, select **Orbit Plot.** 
2. The Select Route screen appears as shown in <FigureRef id="Orbit-Plot-Select-Route-Screen" />

## Orbit Plot Measurement Modal

The following fields and controls available on the **Orbit Plot Measurement** screen.

| Fields/Button   | Description                                                                                                                         |                                                                                                                                                                                                                                                                                                                                                     
| :-------------- | :---------------------------------------------------------------------------------------------------------------------------------- |
| Options         | Displays the current measurement configuration.                                                                                     |
| Rotation        | Displays the shaft rotation direction.<br /> **Example:** Clockwise                                                                 |
| Horizontal      | Displays the angular position configured for the horizontal sensor.<br /> **Example:** 45                                           |
| Vertical        | Displays the angular position configured for the vertical sensor. <br /> **Example:** 315                                           |
| Tachometer      | Displays the tachometer input status.                                                                                               |
| Type            | Displays the signal type being processed.<br /> **Example:** AC                                                                     |
| Nr of orbits    |  Displays the number of shaft revolutions configured for the plot.<br /> **Example:** 4                                             |
| Id              | Displays the measurement identification number.<br /> **Example:** 900001                                                           |
| RMS(H)          | Displays the Root Mean Square vibration level for the horizontal axis.                                                              |
| RMS(V)          | Displays the Root Mean Square vibration level for the vertical axis.                                                                |
| Measure         | Starts the live data acquisition. When active, all other controls on the right panel are disabled until the measurement is stopped. |
| Break           | Stop the active measurement session.                                                                                                |
| Sensor          | Opens the Sensor Selection modal to configure the sensor type and sensitivity. Becomes available after the measurement is stopped.  |
| Test Tachomet.  | Opens the Tachometer Test modal to verify the speed sensor signal. Becomes available after the measurement is stopped.              |
| Options         | Opens the Options screen to configure orbit plot parameters. Becomes available after the measurement is stopped.                    |

:::info

When **Measure** is selected, all other buttons on the right panel are disabled. The remaining controls become available again only after **Break** is selected to stop the measurement.

:::

## Run an Orbit Plot measurement

To run an Orbit Plot measurement, proceed as follows:

1. On the Orbit Plot Measurement screen, select **Measure**. 
2. The DCU begins capturing vibration data from the horizontal and vertical sensors. 
3. The task status bar displays **Waiting for tach**. 
4. All other controls on the right panel are disabled during the active measurement.
5. Allow the DCU to capture the shaft orbit data.
6. Select **Break** to stop the measurement. The remaining controls become available.
7. Review the following values on the measurement screen:
<ul><li>RMS(H)</li>
<li>RMS(V)</li>
<li>Nr of orbits</li></ul>

## Sensor Selection modal

The following fields and controls available in the Sensor Selection modal.


| Field/Button           | Description                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                            
| :--------------------- | :------------------------------------------------------------------------------- |
| Sensor                 | Selects the sensor type from the dropdown. <br />**Example:** Aux Input          |

| Aux Parameters         | Displays the auxiliary input configuration options.                              |
