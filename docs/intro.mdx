# Introduction

This module introduces the **Series 715 Digital Collection Unit (DCU)**, its operating concept, and the overall workflow
used to collect vibration measurements. It also provides an overview of the DCU hardware, user interface, and 
system capabilities to help technicians become familiar with the device before performing measurements or 
diagnostics.

## Overview
The **Series 715 Digital Collection Unit** (hereafter referred to as the DCU) is a portable vibration data collection
device designed for predictive maintenance and condition monitoring applications. It acquires vibration and process
data from industrial equipment, stores the collected measurements, and transfers them to the ITR Graphics™ software
platform for analysis and reporting.

The DCU supports simultaneous multi-channel data acquisition, allowing vibration, auxiliary sensor, and tachometer signals
to be collected while maintaining phase relationships between channels. 

Measurements can be displayed in multiple formats, including spectrum, time waveform, phase, and waterfall views, enabling
technicians to verify signal quality before saving data.

This module introduces the DCU hardware, explains how the system operates, and describes the layout of the user interface.

## System Configuration
The Series 715 DCU is designed to operate with the **ITR Graphics™** vibration analysis platform.

Before field work begins, predefined measurement routes are transferred from ITR Graphics™ to the DCU. These routes guide 
technicians through each inspection by defining the equipment to measure, the order in which measurements are collected, 
and the acquisition parameters required for each point.

A measurement route can include:

- Measurement locations
- Machine information
- Measurement sequence
- Sensor configuration
- Data acquisition parameters
- Historical measurement information
- Scheduled inspection information

After measurements have been collected, the recorded data is transferred back to ITR Graphics™ for processing, trending, 
analysis, and report generation.

## How the DCU Works
The DCU records machine vibration using an accelerometer mounted at predefined measurement locations.

During data collection, the operator places the sensor on the machine according to the measurement route loaded into the DCU. 
The device acquires vibration data, processes the measurement in real time, and stores the results as a **measurement event**.

Once field data collection is complete, the stored measurements are uploaded to ITR Graphics™, where vibration analysts review 
the results to evaluate machine condition, identify developing faults, and prepare maintenance recommendations.

The overall workflow consists of four stages:

1. Measurement routes are created in ITR Graphics™.
2. Routes are transferred to the DCU.
3. Measurements are collected in the field using the DCU.
4. Measurement data is uploaded back to ITR Graphics™ for analysis and reporting.

## Hardware Overview
The Series 715 Digital Collection Unit (DCU) is designed for portable field use in industrial environments. The device combines vibration
data acquisition, onboard processing, and a touchscreen interface in a rugged enclosure that enables technicians to perform measurements 
without requiring a separate computer.

The DCU supports multiple sensor connections, auxiliary inputs, and communication interfaces that allow technicians to collect, store,
and transfer measurement data during routine condition monitoring and diagnostic activities.

## Application Interface 
The DCU application provides a consistent touchscreen interface across all modules, including Routes, Measurements, Special Tests, and DCU Setup. Most screens share the same layout, allowing technicians to navigate the application and monitor device status regardless of the function being performed.

    The application interface consists of four primary areas:
    - Header Bar
    - Task Status Bar
    - Main Workspace
    - System Alerts Bar

    Understanding the purpose of each area will help you navigate the application and quickly identify important system information during operation.

    ### Application Screen Layout
    The DCU application uses a consistent screen layout throughout the software. Each screen is divided into four functional areas that display navigation information, task status, application content, and system notifications.

## System Specifications
This section describes the hardware, communication, data acquisition, signal processing, storage, power, and environmental specifications 
of the Series 715 Digital Collection Unit (DCU).

###  Operating System and User Interface
The Series 715 DCU includes an embedded operating system and integrated touchscreen interface designed for portable 
field operation. The following table describes the operating system and user interface specifications.

    | Specification      | Description                                            |
    |:------------------ | :----------------------------------------------------- |
    | Operating System   | Embedded Windows® 7                                    |
    | Processor          | Intel® E-Series processor running at 1.6 GHz           |
    | Display            | 6.5-inch TFT LCD touchscreen                           |
    | Display Resolution | 640 × 480 pixels                                       |
    | Input Methods      | Touchscreen and optional Bluetooth keyboard            |
    | Language Support   | English, Chinese, German, Spanish, French, and Italian |

### Communication Interfaces
The DCU supports multiple communication methods for transferring routes, software updates, and measurement data. The
following table describes the available communication interfaces.

    | Interface    | Description       |
    |:------------ | :---------------- |
    | USB          | USB 2.0           |
    | Bluetooth    | Bluetooth® 2.0    |
    | Wireless LAN | IEEE 802.11 b/g/n |

### Data Acquisition
The DCU supports simultaneous multi-channel vibration data acquisition using accelerometers, auxiliary inputs, and 
a tachometer input. The following table describes the supported input capabilities.

    | Feature                   | Description                                                   |
    |:------------------------- | :------------------------------------------------------------ |
    | Dynamic Measurement Range | 80 dB                                                         |
    | Sensor Excitation         | 20 V, 2.7 mA constant-current IEPE (ICP®) excitation          |
    | Accelerometer Support     | Triaxial, dual-axis, and single-axis IEPE accelerometers      |
    | Voltage Inputs            | All channels can be configured for voltage input measurements |
    | Signal Clipping Detection | ±5 V AC peak-to-peak maximum                                  |
    | Auxiliary Inputs          | Two auxiliary channels supporting up to 50 VDC                |   
    | Ultrasonic Input          | AUX2 supports ultrasonic measurements up to 80 kHz            |
    | Tachometer Input          | One TTL-compatible pulse input per revolution                 |
    | Cable Diagnostics         | Accelerometer cable fault detection                           |

    :::note

        Certain sensor configurations require external adapters or power sources depending on the connected sensor.
    
    :::

### Signal Processing
The DCU performs onboard digital signal processing to analyze vibration data during measurement acquisition. The 
following table summarizes the signal processing capabilities.

    | Feature                        | Description                                                 |
    |:------------------------------ | :---------------------------------------------------------- |
    | Analog-to-Digital Converter    | 16-bit ADC                                                  |
    | Sampling Rate                  | Up to 64 kHz per channel                                    |
    | Window Function                | Hanning                                                     |
    | FFT Resolution                 | 200, 400, 800, 1,600, 3,200, 6,400, 12,800, or 25,600 lines |
    | Averaging                      | Linear averaging up to 512 averages                         |
    | Measurement Modes              | Acceleration and Velocity                                   |
    | RMS Calculation                | Supported                                                   |
    | Waterfall Analysis             | Supported                                                   |
    | Envelope Analysis              | Automatic on the vertical channel                           |
    | Time Domain Overlap            | 50% (Normal Mode), 0% (Tachometer Mode)                     |
    | Simultaneous Measurements      | Two, three, four, and five channels                         |
    | ODS Data Collection            | Supported                                                   |
    | Continuous Waveform Collection | Supported                                                   |
    | Ultrasonic Processing          | Up to 80 kHz                                                |
