## General Information
The **Series 715 Digital Collection Unit (DCU)** is a high-performance portable system designed for **advanced vibration 
data collection, monitoring, and analysis** in industrial environments. It is specifically developed to support 
**predictive maintenance** by accurately measuring machine vibration and helping detect potential faults before they 
lead to equipment failure.

The DCU supports **triaxial (3-channel) vibration measurement** along with **two auxiliary sensor channels** and a 
**tachometer input**, allowing simultaneous multi-channel data acquisition while preserving phase relationships 
between signals. Although optimized for accelerometer sensors, the system can interface with a wide range of sensor 
types, making it highly flexible for different monitoring applications. Built on an **embedded Windows 7 platform,** the
DCU measures, processes, displays, and stores vibration data in both **frequency (spectrum)** and **time waveform** formats.
Real-time measurement results can be viewed directly on the integrated LCD display in multiple formats, including 
**spectrum, time waveform, phase, and waterfall plots**.

## System Configuration/Setup
The **Digital Collection Unit (DCU)** is designed to operate with the **ITR Graphics™ vibration** analysis platform. 
Predefined measurement routes are loaded into the unit to guide the operator during the data collection process. 
These routes define:
- Desired Order of Data Collection
- Measurement Parameters such as
    <ul>
        <li>Data acquisition parameters</li>
        <li>Vibration data Comparison with previous readings and reports</li>
    <li>Schedule information to show the operator which machines need to be measured.</li>
    </ul>

## How It Works
This equipment is measured by placing the magnet-mounted accelerometer at specific points and orientations on a 
machine and using the **DCU** to record the vibration data; the recorded data is called a, **“Measure Event.”**  When 
received at **ITR, the Measure Event Data** is then further processed and prepared for presentation to a trained 
vibration analyst who uses the **ITR Graphics™** platform to assess the current operating characteristics of the 
equipment and to predict future problems that may occur.  Concise reports are prepared and presented to the 
individuals responsible for maintaining the equipment.

## Operating System and Interface
**DCU** features a 1.6 GHz Intel E-Series CPU with onboard central processing, memory, and high integration data 
acquisition circuitry. 
    - Embedded Windows 7 OS with preinstalled DCU program
    - Touchscreen and optional Bluetooth keyboard
    - 6.5” 640x480 TFT LCD display
    - Multiple language capabilities include Chinese, German, Spanish, French, and Italian

## Communication
This device communicates via
    - USB 2.0
    - Bluetooth 2.0
    - WIFI 802.11b/g/n

## Data Inputs
Input Data through:
    - 80dB dynamic measurement range
    - 20V, 2.7mA constant-current excitation power source to power the sensor, such as triaxial/single axial IEPE (ICP®) accelerometers
    - All channels can be configured to accept voltage inputs 
    - Signal clipping detection (±5 volts AC Peak to Peak maximum) 
    - Two auxiliary channels (Aux1 & Aux2) can be configured to accept 50 VDC signals
    - Aux2 can be used as a microphone input channel, processing ultrasonic signals up to 80 KHz, ±8V Peak to Peak
    - One Phasor / Tachometer Pulse input, one pulse per revolution, low to high or high to low, TTL compatible 
    - Cable fault detection (Used to diagnose accelerometer sensor cable problems)

## Signal Processing
The Signal processing contains:
    - 16-bit ADC with 64K sample rate per channel
    - Hanning windowing 
    - FFT resolution is selectable to 200, 400, 800, 1600, 3200, 6400, 12800, 25600 lines
    - Normal averaging mode
    - Selectable acceleration or velocity modes  
    - RMS calculation 
    - Selectable FFT linear averaging, up to 512 averages 
    - Waterfall generation on a specified channel; number of spectra, spectral resolution, and time between spectra are selectable 
    - Enveloping function automatically performed on the vertical channel 
    - 50%-time domain overlap for FFT in normal mode, 0% overlap in Phasor / Tachometer Mode 
    - 2,3,4 & 5 channel simultaneous measurements 
    - ODS analysis data collection
    - Ultrasonic channel sample up to 80KHz 
    - Continuous waveform collection for transient analysis

## Data Storage
Storage data in:
    - 90GB mSATA Solid State Disk
    - 1 GB RAM

## Logged Data
Logged date in:
    - RMS values 
    - Narrow band FFT data 
    - Envelope data 
    - Time Domain data 
    - Spectral waterfalls, speed, load, and trouble code information

## Power
DCU power contains:
    - High-density smart Li-ion battery supports continuous data collection up to 7 hours
    - Easy and quick to replace and recharge 
    - Smart on/off switch with LED display and voltage indication function

## Mechanical, Electrical, Environmental
It Contains:
    - Dimensions: 9.6 x 7.4 x 5.2 inches
    - Weight: 5.0 lbs. with battery
    - Environmental: -40 to +85°C ambient operating temperature, IP-65 rated environments

When the ITR application starts, the **DCU Initialization** screen is displayed automatically. During startup, the
system initializes the DCU by loading the required components and verifying the device status. The screen also 
displays the internal voltage values, signal channel readings, auxiliary channel readings, and the overall system 
status.
