# Power Off
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>

    The **Power** Off option initiates a full hardware shutdown of the DCU 715. A confirmation dialog appears before the 
    shutdown proceeds, preventing accidental power-off during active data collection.

    :::warning

    Selecting Power Off will shut down the DCU hardware completely. Ensure all measurement data has been saved before 
    proceeding. Unsaved data may be lost.

    :::

    To power off the device, follow the steps below:
    
    1. On the main menu, select **Power**, then select **Power Off**.
    2. A confirmation dialog appears in the center of the screen with the message: "Do you really want to Shutdown?".
    3. Verify that all measurement tasks are complete and data has been saved.
    4. Select **Yes** to initiate the full hardware shutdown, or select **No** to cancel and return to the Power menu.
