# Power Off
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>

    The **Power Off** function initiates a full hardware shutdown of the DCU 715. A confirmation dialog box appears before the 
    shutdown proceeds, preventing accidental power-off during active data collection.

    :::warning

    Selecting Power Off will shut down the DCU hardware completely. Ensure all measurement data has been saved before 
    proceeding. Unsaved data may be lost.

    :::

    To power off the device, follow the steps below:
    
    1. From the **Main Menu**, select **Power**.
    2. From the **Power** submenu, select **Power Off**.
    3. A confirmation dialog box appears as shown in <FigureRef id="PowerOff-Confirmation-Dialog-Box" />.
        <Figure 
            id="PowerOff-Confirmation-Dialog-Box" 
            src="/img/5-Power/Power-Off-Confirmation-Dialog-Box-Light.png" 
            srcDark="/img/5-Power/Power-Off-Confirmation-Dialog-Box-Dark.png"
            caption="Power Off Confirmation Dialog Box" 
            width="70%"
        />
    4. Verify that all measurement tasks are complete and data has been saved.
    5. Select **Yes** to initiate the full hardware shutdown, or select **No** to cancel and return to the **Power** submenu.
</FigureProvider>
