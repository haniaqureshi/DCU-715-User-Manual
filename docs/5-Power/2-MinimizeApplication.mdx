# Minimize Application
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Minimize Application** function to hide the application and show the Windows desktop. The application keeps
running in the background, so you don't lose any data or session information.

## Minimize the application

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **Power**.
3. From the **Power** submenu, select **Minimize Application**. The application window minimizes and the Windows desktop appears.
4. To return to the application, select its button on the Windows taskbar. The application opens where you left it.
