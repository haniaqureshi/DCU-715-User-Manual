# Minimize Application
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

<FigureProvider>

    The **Minimize Application** option hides the diagnostic software interface and redirects to the desktop environment. 
    The application session remains active and can be restored at any time from the system taskbar.

    :::note

    The software continues running in the background when minimized. No data or session state is lost.

    :::

    To minimize the application, follow the steps below:

    1. On the main menu, select **Power**, then select **Minimize Application**.
    2. The software window minimizes and the system redirects to the desktop.
    3. Perform any required operating system tasks or access other desktop applications as needed.
    4. To return to the software, select the application icon from the system taskbar to restore the interface.

</FigureProvider>
