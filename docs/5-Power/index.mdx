# Power
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

The **Power** submenu lets you manage the application and the device's power status. Use this submenu to safely shut down the device, minimize the application to access the operating system, or close the software while keeping the hardware powered on.

:::info

Always ensure that all data has been saved before using any Power function.

:::

To open the Power submenu, proceed as follows:

1. From the **Main Menu**, select **Power**.
