Use the **Power** submenu to turn off the DCU 715, minimize the application to use the Windows desktop, or close the application while the DCU 715 stays on.

:::info

Save all your data before you use any **Power** function.

:::

## Open the Power submenu

1. From the **Main Menu**, select **Power**. The **Power** submenu appears, as shown in <FigureRef id="Power-Sub-Menu" />.

## Power functions

The **Power** submenu contains the following functions:

- [**Power Off**](./1-PowerOff.mdx): Turns off the DCU 715.
- [**Minimize Application**](./2-MinimizeApplication.mdx): Hides the application and shows the Windows desktop. The application keeps running.
- [**Exit Application**](./3-ExitApplication.mdx): Closes the application. The DCU 715 stays on.

## Close the Power submenu

To close the **Power** submenu without selecting a function, select **Cancel**. The **Dashboard** appears.
