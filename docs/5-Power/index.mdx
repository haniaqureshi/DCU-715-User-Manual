The **Power** menu lets you manage the application and the device's power status. Use it to safely shut down the device, 
minimize the application to access the operating system, or close the software while keeping the hardware powered on.

:::info

Always ensure that all data has been saved before using any Power option.

:::

On the main menu, select Power. The **Power** options appear in the panel below the dashboard, as shown in <FigureRef id="Power-Sub-Menu"/>.
