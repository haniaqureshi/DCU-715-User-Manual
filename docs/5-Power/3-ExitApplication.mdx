# Exit Application
import { FigureProvider, FigureRef } from "@site/src/components/FigureContext";
import Figure from "@site/src/components/Figure";

Use the **Exit Application** function to close the application and end the current session. Unlike **Power Off**, this
function doesn't turn off the DCU 715. The device stays on after the application closes.

:::warning

Any unsaved data is lost. Save or synchronize your data before you select **Exit Application**.

:::

## Close the application

1. On the Home screen, select **Menu**. The **Main Menu** appears.
2. From the **Main Menu**, select **Power**.
3. From the **Power** submenu, select **Exit Application**. The application closes immediately.
4. Make sure that the Windows desktop or sign-in screen appears. This confirms that the application closed.
